## Overview

This program implements a Trie (prefix tree) in C to solve Codeforces Problem 1902E ("Collapsing Strings"). The problem requires computing the total length of all collapsed string concatenations across $n$ strings. The program builds a frequency-annotated Trie, counts cumulative prefix matches, and calculates the total length reduction by querying reversed strings against the Trie.

## How it works

The struct `Node` defines each Trie node:
- `char exit`: flag indicating if a word ends at this node.
- `int freq`: count of strings sharing this prefix path.
- `struct Node* child[26]`: pointers to children for lowercase English letters 'a' through 'z'.

Functions:
- `NewNode()`: allocates a node via `malloc`, initializes `exit = 0`, `freq = 0`, and zeroes all child pointers.
- `insert(struct Node* root, const char* s, int n)`: traverses string `s`, creating child nodes as needed and incrementing `cur->freq` at each node. Sets `cur->exit = 1` at the end.
- `LCP(struct Node* root, const char* s, int n)`: computes the sum of prefix frequencies matching string `s`. At each character `s[i]`, traverses to the child and adds `cur->freq` to `ans`.
- `freeTrie(struct Node* node)`: recursively frees all 26 child subtrees before freeing the node.

In `main`:
- Reads integer $n$.
- Allocates an array of string pointers `arr[n]` on the stack (C99 VLA).
- Reads $n$ strings into dynamically allocated buffers with `fgets`.
- Inserts each string into the Trie, computing the initial total string length sum.
- Initializes answer `ans = 2ll * ans * n`.
- For each string, reverses it in place and subtracts `2ll * LCP(root, arr[i], sLen)` from `ans`.
- Prints the final collapsed length `ans`.
- Frees the Trie and all allocated string buffers.

## Key excerpt

```c
void insert(struct Node* root, const char* s, int n) {
	struct Node* cur = root;
	cur->freq++;
	for (int i = 0; i < n; i++) {
		int ch = s[i] - 'a';
		if (!cur->child[ch]) {
			cur->child[ch] = NewNode();
		}
		cur = cur->child[ch];
		cur->freq++;
	}
	cur->exit = 1;
}

long long LCP(struct Node* root, const char* s, int n) {
	long long ans = 0;
	struct Node* cur = root;
	for (int i = 0; i < n; i++) {
		int ch = s[i] - 'a';
		if (!cur->child[ch]) {
			break;
		}
		cur = cur->child[ch];
		ans += cur->freq;
	}
	return ans;
}
```

## Things to watch

- **Stack overflow on recursive free:** `freeTrie` is a recursive function. For string inputs of up to $10^6$ characters, a deep Trie branch can cause the call stack to exceed stack memory limits.
- **Large buffer in main:** `char buffer[N]` with `N = 1e6 + 5` is declared as a local variable in `main`. On platforms with limited default stack sizes (such as macOS or Windows where stack is 1MB-8MB), declaring a 1MB local array can cause stack overflow; declaring it globally or with `malloc` is safer.

## Terms

- **Trie:** An ordered tree data structure used to store an associative array where keys are usually strings.
- **LCP (Longest Common Prefix):** The longest prefix shared between two or more strings.
- **Collapsing Strings:** An operation where matching suffix and prefix characters cancel each other out when concatenating strings.
