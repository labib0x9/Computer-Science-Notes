## Overview

This program implements a Trie in Go to solve Codeforces Problem 1902E ("Collapsing Strings"). To handle high-volume input within strict competitive programming time limits, it combines fast buffered standard I/O (`bufio.ReaderSize`, `bufio.WriterSize`) with a frequency-annotated prefix tree to compute total collapsed concatenation lengths across $n$ strings.

Structs:
- `node`: stores `child [26]*node`, `isEnd bool`, and `freq int`.
- `Trie`: holds pointer `root *node`.

Methods:
- `Insert(s string)`: traverses `s`, allocating missing child nodes via `NewNode()`, incrementing `cur_node.freq` at every step, and setting `isEnd = true` at the leaf.
- `LCP(s string) (cnt int)`: traverses characters in `s`. While matching child nodes exist, adds `cur_node.freq` to `cnt`.

In `solve()`:
- Reads $n$, allocates `arr` of size $n$, and reads each string.
- Creates `t := NewTrie()`.
- Sums string lengths into `ans` and inserts all strings into `t`.
- Multiplies `ans = ans * int64(2 * n)`.
- For each string, creates reversed copy `newS`, queries `t.LCP(string(newS))`, and subtracts `2 * t.LCP(...)` from `ans`.
- Outputs `ans` through buffered `Write`.

In `main()`:
- Uses `defer writer.Flush()` to ensure all buffered output is written before program termination.
- Executes `solve()`.

## Key excerpt

```go
func (t *Trie) Insert(s string) {
	cur_node := t.root
	cur_node.freq++
	for _, c := range s {
		ch := c - 'a'
		if cur_node.child[ch] == nil {
			cur_node.child[ch] = NewNode()
		}
		cur_node = cur_node.child[ch]
		cur_node.freq++
	}
	cur_node.isEnd = true
}

func (t *Trie) LCP(s string) (cnt int) {
	cur_node := t.root
	for _, c := range s {
		ch := c - 'a'
		if cur_node.child[ch] == nil {
			return
		}
		cur_node = cur_node.child[ch]
		cnt += cur_node.freq
	}
	return
}
```

## Things to watch

- **writer.Flush requirement:** Because `writer` is a 1MB buffered writer, failing to call `writer.Flush()` before program exit causes output to be held in memory without being written to standard output. The deferred `defer writer.Flush()` in `main()` guarantees proper flushing.
- **Unused helpers:** Functions `ReadPairs`, `ReadArray`, and `dfs` are declared but never invoked in `solve()`. They represent template boilerplate common in competitive programming setups.

## Terms

- **bufio:** A standard Go library providing buffered I/O wrappers around `io.Reader` and `io.Writer` to minimize operating system read/write system calls.
- **Prefix tree:** An $m$-ary tree where descendants of a node share a common string prefix.
