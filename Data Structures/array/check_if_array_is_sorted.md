## How it works

The program includes `<stdio.h>` for printing and `<stdbool.h>` for standard boolean types (`bool`, `true`, `false`).

The function `is_asorted` checks if an array is sorted in ascending order:
- It takes an array `arr[]` and its length `len`.
- It iterates using index `i` from `0` up to `len - 2`.
- Inside the loop, it checks if `arr[i] > arr[i + 1]`. If any element is strictly greater than its subsequent neighbor, the array is not ascending, so it returns `false` immediately.
- If the loop completes without finding an inversion, it returns `true`.

The function `is_dsorted` checks if an array is sorted in descending order:
- It iterates through index `i` from `0` up to `len - 2`.
- It checks if `arr[i] < arr[i + 1]`. If any element is strictly smaller than its following neighbor, it returns `false`.
- If no inversions occur, it returns `true`.

In `main`:
- Defines three test arrays: `arr` (sorted ascending: `1, 2, 3`), `brr` (sorted descending: `3, 2, 1`), and `crr` (unsorted: `1, 3, 2`).
- Runs `is_asorted` on `arr` and `brr`, printing the results.
- Runs `is_dsorted` on `brr` and `crr`, printing the results.
- Returns `0`.

## Key excerpt

```c
bool is_asorted(int arr[], int len) {
    for (int i = 0; i + 1 < len; i++) {
        if (arr[i] > arr[i + 1]) {
            return false;
        }
    }
    return true;
}

bool is_dsorted(int arr[], int len) {
    for (int i = 0; i + 1 < len; i++) {
        if (arr[i] < arr[i + 1]) {
            return false;
        }
    }
    return true;
}
```

## Things to watch

- **Loop boundary condition:** The loops use `i + 1 < len` (equivalent to `i < len - 1`). If `len` is `0` or `1`, the loop condition is immediately false and the functions return `true`, which correctly matches the mathematical definition that an empty or single-element collection is vacuously sorted.
- **Variable-length arrays in main:** The arrays in `main` are declared as `arr[lenA]`, `brr[lenB]`, and `crr[lenC]`. These are C99 variable-length arrays (VLAs), which are optional in C11 and unsupported on some compilers such as MSVC.

## Terms

- **Linear scan:** An algorithmic technique that inspects every element in a sequence one by one from start to finish.
- **Vacuously sorted:** A mathematical property where a sequence of length 0 or 1 is considered sorted because no pair of adjacent elements exists to violate ordering.
- **Early exit:** Returning from a function as soon as a definitive result is found without executing unnecessary remaining iterations.
