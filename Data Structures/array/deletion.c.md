## Overview

This program demonstrates how to delete an element at an arbitrary index from a contiguous array in C. Because static arrays do not dynamically shrink, deleting an element requires shifting all subsequent elements left by one position to overwrite the targeted index and decrementing the logical length. It illustrates two deletion methods: bulk memory shifting via `memmove` and a manual iterative `for` loop.

## How it works

The program includes `<stdio.h>` for console output and `<string.h>` for memory operations.

The helper function `print_array` prints all elements from index `0` to `len - 1` followed by a newline.

The function `delete` performs deletion at index `idx`:
- It takes the array `arr[]`, the index `idx` to remove, and a pointer `int* len` representing the active length.
- It invokes `memmove(&arr[idx], &arr[idx + 1], sizeof(int) * (*len - idx - 1))`. This shifts all elements from `idx + 1` up to the end of the array one position to the left, overwriting `arr[idx]`.
- It decrements `(*len)` so subsequent operations ignore the now-redundant final slot.

In `main`:
- Allocates an array `arr` with capacity `10` and length `10`, filled with values `1` through `10`.
- Deletes index `0` (the first element) and prints the array (now 9 elements: `2 3 4 5 6 7 8 9 10`).
- Deletes index `3` and prints the array (now 8 elements: `2 3 4 6 7 8 9 10`).
- Deletes the final element `len - 1` and prints the array (now 7 elements: `2 3 4 6 7 8 9`).
- Demonstrates manual loop shifting: sets `idx = 3`, loops from `i = idx` to `len - 2`, assigning `arr[i] = arr[i + 1]`, decrements `len`, and prints the remaining 6 elements (`2 3 4 7 8 9`).
- Returns `0`.

## Key excerpt

```c
void delete(int arr[], int idx, int* len) {
    // if (*len >= capacity) { return; }
    memmove(&arr[idx], &arr[idx + 1], sizeof(int) * (*len - idx - 1));
    (*len)--;
}
```

## Things to watch

- **Lack of bounds checking:** The `delete` function does not validate whether `idx >= 0` and `idx < *len`. If `idx >= *len`, the expression `*len - idx - 1` produces a negative value that underflows into a huge `size_t` when passed to `memmove`, leading to segmentation faults or buffer overflows.
- **Physical vs logical size:** Deleting an element does not free or erase memory in the stack buffer; the trailing element still exists physically in memory until overwritten. Only the logical counter `len` is decremented.

## Terms

- **memmove:** A standard C library function that safely copies a block of bytes between potentially overlapping memory regions.
- **Logical length:** The number of valid active elements currently recognized in a collection, as opposed to its total allocated capacity.
- **Left shift:** An operation that moves array elements toward index 0 to fill a gap created by deletion.
