## Overview

This program demonstrates how to delete an element at an arbitrary index from an integer slice in Go. In Go, slices are dynamic views over backing arrays, so deleting an element while maintaining order involves shifting subsequent elements left with the built-in `copy` function and trimming the slice length by one using a reslicing expression.

## How it works

The `main` function serves as the application entry point:
- Sets `n := 7` and creates an integer slice `arr := make([]int, n)`.
- Populates `arr` with values `1` through `7` using a `for` loop.
- Prints the initial slice: `[1 2 3 4 5 6 7]`.
- Sets `idx := 0` to target the first element for deletion.
- Calls `copy(arr[idx:], arr[idx+1:])`. The `copy` function shifts all elements from index `1` upwards one position to the left, overwriting `arr[0]`.
- Reslices `arr = arr[:n-1]`, reducing the length of the slice from 7 to 6.
- Prints the updated slice: `[2 3 4 5 6 7]`.

## Key excerpt

```go
func main() {
	// n elements
	n := 7
	arr := make([]int, n)

	for i := 0; i < n; i++ {
		arr[i] = i + 1
	}

	fmt.Println(arr)

	// deletion
	idx := 0
	copy(arr[idx:], arr[idx+1:]) // left shift
	arr = arr[:n-1]              // remove one room

	fmt.Println(arr)
}
```

## Things to watch

- **Memory retention on slices of pointers:** For integer slices, truncating the slice with `arr[:n-1]` leaves the old final value in the backing array, which causes no memory leak. However, if the slice contains pointers or references, the hidden trailing element in the backing array will prevent the referenced object from being garbage collected. In such cases, `arr[len(arr)-1] = nil` must be set before reslicing.
- **Slice capacity:** Truncating `arr[:n-1]` modifies `len(arr)` but leaves `cap(arr)` unchanged.

## Terms

- **Reslicing:** Creating a new slice descriptor that references a modified sub-range of the same underlying backing array.
- **Backing array:** The contiguous block of memory allocated by Go to hold elements displayed by a slice.
- **copy:** A built-in Go function that copies elements between slices up to `min(len(dst), len(src))`.
