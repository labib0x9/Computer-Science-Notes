## Overview

This program demonstrates how to insert a new element at an arbitrary index into a fixed-capacity contiguous array in C. Because arrays occupy fixed memory blocks, inserting an element requires verifying available capacity, shifting existing elements from the target index one position to the right, inserting the new value into the vacated slot, and incrementing the logical length. It illustrates both `memmove` and iterative reverse `for` loops.

## How it works

The program includes `<stdio.h>` for printing and `<string.h>` for memory operations.

The helper function `print_array` prints all active elements up to `len`.

The function `insert` handles insertion:
- Accepts `arr[]`, index `idx`, value `x`, length pointer `int* len`, and maximum `capacity`.
- Checks if `*len >= capacity`. If full, it exits early without modifying memory.
- Calls `memmove(&arr[idx + 1], &arr[idx], sizeof(int) * (*len - idx))`. This shifts all elements from `idx` onward one position to the right.
- Increments `(*len)`.
- Places the new value: `arr[idx] = x`.

In `main`:
- Allocates array `arr` with capacity `10` and initial length `5`, populated with `1, 2, 3, 4, 5`.
- Inserts `100` at index `0`: shifts everything right, resulting in `100 1 2 3 4 5` (len = 6).
- Inserts `200` at index `3`: shifts elements from index 3 right, resulting in `100 1 2 200 3 4 5` (len = 7).
- Inserts `300` at index `len - 1` (index 6): results in `100 1 2 200 3 4 300 5` (len = 8).
- Demonstrates manual reverse loop shifting: sets `idx = 3` and `x = 400`, loops backward `for (int i = len - 1; i >= idx; i--) arr[i + 1] = arr[i]`, inserts `arr[idx] = x`, increments `len`, and prints the final 9 elements (`100 1 2 400 200 3 4 300 5`).
- Returns `0`.

## Key excerpt

```c
void insert(int arr[], int idx, int x, int* len, int capacity) {
    if (*len >= capacity) { return; }
    memmove(&arr[idx + 1], &arr[idx], sizeof(int) * (*len - idx));
    (*len)++;
    arr[idx] = x;
}
```

## Things to watch

- **Reverse loop direction:** When shifting elements to the right manually, the loop must iterate backwards from `len - 1` down to `idx`. Iterating forward would overwrite subsequent elements before they are moved, corrupting the array.
- **Index validation:** The `insert` function checks `*len >= capacity`, but does not verify whether `idx < 0` or `idx > *len`. Passing an out-of-range index results in memory corruption.

## Terms

- **Capacity:** The total amount of allocated storage available in a buffer.
- **Right shift:** Moving array elements toward higher memory addresses to create space for an incoming element.
- **memmove:** A standard library function that safely copies memory blocks even when source and destination overlap.
