## Overview

This program provides a solution for LeetCode problem 905 ("Sort Array By Parity") in Go. Given an integer slice `nums`, it rearranges the elements in-place so that all even integers appear before all odd integers, operating in $O(n)$ time complexity using a converging two-pointer partition technique.

## How it works

The function `sortArrayByParity(nums []int) []int`:
- Initializes two pointer indices: `odd := 0` pointing to the start and `even := len(nums) - 1` pointing to the end.
- Executes `for odd < even`:
  - Enters a loop `for odd < even && nums[odd] & 1 == 0` that advances `odd` past any numbers that are already even.
  - Enters a loop `for odd < even && nums[even] & 1 != 0` that decrements `even` past any numbers that are already odd.
  - When `odd < even`, `nums[odd]` is odd and `nums[even]` is even, so it swaps them: `nums[odd], nums[even] = nums[even], nums[odd]`.
  - Increments `odd` by 1 and decrements `even` by 1.
- Returns the partitioned slice `nums`.

## Key excerpt

```go
func sortArrayByParity(nums []int) []int {
	odd, even := 0, len(nums)-1
	for odd < even {
		for odd < even && nums[odd]&1 == 0 {
			odd++
		}
		for odd < even && nums[even]&1 != 0 {
			even--
		}
		nums[odd], nums[even] = nums[even], nums[odd]
		odd, even = odd+1, even-1
	}
	return nums
}
```
