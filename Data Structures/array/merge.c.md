## Overview

This program demonstrates techniques for merging two distinct integer arrays into a single combined array in C. It illustrates two contrasting methods: an element-by-element assignment loop and a bulk binary copy using `memmove` from `<string.h>`. C programmers write array concatenation routines to understand manual memory layout, pointer offsets, and standard byte-copying primitives.

## How it works

The program includes `<stdio.h>` for console output and `<string.h>` for memory operations.

The helper function `print_array` accepts an integer array pointer `arr[]` and its length `len`. It iterates from `0` to `len - 1`, printing each integer separated by a space, followed by a trailing newline.

The `main` function executes the following sequence:
- Declares lengths `lenA = 3` and `lenB = 4`, and initializes two stack arrays: `arr[lenA]` and `brr[lenB]`.
- Populates `arr` with values `1, 2, 3` using a `for` loop, and `brr` with `4, 5, 6, 7` using an offset formula `i + lenA + 1`.
- Calls `print_array` on both arrays to display initial inputs.
- Implements loop-based merging:
  - Declares `merged_arr` of size `lenC = lenA + lenB` (7 elements).
  - Iterates through `arr` to copy elements into indices `0` through `lenA - 1`.
  - Iterates through `brr` to copy elements into indices `lenA` through `lenC - 1` using offset index `i + lenA`.
  - Calls `print_array` on `merged_arr`.
- Implements `memmove` based merging:
  - Declares an uninitialized array `drr[lenC]`.
  - Calls `memmove(&drr, &arr, sizeof(int) * lenA)` to copy the bytes of `arr` to the beginning of `drr`.
  - Calls `memmove(&drr[lenA], &brr, sizeof(int) * lenB)` to copy the bytes of `brr` directly following the first segment at offset `drr[lenA]`.
  - Calls `print_array` on `drr`.
- Returns `0`.

## Things to watch

- **Variable-Length Arrays (VLAs):** Declaring arrays with runtime dimensions (such as `int arr[lenA]`) is a C99 feature known as VLAs. While standard in C99, VLAs were made optional in C11 (under `__STDC_NO_VLA__`) and are unsupported by Microsoft Visual C++ (MSVC).
- **Pointer argument types in `memmove`:** Passing `&drr` and `&arr` evaluates to pointers to arrays (`int (*)[7]`) rather than pointers to elements (`int *`). While the numeric address is identical, standard C idiom is to pass `drr` and `arr` (which decay to `int *` compatible with `void *`).
- **Concatenation vs. Sorted Merge:** The program performs plain concatenation. It does not inspect values or maintain sorted ordering across elements (unlike its Go counterpart `merge.go`).

## Terms

- **memmove:** A standard library function in `<string.h>` that copies a specified number of bytes between memory buffers, safely handling overlapping memory regions.
- **Variable-Length Array (VLA):** An array whose dimension is determined at runtime on the call stack rather than as a compile-time constant.
- **Zero-based indexing:** An array addressing scheme where the first element is accessed at index offset 0.
