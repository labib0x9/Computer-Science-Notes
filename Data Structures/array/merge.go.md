## Overview

This program demonstrates two primary methods for combining data slices in Go: sequential concatenation using the built-in `copy` function, and a two-pointer merge algorithm that combines two pre-sorted slices into a single sorted result. Developers write these routines to practice slice manipulation and implement the merge step fundamental to algorithms like merge sort.

## How it works

The `main` function serves as the program entry point:
- Initializes two integer slices: `arr := []int{1, 3, 4}` and `brr := []int{2, 5, 7, 8}`.
- Measures the length of each slice with `len(arr)` (`n = 3`) and `len(brr)` (`m = 4`).
- Allocates a destination slice `crr` of length `N = n + m` (7) using `make([]int, N)`.
- Demonstrates slice concatenation:
  - Invokes `copy(crr, arr)`, copying the 3 elements of `arr` into indices `0` through `2` of `crr`.
  - Invokes `copy(crr[n:], brr)`, copying the 4 elements of `brr` into the subslice of `crr` beginning at index `n` (indices `3` through `6`).
  - Prints the concatenated slice: `[1 3 4 2 5 7 8]`.
- Demonstrates sorted two-pointer merge:
  - Initializes index pointers `i = 0` (for `arr`), `j = 0` (for `brr`), and `idx = 0` (for `crr`).
  - Evaluates `for i < n && j < m`: in each iteration, compares `arr[i]` with `brr[j]`. The smaller value is assigned to `crr[idx]`, and the corresponding pointer along with `idx` is incremented by 1.
  - Flushes any remaining elements from `arr` into `crr` using `for i < n`.
  - Flushes any remaining elements from `brr` into `crr` using `for j < m`.
  - Prints the sorted merged slice: `[1 2 3 4 5 7 8]`.

## Key excerpt

```go
	// copy one array entirely
	for i < n && j < m {
		if arr[i] < brr[j] {
			crr[idx] = arr[i]
			i, idx = i+1, idx+1
		} else {
			crr[idx] = brr[j]
			j, idx = j+1, idx+1
		}
	}

	// if arr remains
	for i < n {
		crr[idx] = arr[i]
		i, idx = i+1, idx+1
	}

	// if brr remains
	for j < m {
		crr[idx] = brr[j]
		j, idx = j+1, idx+1
	}

	fmt.Println(crr)
```

## Things to watch

- **In-place buffer overwriting:** The two-pointer merge algorithm reuses the slice `crr` previously populated by the concatenation step without zeroing it out. This is safe only because the merge algorithm is guaranteed to write to every index from `0` to `N - 1`.
- **Pre-sorted assumption:** The two-pointer merge algorithm assumes both input slices are strictly sorted in ascending order. If either input slice is unsorted, the resulting merged slice will not maintain sorted order.

## Terms

- **Slice:** A dynamically-sized, flexible view into the elements of an underlying array in Go.
- **copy:** A built-in Go function that copies elements from a source slice to a destination slice up to the minimum of their lengths.
- **Two-pointer technique:** An algorithmic approach using multiple index variables to traverse sequences concurrently with linear time complexity.
