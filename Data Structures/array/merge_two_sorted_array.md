## Overview

This program implements the classic two-pointer algorithm to merge two pre-sorted arrays of integers into a single combined sorted array in C. This procedure is fundamental in computer science as the "merge" step of the $O(n \log n)$ Merge Sort algorithm. It demonstrates how to achieve linear $O(n + m)$ runtime without requiring additional sorting comparisons.

## How it works

The program includes `<stdio.h>` for printing and `<string.h>` for utility functions.

The helper function `print_array` prints the elements of an array separated by spaces.

In `main`:
- Initializes sorted array `arr` with 3 elements (`{1, 4, 6}`) and sorted array `brr` with 4 elements (`{2, 3, 4, 5}`).
- Displays both source arrays using `print_array`.
- Declares three pointer indices initialized to 0: `ptr_a` for `arr`, `ptr_b` for `brr`, and `ptr_idx` for the destination array `merged_arr`.
- Declares `merged_arr` of size `lenA + lenB` (7 elements).
- Executes the main comparison loop: `while (ptr_a < lenA && ptr_b < lenB)`. On each iteration, it compares `arr[ptr_a]` with `brr[ptr_b]`. The smaller element is copied to `merged_arr[ptr_idx++]`, and the pointer of the selected array is incremented.
- Executes two cleanup `while` loops:
  - `while (ptr_a < lenA)` flushes any remaining elements from `arr` into `merged_arr`.
  - `while (ptr_b < lenB)` flushes any remaining elements from `brr` into `merged_arr`.
- Prints the merged result: `1 2 3 4 4 5 6`.
- Returns `0`.

## Key excerpt

```c
    while (ptr_a < lenA && ptr_b < lenB) {
        if (arr[ptr_a] < brr[ptr_b]) merged_arr[ptr_idx++] = arr[ptr_a++];
        else merged_arr[ptr_idx++] = brr[ptr_b++];
    }

    // if arr didn't finish
    while (ptr_a < lenA) merged_arr[ptr_idx++] = arr[ptr_a++];

    // if brr didn't finish
    while (ptr_b < lenB) merged_arr[ptr_idx++] = brr[ptr_b++];

    print_array(merged_arr, lenA + lenB);
```

## Things to watch

- **Pre-condition of sorted inputs:** The algorithm strictly depends on both input arrays being sorted in ascending order beforehand. If either array is unsorted, the merged result will be incorrect.
- **C99 VLA allocation:** `int merged_arr[lenA + lenB]` is a Variable-Length Array allocated on the call stack. For massive inputs, allocating large VLAs on the stack risks stack overflow; heap allocation via `malloc` would be safer for arbitrarily large arrays.

## Terms

- **Two-pointer technique:** An algorithm pattern maintaining two independent index markers that advance through collections based on comparative logic.
- **Merge step:** The phase in merge sort where two sorted subsequences are combined into a single sorted list in $O(n)$ time.
- **Stack overflow:** An error condition caused by exhausting the allocated memory space of the program call stack.
