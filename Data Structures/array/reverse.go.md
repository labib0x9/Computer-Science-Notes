## Overview

This program demonstrates in-place reversal of an integer slice in Go. It pairs a two-pointer converging loop with the bitwise XOR swap trick, swapping elements from the outside inward until the pointers cross.

## How it works

The `main` function serves as the application entry point:
- Sets `n := 7` and allocates a slice `arr := make([]int, n)`.
- Populates `arr` with values `1` through `7`.
- Prints the initial slice: `[1 2 3 4 5 6 7]`.
- Initializes two index pointers: `lo := 0` at the start and `hi := n - 1` at the end.
- Executes `for lo < hi`:
  - Swaps `arr[lo]` and `arr[hi]` using three XOR steps:
    - `arr[lo] ^= arr[hi]`
    - `arr[hi] ^= arr[lo]`
    - `arr[lo] ^= arr[hi]`
  - Increments `lo` by 1 and decrements `hi` by 1.
- Prints the reversed slice: `[7 6 5 4 3 2 1]`.

## Key excerpt

```go
func main() {
	// n elements
	n := 7
	arr := make([]int, n)

	for i := 0; i < n; i++ {
		arr[i] = i + 1
	}

	fmt.Println(arr)

	// two pointer reverse
	lo, hi := 0, n-1
	for lo < hi {
		arr[lo] ^= arr[hi]
		arr[hi] ^= arr[lo]
		arr[lo] ^= arr[hi]

		lo++
		hi--
	}

	fmt.Println(arr)
}
```

## Things to watch

- **Idiomatic Go swapping:** In Go, the idiomatic way to swap slice elements is tuple assignment: `arr[lo], arr[hi] = arr[hi], arr[lo]`. This is cleaner, less error-prone, and enables compiler optimizations.
- **Safe loop bound:** The condition `lo < hi` terminates before `lo == hi` when the slice length is odd, ensuring the center element is never XOR-swapped with itself.

## Terms

- **Bitwise XOR (^):** An operator that returns 1 for each bit position where only one of the corresponding operand bits is 1.
- **In-place algorithm:** An algorithm that transforms input data without allocating additional auxiliary memory proportional to the input size.
