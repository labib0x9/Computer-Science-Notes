## Overview

This program demonstrates techniques for rotating the elements of an array circularly to the left and to the right in C. It illustrates two contrasting strategies: single-position shifting where an edge element is saved into a temporary variable while remaining elements shift sequentially, and arbitrary $k$-step rotation using modulo index mapping into a secondary buffer.

## How it works

The program includes `<stdio.h>` and defines `print_array` to format output.

In `main`:
- Initializes array `arr` with 5 elements: `1, 2, 3, 4, 5`. Prints `arr`.
- Left-rotation by 1:
  - Stores `temp = arr[0]`.
  - Loops `for (int i = 0; i + 1 < n; i++) arr[i] = arr[i + 1]`.
  - Assigns `arr[n - 1] = temp`.
  - Prints: `2 3 4 5 1`.
- Right-rotation by 1:
  - Stores `temp = arr[n - 1]`.
  - Loops backward `for (int i = n - 1; i - 1 >= 0; i--) arr[i] = arr[i - 1]`.
  - Assigns `arr[0] = temp`.
  - Prints: `1 2 3 4 5` (restoring original order).
- Arbitrary left-rotation using modulo:
  - Sets `k = 1`. Declares auxiliary array `ans[n]`.
  - Maps `ans[i] = arr[(i + k + n) % n]`.
  - Prints `ans`: `2 3 4 5 1`.
  - Copies `ans` back into `arr`.
- Arbitrary right-rotation using modulo:
  - Maps `ans[i] = arr[(i - k + n) % n]`. Adding `n` ensures the dividend is positive before applying `% n`.
  - Prints `ans`: `1 2 3 4 5`.
- Returns `0`.

## Things to watch

- **Negative modulo behavior in C:** In C (C99 and later), the `%` operator computes truncated remainder. If the left operand is negative (such as `i - k` when `i < k`), `(i - k) % n` yields a negative remainder. Writing `(i - k + n) % n` adds `n` to guarantee a non-negative dividend.
- **GNU extension syntax:** The syntax `int ans[n] = {};` initializes a variable-length array with an empty initializer list. In ISO C99, initializing a VLA with `{}` is not permitted, though it is supported as a GNU extension in GCC and Clang.
- **Invalid statement:** Line 42 contains `ans[n] = {};` which attempts to assign an initializer list to an out-of-bounds array element index `n`. GCC/Clang may warn or error on this line under strict ISO C conformance (`-pedantic -std=c99`).

## Terms

- **Circular rotation:** Shifting elements along an array such that elements that fall off one end wrap around to reappear at the opposite end.
- **Truncated division:** Division that rounds toward zero, resulting in negative remainders when negative dividends are evaluated with `%`.
