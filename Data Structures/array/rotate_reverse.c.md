## Overview

This program implements the optimal three-reversal algorithm for rotating an array by $k$ positions in C. Unlike shift-and-rotate approaches that require $O(n \times k)$ operations or modulo methods that require $O(n)$ auxiliary buffer memory, the reversal algorithm operates in strictly $O(n)$ time complexity and $O(1)$ auxiliary space.

## Key excerpt

```c
void reverse_array(int arr[], int l, int r) {
    for (int i = 0; i < (r - l + 1) / 2; i++) {
        int temp = arr[l + i];
        arr[l + i] = arr[r - i];
        arr[r - i] = temp;
    }
}

int main() {

    int n = 5, k = 3;
    int arr[] = {1, 2, 3, 4, 5};

    print_array(arr, n);

    // Left - Rotation
    reverse_array(arr, 0, k - 1);
    reverse_array(arr, k, n - 1);
    reverse_array(arr, 0, n - 1);

    print_array(arr, n);
```

## Things to watch

- **Constraint on $k$:** The code assumes $0 \le k \le n$. If $k > n$, calling `reverse_array(arr, 0, k - 1)` causes out-of-bounds memory access. In robust production code, $k$ must be normalized with `k = k % n`.
- **Right rotation continuity:** In `main()`, the right-rotation is performed directly on the array after it was already left-rotated by 3. Because left-rotating by 3 and subsequently right-rotating by 3 are inverse operations, the final output returns to the original sequence `1 2 3 4 5`.

## Terms

- **Three-reversal algorithm:** A technique to rotate a sequence of elements by reversing two distinct sub-segments followed by a reversal of the entire collection.
- **In-place rotation:** Rearranging sequence elements without allocating secondary arrays.
