## Overview

This program demonstrates in-place rotation of an integer slice by $k$ positions using the three-reversal algorithm in Go. Operating in $O(n)$ time and $O(1)$ auxiliary memory, it avoids additional slice allocations by performing element-level reversals with bitwise XOR swaps.

## How it works

The function `reverse_array(arr []int, lo int, hi int)`:
- Takes a slice `arr` and bounds `lo` and `hi`.
- Loops `for lo < hi`:
  - Swaps `arr[lo]` and `arr[hi]` via bitwise XOR:
    - `arr[lo] ^= arr[hi]`
    - `arr[hi] ^= arr[lo]`
    - `arr[lo] ^= arr[hi]`
  - Advances `lo = lo + 1` and `hi = hi - 1`.

In `main`:
- Initializes slice `arr := []int{1, 2, 3, 4, 5}`, `n = 5`, and `k = 3`.
- Left-rotation by $k = 3$:
  - Reverses slice from `0` to `k - 1` (`0` to `2`): `[3, 2, 1, 4, 5]`.
  - Reverses slice from `k` to `n - 1` (`3` to `4`): `[3, 2, 1, 5, 4]`.
  - Reverses full slice from `0` to `n - 1` (`0` to `4`): `[4, 5, 1, 2, 3]`.
  - Prints: `[4, 5, 1, 2, 3]`.
- Right-rotation by $k = 3$:
  - Reverses slice from `0` to `n - k - 1` (`0` to `1`): `[5, 4, 1, 2, 3]`.
  - Reverses slice from `n - k` to `n - 1` (`2` to `4`): `[5, 4, 3, 2, 1]`.
  - Reverses full slice from `0` to `n - 1` (`0` to `4`): `[1, 2, 3, 4, 5]`.
  - Prints: `[1, 2, 3, 4, 5]`.

## Key excerpt

```go
func reverse_array(arr []int, lo int, hi int) {
	for lo < hi {
		arr[lo] ^= arr[hi]
		arr[hi] ^= arr[lo]
		arr[lo] ^= arr[hi]
		lo, hi = lo+1, hi-1
	}
}

func main() {
	arr := []int{1, 2, 3, 4, 5}
	n, k := len(arr), 3
	// Left - Rotatioin
	reverse_array(arr, 0, k-1)
	reverse_array(arr, k, n-1)
	reverse_array(arr, 0, n-1)
	fmt.Println(arr)

	// Right - Rotation
	reverse_array(arr, 0, n - k - 1)
	reverse_array(arr, n - k, n - 1)
	reverse_array(arr, 0, n - 1)
	fmt.Println(arr)
}
```

## Things to watch

- **Sequential mutations:** The right rotation is applied directly to the slice after it was already left-rotated by 3, returning it back to its original configuration `[1, 2, 3, 4, 5]`.
- **Value of $k$:** If $k > n$, index expressions like `k - 1` trigger panic index out of range. A safety guard `k = k % n` is recommended.

## Terms

- **Reversal rotation:** An algorithm that performs three reverse operations on partitions to rotate elements with zero memory overhead.
- **Panic:** A runtime error in Go triggered when operations violate memory safety (such as indexing beyond slice bounds).
