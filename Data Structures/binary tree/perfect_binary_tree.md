## Overview

This program demonstrates the dynamic generation and hierarchical traversal of a perfect binary tree in C. A perfect binary tree is a binary tree in which all interior nodes have two children and all leaf nodes reside at the same depth. The program recursively allocates tree nodes on the heap, prints the tree structure indented by depth, and performs a clean recursive deallocation.

## How it works

The program includes `<stdio.h>`, `<stdlib.h>`, `<string.h>`, `<stdbool.h>`, and `<math.h>`.

A struct `node` defines each tree node: an integer `val`, a pointer `left` to the left child, and a pointer `right` to the right child.

The constructor function `new_node(int val)` allocates a `node` using `malloc`, initializes its value, sets both child pointers to `NULL`, and returns the pointer.

Global variables:
- `depth`: defines the maximum depth (0-indexed).
- `NowAt`: a counter that assigns unique sequential integers to created nodes.

The function `create_tree(node* root, int d)`:
- Recursively populates children until `d == depth`.
- Allocates a new node with value `++NowAt` and assigns it to `root->left`, then recurses with `create_tree(root->left, d + 1)`.
- Allocates a new node with value `++NowAt` and assigns it to `root->right`, then recurses with `create_tree(root->right, d + 1)`.

The function `visit_tree(node* root, int d)`:
- Prints tab indentation proportional to depth `d`, followed by `root->val`.
- Stops recursing when `d == depth`.
- Recursively visits `root->left` and `root->right`.

The function `free_tree(node* cur)`:
- Recursively frees children in post-order (`left`, then `right`, then `cur`) to avoid dangling pointers and memory leaks.

In `main`:
- Sets `depth = 2`.
- Creates root node with `new_node(++NowAt)`.
- Calls `create_tree(root, 0)` to build depth 0, 1, and 2 (total 7 nodes: $2^{2+1}-1$).
- Calls `visit_tree(root, 0)` to print the tree hierarchy.
- Calls `free_tree(root)` to deallocate memory, and returns 0.

## Key excerpt

```c
void create_tree(node* root, int d) {
	if (d == depth) {
		return;
	}

	node* nnode;
	nnode = new_node(++NowAt);
	root->left = nnode;
	create_tree(root->left, d + 1);

	nnode = new_node(++NowAt);
	root->right = nnode;
	create_tree(root->right, d + 1);
}
```

## Things to watch

- **Global state dependency:** The functions rely on mutable global variables `depth` and `NowAt`. In multi-threaded programs or reusable libraries, this pattern causes race conditions and lacks reentrancy.
- **Unchecked malloc return in tree creation:** `new_node` checks for `NULL`, but `create_tree` does not verify if `new_node` returned `NULL` before dereferencing `root->left`, which could cause a segmentation fault if memory allocation fails.

## Terms

- **Perfect Binary Tree:** A binary tree in which every internal node has exactly two children and all leaf nodes reside at identical depth.
- **Post-order traversal:** Traversing child subtrees before processing or freeing the current node.
