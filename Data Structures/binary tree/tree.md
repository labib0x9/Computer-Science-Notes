## Overview

This program demonstrates how to generate a binary tree in C where node creation is constrained both by a maximum depth limit and a total node count $N$. By placing bounds on the global node allocation counter, it creates an incomplete binary tree and displays its structure using depth-based tab indentation before freeing all allocated memory.

## How it works

The program includes standard headers `<stdio.h>`, `<stdlib.h>`, and `<math.h>`.

A struct `node` defines binary tree nodes containing an integer `val` and pointers `left` and `right`.

The constructor `new_node(int val)` allocates a `node` via `malloc`, setting both child pointers to `NULL`.

Global variables:
- `N`: total maximum number of nodes permitted.
- `depth`: maximum depth constraint.
- `NowAt`: counter tracking the index of the latest allocated node.

The function `create_tree(node* root, int d)`:
- Returns if `d == depth`.
- If `NowAt < N`, allocates a left child with `++NowAt`, links it to `root->left`, and recurses into `create_tree(root->left, d + 1)`.
- If `NowAt < N`, allocates a right child with `++NowAt`, links it to `root->right`, and recurses into `create_tree(root->right, d + 1)`.

The function `visit_tree(node* root, int d)`:
- Formats and prints `root->val` indented by `d` tabs.
- Recurses into existing left and right children up to `depth`.

The function `free_tree(node* cur)`:
- Recursively frees `cur->left`, `cur->right`, and `cur`.

In `main`:
- Sets `N = 5` and `depth = 2`.
- Allocates root node with value 1 (`NowAt = 1`).
- Calls `create_tree(root, 0)`. The tree allocates nodes 2, 3, 4 under node 2, then node 5 under root's right child, reaching $N = 5$.
- Calls `visit_tree(root, 0)` and `free_tree(root)`.
- Returns 0.

## Key excerpt

```c
void create_tree(node* root, int d) {
	if (d == depth) {
		return;
	}

	node* nnode;
	if (NowAt < N) { // remove this condition and you will get perfect binary tree..
		nnode = new_node(++NowAt);
		root->left = nnode;
		create_tree(root->left, d + 1);
	}

	if (NowAt < N) {
		nnode = new_node(++NowAt);
		root->right = nnode;
		create_tree(root->right, d + 1);
	}
}
```

## Things to watch

- **Asymmetric tree topology:** Because `NowAt < N` checks sequential node creation, the left subtree is fully expanded before any nodes are allocated in the right subtree, resulting in an unbalanced tree.
- **Global state coupling:** The recursion relies on globals `N`, `depth`, and `NowAt`.

## Terms

- **Depth:** The distance of a node from the root node in terms of edge count.
