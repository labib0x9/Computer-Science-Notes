## Overview

This program demonstrates a fixed-capacity circular queue (ring buffer) implementation in C using a static array. A circular queue connects the end of the array back to the beginning using modulo arithmetic, enabling constant time $O(1)$ enqueue (`push`) and dequeue (`pop`) operations without shifting elements.

## How it works

The file declares global variables:
- `FIXED_QUEUE_ELEM = 10`: maximum capacity.
- `queue[FIXED_QUEUE_ELEM]`: underlying integer storage array.
- `insertAt = 0`: pointer index where next pushed item is written.
- `readAt = 0`: pointer index where next popped item is read.
- `count = 0`: number of active elements in the queue.

Functions:
- `isEmpty()`: returns true if `count == 0`.
- `isFull()`: returns true if `count == FIXED_QUEUE_ELEM`.
- `push(int val)`: checks `if (isFull())`, prints `"QUEUE FULL"` and returns 0. Otherwise, writes `val` to `queue[insertAt]`, advances `insertAt = (insertAt + 1) % FIXED_QUEUE_ELEM`, increments `count`, and returns 1.
- `pop()`: checks `if (isEmpty())`, prints `"EMPTY -> QUEUE"` and returns -1. Otherwise, reads `queue[readAt]`, advances `readAt = (readAt + 1) % FIXED_QUEUE_ELEM`, decrements `count`, and returns the value.
- `print()`: iterates `i` from 0 to `count - 1`, printing `queue[(i + readAt) % FIXED_QUEUE_ELEM]`.

## Key excerpt

```c
char push(int val) {
  if(isFull()) {
   printf("QUEUE FULL
");
   return 0;
  }
  queue[insertAt] = val;
  insertAt = (insertAt + 1) % FIXED_QUEUE_ELEM;
  count++;
  return 1;
}

int pop() {
   if (isEmpty()) {
      printf("EMPTY -> QUEUE
");
      return -1;
   }
   int x = queue[readAt];
   readAt = (readAt + 1) % FIXED_QUEUE_ELEM;
   count--;
   return x;
}
```

## Things to watch

- **Missing main function:** The file provides data structure functions only, serving as a modular implementation snippet.
- **Sentinel value ambiguity:** `pop()` returns `-1` to indicate an empty queue. If the queue legitimately stores the value `-1`, the caller cannot distinguish between a valid stored value and an error condition.
- **Global non-reentrant state:** Uses global variables, making it thread-unsafe and restricting the program to a single queue instance.

## Terms

- **Circular Queue:** A FIFO queue implemented in a fixed buffer where the last position wraps around to the first position.
- **FIFO:** First-In, First-Out, where the first element added is the first element removed.
