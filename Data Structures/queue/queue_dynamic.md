## Overview

This program implements a dynamically resizing circular queue (ring buffer) in C. When the queue reaches full capacity during a `push` operation, it doubles its allocated heap capacity, reorders the existing wrapped elements linearly into the new buffer, updates index pointers, and frees the previous allocation.

## How it works

The struct `queue` defines the queue state:
- `int* q`: dynamically allocated array buffer.
- `int cap`: total allocated capacity.
- `int len`: current element count.
- `int readAt, insertAt`: read and insert offsets.

Functions:
- `init_queue(queue* q)`: sets `cap = 1`, `len = 0`, `readAt = insertAt = 0`, and allocates `q->q` via `malloc(sizeof(int) * q->cap)`.
- `isFull(queue* q)`: returns `q->len == q->cap`.
- `isEmpty(queue* q)`: returns `q->len == 0`.
- `resize(queue* q)`: doubles capacity (`newCap = 2 * q->cap`), allocates `newQ`, copies elements sequentially using `newQ[i] = q->q[(q->readAt + i) % q->cap]`, frees old buffer `q->q`, and resets `insertAt = q->len` and `readAt = 0`.
- `push(queue* q, int val)`: calls `resize(q)` if full, writes `val` at `q->insertAt`, advances `insertAt = (insertAt + 1) % q->cap`, and increments `len`.
- `pop(queue* q, int *val)`: returns `false` if empty. Otherwise writes item into `*val`, advances `readAt`, decrements `len`, and returns `true`.
- `free_queue(queue* q)`: frees `q->q` and `q`.

## Key excerpt

```c
bool resize(queue* q) {
   if (!isFull(q)) {
      return false;
   }

   // resize by double of capacity
   int newCap = 2 * q->cap;
   int* newQ = (int*) malloc(sizeof(int) * newCap);   // how can i use realloc() ??
   if (newQ == NULL) {
      return false;
   }

   // move elements
   // well, here % is a costly operation, can i use memmove() ??
   for (int i = 0; i < q->len; i++) {
      newQ[i] = q->q[(q->readAt + i) % q->cap];
   }

   // update
   free(q->q);
   q->q = newQ;
   q->cap = newCap;
   q->insertAt = q->len;
   q->readAt = 0;

   return true;
}
```

## Things to watch

- **free_queue memory assumption:** `free_queue` calls `free(q->q)` and then `free(q)`. If `q` was declared as a local stack variable (`queue q; init_queue(&q);`), calling `free(q)` attempts to free stack memory, causing undefined behavior or crash.

## Terms

- **Geometric resizing:** Doubling capacity on exhaustion to ensure amortized $O(1)$ insertion time.
- **Normalization:** Flattening wrapped circular queue elements into a contiguous 0-indexed sequence during reallocation.
