## Overview

This program implements a FIFO queue using a singly-linked list in C. By maintaining both `head` and `tail` pointers, the queue supports $O(1)$ constant time operations: items are enqueued (`push`) at the tail and dequeued (`pop`) from the head. Dynamic node allocation allows the queue to grow unbounded without requiring reallocation or copying.

## How it works

The struct `node` defines linked list elements containing integer `val` and pointer `next`.

The struct `queue` contains pointers `head` (front of queue) and `tail` (rear of queue).

Functions:
- `init_queue()`: allocates a `queue` struct on the heap, initializes `head = tail = NULL`, and returns the pointer.
- `push(queue* q, int val)`: allocates a new `node`. If the queue is empty (`head == NULL`), both `head` and `tail` point to the new node. Otherwise, links `tail->next = newNode` and updates `tail = newNode`.
- `pop(queue* q)`: returns `-1` if empty. Otherwise, saves `val = q->head->val`, captures `next = q->head->next`, frees the former head node with `free(q->head)`, and updates `q->head = next`. If `head` becomes `NULL`, sets `tail = NULL`.
- `peek(queue* q)`: returns `q->head->val` without removing the node.
- `free_queue(queue* q)`: iterates through all remaining nodes freeing each, then frees `q`.

In `main`:
- Initializes queue with `init_queue()`.
- Pushes `10`, `20`, `111`.
- Calls `pop()` four times: prints `10`, `20`, `111`, and `-1` (on empty queue).
- Pushes `100`, `210`.
- Calls `pop()` twice: prints `100`, `210`.
- Deallocates with `free_queue(q)` and returns 0.

## Key excerpt

```c
bool push(queue* q, int val) {
   // new node
   node* newNode = (node*) malloc(sizeof(node));
   if (newNode == NULL) {  // malloc fails
      return false;
   }
   newNode->val = val;
   newNode->next = NULL;

   // first node..
   if(q->head == NULL) {
      q->head = newNode;
      q->tail = newNode;
      return true;
   }

   // chain with prev node ..
   q->tail->next = newNode;
   q->tail = newNode;
   return true;
}
```

## Things to watch

- **Sentinel return value on empty queue:** `pop()` and `peek()` return `-1` when the queue is empty. If `-1` is stored as a valid queue element, the caller cannot determine if the return value represents data or an empty queue.
- **Allocation overhead:** Every `push` performs an individual `malloc` and every `pop` calls `free`. While this allows unbounded growth, it introduces pointer chasing and memory fragmentation compared to contiguous circular buffers.

## Terms

- **Singly-linked list:** A linear data structure where each node stores a data value and a pointer to the next node in sequence.
- **Head and tail pointers:** Pointers maintained to provide immediate access to the beginning and end of a sequence.
