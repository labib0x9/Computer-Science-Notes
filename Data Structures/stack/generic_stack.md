## Overview

This program demonstrates how to implement a generic dynamically resizing stack in C by storing untyped `void*` pointers. Storing `void*` enables a single stack implementation to hold any data type (integers, floats, structs, strings) by taking references to objects, accompanied by dynamic capacity doubling when the stack fills up.

## How it works

The program includes `<stdio.h>`, `<stdlib.h>`, `<string.h>`, and `<stdbool.h>`.

The struct `stack` defines the data structure:
- `void** data`: array of `void*` pointers.
- `int len`: current number of elements.
- `int cap`: allocated capacity.

Functions:
- `newStack(int cap)`: initializes capacity (defaulting to 1 if passed 0), allocates `stack`, allocates `data` array of size `sizeof(void*) * cap`, and returns the stack pointer.
- `isEmpty(stack* st)`: checks if `st->len == 0`.
- `isFull(stack* st)`: checks if `st->len == st->cap`.
- `resize(stack* st)`: doubles capacity (`st->cap += st->cap`), calls `realloc(st->data, sizeof(void*) * st->cap)`, updating `st->data`. If allocation fails, restores original capacity and returns `false`.
- `push(stack* st, void* x)`: resizes if full, assigns `st->data[st->len++] = x`.
- `pop(stack* st)`: returns `NULL` if empty, otherwise returns `st->data[--st->len]`.
- `printStack(stack* st)`: iterates and prints elements by casting them to `*(int*)`.
- `freeStack(stack* st)`: frees `st->data` and `st`.

In `main`:
- Creates stack `st = newStack(0)`.
- Pushes stack pointer `&arr[0]`.
- Allocates heap integer `x` via `malloc`, sets `*x = 30`, and pushes `x`.
- Pops and prints top item: `*(int*) pop(st)` prints `30`.
- Calls `printStack(st)`: prints `10`.
- Calls `freeStack(st)` and frees heap integer `free(x)`.
- Returns `0`.

## Key excerpt

```c
typedef struct GStack {
	void** data;
	int len;
	int cap;
} stack;

bool resize(stack* st) {
	st->cap += st->cap;	// resize by double
	void** data = (void**) realloc(st->data, sizeof(void*) * st->cap);
	if (data == NULL) {
		st->cap /= 2;
		return false;
	}
	st->data = data;
	return true;
}

bool push(stack* st, void* x) {
	if (isFull(st)) {
		if (!resize(st)) return false;
	}
	st->data[st->len] = x;
	st->len++;
	return true;
}
```

## Things to watch

- **Memory ownership and lifetimes:** The stack stores raw pointers (`void*`). `freeStack` only frees the pointer array `st->data`, not the objects pointed to. The caller remains responsible for freeing any heap memory pushed onto the stack. Pushing stack pointers to local variables that leave scope leads to dangling pointers.
- **Type safety absence:** Storing `void*` eliminates compile-time type checking. `printStack` blindly casts items to `*(int*)`, which triggers undefined behavior or corrupt output if non-integer data is pushed.

## Terms

- **void pointer (`void*`):** A generic pointer type in C that can hold the address of any data type without type information.
- **LIFO:** Last-In, First-Out, where the most recently added item is the first one removed.
