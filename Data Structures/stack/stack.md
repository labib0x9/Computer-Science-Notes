## Overview

This program implements a dynamically resizing integer stack in C. It encapsulates dynamic memory management using `malloc` and `realloc`, doubling capacity whenever the stack becomes full. It provides standard stack operations: `push`, `pop`, `isEmpty`, `isFull`, and diagnostic printing.

## How it works

The struct `stack` encapsulates:
- `int* data`: dynamic array of integers.
- `int len`: current element count.
- `int cap`: allocated capacity.

Functions:
- `newStack(int cap)`: initializes capacity (defaulting to 1 if passed 0), allocates the `stack` struct, allocates `data` with `malloc(sizeof(int) * cap)`, sets `len = 0`, and returns the stack.
- `isEmpty(stack* st)`: returns `st->len == 0`.
- `isFull(stack* st)`: returns `st->len == st->cap`.
- `resize(stack* st)`: doubles capacity, calls `realloc(st->data, sizeof(int) * st->cap)`. If reallocation fails, it restores `st->cap /= 2` and returns `false`.
- `push(stack* st, int x)`: calls `resize` if full, then appends `st->data[st->len++] = x`.
- `pop(stack* st)`: returns `-1` if empty, otherwise returns `st->data[--st->len]`.
- `printStack(stack* st)`: prints all active elements separated by spaces.
- `freeStack(stack* st)`: frees `st->data` and `st`.

In `main`:
- Allocates `newStack(0)`.
- Pushes `10, 20, 30`.
- Pops twice: prints `30` and `20`.
- Pushes `40, 50`.
- Pops once: prints `50`.
- Pushes `60`.
- Pops once: prints `60`.
- Calls `printStack(st)`: remaining items are `10 40`.
- Pops twice: empties the stack.
- Calls `printStack(st)`: outputs blank line.
- Calls `pop(st)` on empty stack: prints `-1`.
- Calls `freeStack(st)` and returns 0.

## Key excerpt

```c
bool resize(stack* st) {
	st->cap += st->cap;	// resize by double
	int* data = (int*) realloc(st->data, sizeof(int) * st->cap);
	if (data == NULL) {
		st->cap /= 2;
		return false;
	}
	st->data = data;
	return true;
}

bool push(stack* st, int x) {
	if (isFull(st)) { 
		if (!resize(st)) return false;
	}
	st->data[st->len] = x;
	st->len++;
	return true;
}
```

## Things to watch

- **Sentinel ambiguity:** `pop()` returns `-1` when the stack is empty. If `-1` is stored as a valid integer in the stack, the caller cannot distinguish between valid data and stack underflow.
- **Realloc safety pattern:** The `resize` function assigns `realloc` results to a temporary pointer `int* data` before overwriting `st->data`, ensuring that if `realloc` fails, the existing memory is not leaked.

## Terms

- **LIFO:** Last-In, First-Out access order.
- **Amortized analysis:** Demonstrating that while an individual `push` requiring `resize` takes $O(n)$ time, the average cost per `push` across a sequence of operations is $O(1)$.
