## Overview

This program demonstrates procedure calls (`call` and `ret`) and console I/O in 16-bit MS-DOS assembly for the Intel 8086 microprocessor. It defines a reusable procedure `print_msg` to output `$`-terminated strings via DOS interrupt `21h` function `09h`, prompts the user for a single character via function `01h`, and echos the character and newlines back to the screen.

## How it works

The directives `.MODEL SMALL` and `.STACK 100H` define the memory model and allocate 256 bytes for stack frames.

The `.DATA` segment defines:
- `num1Msg db "A [0-255]: $"`: prompt string.
- `newLine db 0Dh, 0Ah, "$"`: carriage return (`0Dh`), line feed (`0Ah`), and `$` terminator.
- `num1 db ?, "$"`: a two-byte sequence containing an uninitialized byte for the character and a `$` delimiter so it can be printed directly via string output.

In the `.CODE` segment:
- `main proc`:
  - Initializes data segment: `mov ax, @data; mov ds, ax`.
  - Prompts user: loads `offset num1Msg` into `dx` and executes `call print_msg`.
  - Reads character: sets `ah = 1` and calls `int 21h`. DOS reads a character from standard input, echoes it to screen, and stores the ASCII value in `al`.
  - Stores the character: `mov num1, al`.
  - Prints newline: loads `offset newLine` into `dx` and calls `print_msg`.
  - Prints character: loads `offset num1` into `dx` and calls `print_msg`.
  - Exits program: sets `ah = 4ch` and calls `int 21h`.
- `print_msg proc`:
  - Sets `ah = 9` (print string service), invokes `int 21h`, and executes `ret` to pop the return address off the stack and jump back to the caller.

## Key excerpt

```asm
main proc
    ; load ds
    mov ax, @data
    mov ds, ax

    ; print msg1
    mov dx, offset num1Msg
    call print_msg

    ; input one char
    mov ah, 1
    int 21h
    mov num1, al

    ; print '
'
    mov dx, offset newLine
    call print_msg

    ; print num1
    mov dx, offset num1
    call print_msg

    ; exit
    mov ah, 4ch
    int 21h
main endp
print_msg proc
    mov ah, 9
    int 21h
    ret
print_msg endp
```

## Things to watch

- **Pre-appended `$` delimiter:** `num1 db ?, "$"` cleverly pairs the single-byte variable with a `$` byte immediately following it in memory. This allows function `09h` to treat `num1` as a null-style string without calling single-character output function `02h`.
- **16-bit real mode only:** Must be assembled and run within DOSBox or a 16-bit MS-DOS virtual environment.

## Terms

- **call/ret:** x86 instructions for invoking subroutines; `call` pushes the instruction pointer (`IP`) onto the stack, and `ret` pops it back to resume execution.
- **Carriage return / Line feed (0Dh, 0Ah):** The standard MS-DOS two-character newline sequence (ASCII 13, 10).
