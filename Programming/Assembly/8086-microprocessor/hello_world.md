## Overview

This program demonstrates the canonical "Hello, world!" program written in 16-bit x86 assembly language for the Intel 8086 microprocessor architecture. It initializes the data segment, loads string address offsets, and invokes MS-DOS software interrupt services (`INT 21H`) to display characters on the console and cleanly terminate the executable. Assembly programmers use programs like this to understand memory segmentation, register conventions, and BIOS/DOS system calls.

## How it works

The assembler directive `.MODEL SMALL` selects the small memory model, configuring the executable to use one 64KB segment for code and one 64KB segment for data. The `.STACK 100H` directive reserves 256 bytes (100h in hexadecimal) for the program call stack.

In the data segment (`.DATA`), the directive `TEXT DB "Hello, world!$"` allocates a contiguous sequence of bytes containing the string followed by a `$` character. MS-DOS display routines use `$` as the terminating sentinel.

In the code segment (`.CODE`), the procedure `MAIN PROC` defines the execution entry point:
- The segment address of the data segment (`@DATA`) is loaded into general-purpose register `AX`, and then moved into data segment register `DS`. In 8086 assembly, immediate constants cannot be transferred directly into segment registers.
- The offset address of `TEXT` within the data segment is loaded into register `DX` using `MOV DX, OFFSET TEXT`.
- Register `AH` is loaded with `9`, selecting MS-DOS interrupt service function `09H` (Write String to Standard Output).
- Invoking `INT 21H` prompts DOS to read characters from memory location `DS:DX` until it encounters `$`, printing each character to the console.
- Register `AH` is loaded with `4CH`, selecting MS-DOS interrupt service function `4CH` (Terminate Process with Return Code).
- Invoking `INT 21H` terminates the program and cleanly returns control to the operating system or DOS command interpreter.
- `MAIN ENDP` marks the end of the procedure, and `END MAIN` marks the end of assembly, identifying `MAIN` as the starting symbol.

## Key excerpt

```asm
.MODEL SMALL
.STACK 100H
.DATA
    TEXT DB "Hello, world!$"
.CODE
MAIN PROC
    ; Set Data Segement
    MOV AX, @DATA
    MOV DS, AX

    ; Copy TEXT into DX, as ah = 09h reads from DS:DX
    MOV DX, OFFSET TEXT
    MOV AH, 9
    INT 21H

    ; tell program to exit, ah = 4ch meaning terminate the program.
    MOV AH, 4CH
    INT 21H
MAIN ENDP
END MAIN
```

## Things to watch

- **16-bit DOS real mode:** This program is written specifically for 16-bit real mode MS-DOS. It cannot run natively on modern 64-bit operating systems without an emulator such as DOSBox or an x86 virtual machine running DOS.
- **The `$` string delimiter:** DOS function `09H` requires strings to be terminated with `$`. If the `$` byte is omitted or overwritten, the routine continues reading consecutive memory past the string, printing garbage characters until a byte matching ASCII 36 (`$`) is encountered.
- **Indirect segment loading:** Moving immediate values directly to segment registers (`MOV DS, @DATA`) is invalid in 8086 machine code and will fail to assemble; using `AX` as a transfer register is mandatory.

## Terms

- **Real Mode:** The primitive operating mode of x86 processors characterized by 20-bit segmented memory addressing and direct hardware access without virtual memory protection.
- **Interrupt (INT 21H):** A software interrupt instruction in x86 used by MS-DOS to expose system service functions to applications.
- **Segment Register:** A 16-bit processor register (such as `CS`, `DS`, `SS`) holding the base address of a 64KB memory segment.
