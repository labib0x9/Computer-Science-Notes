## Overview

This program demonstrates counted loop execution in 16-bit 8086 assembly using the hardware `loop` instruction and `CX` register. In x86 assembly, the `loop` instruction automatically decrements `CX` and branches to a specified label if `CX` is non-zero, providing an efficient hardware loop construct.

## How it works

The directives `.MODEL SMALL` and `.STACK 100H` define memory boundaries.

The `.DATA` segment defines `num1Msg` and `newLine`.

In `.CODE`:
- `main proc`:
  - Sets up data segment: `mov ax, @data; mov ds, ax`.
  - Initializes loop bounds: sets `cl = 3` (loop count) and `si = 0` (index tracking).
  - Enters `print_loop`:
    - Loads `offset num1Msg` into `dx` and calls `print_msg`.
    - Loads `offset newLine` into `dx` and calls `print_msg`.
    - Increments `si` via `inc si`.
    - Executes `loop print_loop`. The `loop` instruction decrements `cx` by 1; if `cx != 0`, it branches back to `print_loop`. Once `cx` reaches 0, execution falls through.
  - Terminates cleanly with `mov ah, 4ch; int 21h`.
- `print_msg proc`:
  - Executes `mov ah, 9; int 21h; ret`.

## Key excerpt

```asm
    ; loop range si = 0 to si = cl
    mov cl, 3   ; count
    mov si, 0   ; source index

    print_loop:
        ; print msg1
        mov dx, offset num1Msg
        call print_msg
        
        ; print '
'
        mov dx, offset newLine
        call print_msg

        inc si  ; si = si + 1
        loop print_loop ; next iteration

    ; exit
    mov ah, 4ch
    int 21h
```

## Things to watch

- **High byte of CX register:** The code sets `mov cl, 3` without clearing `ch`. The `loop` instruction checks the full 16-bit `cx` register, not just `cl`. If `ch` contains garbage from earlier instructions, the loop could execute thousands of times. Setting `mov cx, 3` or `xor ch, ch` is safer.

## Terms

- **loop instruction:** An x86 instruction that decrements `CX` and branches to a target label if `CX != 0`.
- **CX register:** The x86 Count Register, dedicated by convention and instruction semantics for loop counters and string repeat operations.
