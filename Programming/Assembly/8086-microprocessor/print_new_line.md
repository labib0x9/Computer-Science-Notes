## Overview

This program demonstrates console text output and explicit line formatting in 16-bit MS-DOS assembly for the Intel 8086. It shows how the ASCII carriage return (`0Dh`) and line feed (`0Ah`) byte sequence creates standard line breaks across successive DOS string print interrupts.

## Concepts used

- DOS interrupt `INT 21H` function `09H` (Write String)
- ASCII control characters (CR = `0Dh`, LF = `0Ah`)
- Multi-string data segment definitions

## How it works

The directives `.MODEL SMALL` and `.STACK 100H` define memory layout.

The `.DATA` segment defines:
- `num1 db "A [0-255]: $"`
- `num2 db "B [0-255]: $"`
- `newLine db 0Dh, 0Ah, "$"`

In `main proc`:
- Loads data segment address into `AX` and moves to `DS`.
- Loads `offset num1` into `DX`, sets `AH = 9`, and calls `INT 21H` to print first prompt.
- Loads `offset newLine` into `DX`, sets `AH = 9`, and calls `INT 21H` to output carriage return and line feed.
- Loads `offset num2` into `DX`, sets `AH = 9`, and calls `INT 21H` to print second prompt.
- Terminates via `MOV AH, 4CH; INT 21H`.

## Key excerpt

```asm
.data
    num1 db "A [0-255]: $"
    num2 db "B [0-255]: $"
    newLine db 0Dh, 0Ah, "$"
.code
main proc
    ; load ds
    mov ax, @data
    mov ds, ax

    ; print msg1
    mov dx, offset num1
    mov ah, 9
    int 21h

    ; print '
'
    mov dx, offset newLine
    mov ah, 9
    int 21h

    ; print msg2
    mov dx, offset num2
    mov ah, 9
    int 21h

    ; exit
    mov ah, 4ch
    int 21h
main endp
```

## Things to watch

- **DOS newline pairing:** In MS-DOS and Windows, a newline requires both Carriage Return (`0Dh`, ASCII 13) to return the cursor to column 0, and Line Feed (`0Ah`, ASCII 10) to advance down one row. Emitting only `0Ah` results in text stepping diagonally across the screen in classic DOS.

## Terms

- **Carriage Return (CR):** An ASCII control character (code 13 / 0Dh) moving the cursor to the beginning of the line.
- **Line Feed (LF):** An ASCII control character (code 10 / 0Ah) advancing the cursor to the next line.
