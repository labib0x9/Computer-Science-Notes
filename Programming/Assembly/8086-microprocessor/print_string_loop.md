## Overview

This program demonstrates how to read a buffered string from the user in 16-bit DOS assembly using interrupt `21h` function `0Ah`, inspect the actual character count returned by DOS, and iterate through the stored characters using the `SI` index register and `loop` instruction to print each character on a separate line.

## Concepts used

- DOS buffered string input structure (`INT 21H`, function `0AH`)
- Indexed memory addressing (`[SI + 1]`, `[SI]`)
- Single character display service (`INT 21H`, function `02H`)
- Counted character loop execution

## How it works

The `.DATA` segment defines:
- `num1Msg`: prompt string.
- `newLine`: CR/LF string.
- `buffer db 5, 0, 5 dup('$')`: a DOS input buffer structure where byte 0 specifies the maximum buffer size (5 bytes), byte 1 holds the count of characters actually entered by the user, and subsequent bytes hold the entered characters.

In `main`:
- Initializes `DS`.
- Calls `print_msg` to show prompt.
- Calls `input_string`.
- Exits with `mov ah, 4ch; int 21h`.

In `input_string proc`:
- Calls `mov ah, 0Ah; int 21h` with `dx = offset buffer`. DOS reads input until Enter is pressed, populating byte 1 with character count.
- Calls `print_msg` to emit a newline.
- Sets `si = offset buffer` and loads the character count into `cl`: `mov cl, [si + 1]`.
- Advances `si` past the header to the start of character data: `add si, 2`.
- Enters `print_char_loop`:
  - Loads character `mov dl, [si]`.
  - Sets `mov ah, 2` (DOS single character output service) and calls `int 21h`.
  - Prints newline via `print_msg`.
  - Increments `si` and loops via `loop print_char_loop`.
- Returns via `ret`.

## Key excerpt

```asm
input_string proc
    ; input string 
    mov ah, 0Ah
    int 21h

    ; print '
'
    mov dx, offset newLine
    call print_msg

    ; set si for index, cl for loop
    mov si, offset buffer   ; si = buf[0]
    mov cl, [si+1]  ; cl = char count
    add si, 2   ; si = buf[2]

    ; print buffer[2] to buffer[2+cl]
    print_char_loop:
        ; print buffer[si]
        mov dl, [si]
        mov ah, 2
        int 21h

        ; print '
'
        mov dx, offset newLine
        call print_msg

        inc si
        loop print_char_loop

    ret
input_string endp
```

## Things to watch

- **Buffer structure layout:** DOS function `0Ah` requires the first byte of the buffer to specify maximum buffer capacity. The second byte is written by DOS with the number of characters read (excluding Enter). Failing to allocate byte 0 and 1 correctly corrupts memory.
- **Empty input handling:** If the user presses Enter immediately, count `[si + 1]` is 0. Loading `cl = 0` causes `loop` to decrement `cx` to `0FFFFh`, looping 65,535 times unless guarded with `jcxz`.

## Terms

- **Buffered Input (0Ah):** An MS-DOS service that reads a line of text into a memory buffer with built-in backspace and editing support.
- **Function 02h:** An MS-DOS interrupt `21h` service that outputs the single ASCII character stored in register `DL`.
