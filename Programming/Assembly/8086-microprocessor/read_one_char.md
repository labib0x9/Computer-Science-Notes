## Overview

This program demonstrates single-character console input and output in 16-bit MS-DOS assembly for the Intel 8086. It illustrates interrupt `21h` function `01h` (Character Input with Echo) to read a keystroke into register `AL` and function `02h` (Character Output) to print characters from register `DL`.

## Concepts used

- DOS interrupt `INT 21H` function `01H` (Read Character with Echo)
- DOS interrupt `INT 21H` function `02H` (Write Character)
- Uninitialized variable allocation (`num1 db ?`)
- Register transfer between `AL` and `DL`

## How it works

The `.DATA` segment defines:
- `num1Msg db "A [0-255]: $"`
- `newLine db 0Dh, 0Ah, "$"`
- `num1 db ?`: allocates 1 uninitialized byte.

In `main proc`:
- Sets `DS` to `@DATA`.
- Prints prompt using function `09h`.
- Sets `AH = 1` and calls `INT 21H`. The CPU halts waiting for a key press; when pressed, the key is echoed to the screen and its ASCII code is returned in `AL`.
- Saves keystroke: `mov num1, al`.
- Prints newline string via function `09h`.
- Loads stored byte `mov dl, num1`, sets `AH = 2`, and calls `INT 21H` to display the character.
- Terminates via `MOV AH, 4CH; INT 21H`.

## Key excerpt

```asm
    ; print msg1
    mov dx, offset num1Msg
    mov ah, 9
    int 21h

    ; input one char
    mov ah, 1
    int 21h
    mov num1, al

    ; print '
'
    mov dx, offset newLine
    mov ah, 9
    int 21h

    ; print char
    mov dl, num1
    mov ah, 2
    int 21h

    ; exit
    mov ah, 4ch
    int 21h
```

## Things to watch

- **Echo behavior of function 01h:** Function `01h` automatically echoes the typed character to the console at the moment of entry. Because the program later outputs a newline and prints `num1` again, the typed character appears twice in the overall console transcript.

## Terms

- **Function 01h:** An MS-DOS interrupt service that waits for a character from standard input, echoes it to screen, and stores the ASCII value in `AL`.
- **Uninitialized data (`?`):** Assembler directive syntax reserving space in memory without assigning an initial compile-time value.
