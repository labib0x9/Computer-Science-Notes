## Overview

This program demonstrates how to read a line of text in 16-bit MS-DOS assembly using buffered input service `0Ah` and dynamically append the `$` string terminator byte to the end of the user's input so it can be redisplayed as a single string using function `09h`.

## Concepts used

- DOS buffered keyboard input (`INT 21H`, function `0AH`)
- Pointer arithmetic and indexed addressing with `SI` and `CX`
- In-memory string delimiter placement (`byte ptr [si], '$'`)
- Procedure modularity

## How it works

The `.DATA` segment defines:
- `num1Msg` and `newLine`.
- `buffer`:
  - `db 5`: maximum length allowed (5 characters).
  - `db ?`: actual count byte written by DOS.
  - `db 5 dup(?)`: storage space for up to 5 characters.

In `main proc`:
- Initializes `DS`.
- Calls `print_msg` to show prompt.
- Reads string: loads `dx = offset buffer`, sets `ah = 0Ah`, and invokes `int 21h`.
- Dynamically appends `$`:
  - Sets `si = offset buffer` (pointing to byte 0).
  - Loads character count `mov cl, [si + 1]` into `cl`.
  - Advances `si` past header: `add si, 2`.
  - Advances `si` to the end of typed characters: `add si, cx`.
  - Writes terminator: `mov byte ptr [si], '$'`.
- Prints newline.
- Prints the input string in one call: loads `dx = offset buffer + 2` and calls `print_msg` (function `09h`).
- Exits cleanly.

## Key excerpt

```asm
    ; input string
    mov dx, offset buffer
    mov ah, 0Ah
    int 21h

    ; add '$' to end
    mov si, offset buffer ; si = offset of buffer[0]
    mov cl, [si + 1]      ; cl = offset of buffer[1]
    add si, 2             ; si = offset of buffer[2]
    add si, cx            ; si = offset of buffer[2 + count]; cx = counter register
    mov byte ptr [si], '$'

    ; print '
'
    mov dx, offset newLine
    call print_msg

    ; print string
    mov dx, offset buffer + 2
    call print_msg
```

## Things to watch

- **High byte of CX during pointer addition:** The code loads `mov cl, [si + 1]` but then executes `add si, cx`. If the high byte `CH` is non-zero from earlier instructions, `si` will jump to an arbitrary memory location outside the buffer. Clearing `ch` with `xor ch, ch` or `mov ch, 0` prior to addition is necessary to guarantee correct pointer arithmetic.
- **Buffer overrun safety:** When the user enters the maximum 5 characters, writing `'$'` at `buffer[2 + 5]` writes into `buffer[7]`. Because `buffer` only reserves 2 header bytes + 5 data bytes (total 7 bytes, indices 0..6), writing at offset 7 overwrites whatever variable follows `buffer` in the data segment. An extra byte should be reserved for the `$` terminator.

## Terms

- **byte ptr:** An assembler type override specifying that a memory operand references an 8-bit byte rather than a 16-bit word.
- **Buffered input header:** The two-byte metadata prefix (max length and actual count) required by DOS interrupt 21h function 0Ah.
