## Overview

This program demonstrates a simplified approach to reading and displaying strings in 16-bit MS-DOS assembly for the Intel 8086. By pre-populating the input buffer with `$` sentinel characters (`5 dup('$')`), it avoids manual runtime calculation and placement of the string terminator after user input.

## Concepts used

- Pre-initialized buffer termination (`5 dup('$')`)
- DOS interrupt `INT 21H` services `0AH` and `09H`
- Modular subroutines (`input_string`, `print_msg`)

## How it works

The `.DATA` segment defines:
- `num1Msg` and `newLine`.
- `buffer db 5, 0, 5 dup('$')`: declares maximum length (5), initial count (0), and initializes all 5 storage bytes to `$`.

In `main proc`:
- Initializes `DS` to `@DATA`.
- Prompts user with `call print_msg`.
- Invokes `call input_string`: calls DOS function `0Ah` with `dx = offset buffer`. DOS writes typed characters into `buffer + 2`, leaving trailing unwritten slots initialized to `$`.
- Prints newline via `call print_msg`.
- Prints entered string via `call print_msg` starting at `offset buffer + 2`.
- Terminates via function `4Ch`.

## Key excerpt

```asm
.data
    num1Msg db "A [0-255]: $"
    newLine db 0Dh, 0Ah, "$"

    buffer db 5, 0, 5 dup('$')
.code
main proc
    ; load ds
    mov ax, @data
    mov ds, ax

    ; print msg1
    mov dx, offset num1Msg
    call print_msg

    ; input string
    mov dx, offset buffer
    call input_string

    ; print '
'
    mov dx, offset newLine
    call print_msg

    ; print string
    mov dx, offset buffer + 2
    call print_msg

    ; exit
    mov ah, 4ch
    int 21h
main endp
```

## Things to watch

- **Overwriting behavior on maximum length:** If the user inputs the maximum 5 characters, all 5 `$` bytes are replaced with text characters, leaving no `$` terminator immediately following the buffer. When `print_msg` runs, it will read beyond the buffer until finding a random `$` byte in memory. Reserving a 6th byte `6 dup('$')` ensures safety.
