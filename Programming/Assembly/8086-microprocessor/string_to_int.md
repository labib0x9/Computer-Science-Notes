## Overview

This program demonstrates how to parse and convert an ASCII character string representing a decimal number into a binary integer in 16-bit 8086 assembly. Instead of using the hardware `MUL` instruction for multiplication by 10, it uses bitwise left shift instructions (`SHL`) and addition ($10x = 2x + 8x$) to multiply the running accumulator before adding each numeric digit.

## How it works

The `.DATA` segment defines prompts, newline, a word variable `num1 dw ?` to receive the integer result, and an input buffer `buffer`.

In `main`:
- Initializes `DS`.
- Calls `print_msg` to prompt the user.
- Calls procedure `input_int` and stores the resulting integer from `AX` into `num1`.
- Exits with function `4Ch`.

In `input_int proc`:
- Reads input string via function `0Ah`.
- Emits a newline via `print_msg`.
- Sets `si = offset buffer` and extracts character count `mov cl, [si + 1]`.
- Sets `si` to point to the first character: `add si, 2`.
- Clears registers: `xor ax, ax`, `xor bx, bx`, `xor dx, dx`.
- Enters `convert_loop`:
  - Fetches character: `mov bl, [si]`.
  - Converts ASCII to digit: `sub bl, '0'` (subtracts 48).
  - Multiplies accumulator `AX` by 10 using shift identity:
    - Copies `dx = ax`.
    - `shl ax, 1`: computes $2 	imes 	ext{AX}$.
    - Three consecutive `shl dx, 1` operations: computes $8 	imes 	ext{AX}$.
    - `add ax, dx`: computes $2 	imes 	ext{AX} + 8 	imes 	ext{AX} = 10 	imes 	ext{AX}$.
  - Adds current digit: `add ax, bx`.
  - Advances pointer: `inc si`.
  - Loops via `loop convert_loop`.
- Returns final integer in `AX`.

## Key excerpt

```asm
    ; set result environment
    xor ax, ax
    xor bx, bx
    xor dx, dx

    ; print buffer[2] to buffer[2+cl]
    convert_loop:
        mov bl, [si]    ; bl = buffer[si]
        sub bl, '0'     ; bl = '9' - '0'

        ; ax = ax * 10
        mov dx, ax
        shl ax, 1   ; ax = ax * 2
        ; shl dx, 3   ; dx = dx * 8 = ax * 8
        shl dx, 1
        shl dx, 1
        shl dx, 1
        add ax, dx  ; ax = 2ax + 8ax = 10ax = ax * 10

        ; ax = ax + digit
        add ax, bx  ; ax = ax + bx[bl]

        inc si
        loop convert_loop
```

## Things to watch

- **Shift vs. Multiply optimization:** Multiplying by 10 via `(ax << 1) + (ax << 3)` was a classic optimization on the original 8086 processor where `MUL` took 118-133 clock cycles while shifts and adds executed in only a few cycles.
- **Overflow check absence:** If the user inputs a number larger than 65,535, 16-bit unsigned addition will overflow without detection.

## Terms

- **ASCII to binary conversion:** The process of subtracting ASCII offset '0' (48) from character digits and accumulating place values in base 10.
- **Bitwise shift left (SHL):** An instruction that shifts all bits in an operand left by one position, multiplying unsigned values by 2.
