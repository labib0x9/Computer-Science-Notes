## Overview

This program demonstrates arithmetic operations (addition and subtraction) on user-entered digits in 16-bit 8086 assembly. It prompts the user for two single-digit inputs, performs binary addition (`ADD`) and subtraction (`SUB`), and implements a custom procedure `print_int` that converts 1-byte integers into printable decimal characters using division by 10.

## How it works

The `.DATA` segment defines prompts `in1`, `in2`, output labels `ou1`, `ou2`, byte variables `A` and `B`, and newline `nl`.

In `main proc`:
- Initializes `DS`.
- Prompts for first number, calls `input_int` (which reads a character via function `01h` and subtracts `'0'`), and stores the digit into `A`.
- Emits newline, prompts for second number, calls `input_int`, and stores into `B`.
- Summation:
  - Prints label `ou1` ("A + B = ").
  - Loads `al = A` and `bl = B`, adds them via `add al, bl`, moves result to `dl`, and calls `print_int`.
- Subtraction:
  - Prints label `ou2` ("A - B = ").
  - Loads `al = A` and `bl = B`, subtracts via `sub al, bl`, moves result to `dl`, and calls `print_int`.
- Exits with function `4Ch`.

Procedure `print_int proc`:
- Compares `dl` with 10 using `cmp dl, 10`.
- If `dl < 10`, jumps to `one_digit`, adds `'0'`, and prints with function `02h`.
- Otherwise enters `two_digit`:
  - Prepares for 8-bit division: loads `al = dl`, clears `ah = 0`, sets `bl = 10`, and executes `div bl`. `AL` receives quotient (tens digit) and `AH` receives remainder (units digit).
  - Prints quotient character via function `02h`.
  - Prints remainder character via function `02h`.
  - Returns via `ret`.

## Key excerpt

```asm
print_int proc
    cmp dl, 10
    jl one_digit       ; if dl < 10 → jump

two_digit:
    mov al, dl
    mov bl, 10
    xor ah, ah
    div bl             ; AL = quotient, AH = remainder

    mov dl, al
    add dl, '0'
    mov ah, 2
    int 21h            ; print quotient

    mov dl, ah
    add dl, '0'
    mov ah, 2
    int 21h            ; print remainder
    ret

one_digit:
    add dl, '0'
    mov ah, 2
    int 21h
    ret
print_int endp
```

## Things to watch

- **Negative subtraction result:** If $A < B$ (for example $A = 3, B = 8$), `sub al, bl` yields a negative two's complement value (e.g. `251` or `0FBh`). Because `cmp dl, 10` is followed by unsigned jump `jl`, 251 is treated as greater than 10, executing `div bl` and printing `25` plus a non-numeric ASCII character rather than a negative sign.

## Terms

- **DIV instruction:** In 8086 assembly, dividing a 16-bit word in `AX` by an 8-bit register produces the quotient in `AL` and remainder in `AH`.
- **ASCII conversion:** Adding ASCII code '0' (48) converts a raw integer digit between 0 and 9 into its printable character representation.
