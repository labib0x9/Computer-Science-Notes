## Overview

This program demonstrates core memory management and pointer casting mechanisms in C++. It contrasts C++ operators (`new`, `new[]`, `delete`, `delete[]`) with C standard library functions (`malloc`, `free`), illustrates typeless pointers (`void*`), and compares binary reinterpretation via `reinterpret_cast` and `memcpy` against value conversion via `static_cast`.

## How it works

The program includes `<iostream>`, `<stdlib.h>`, and imports namespace `std`.

In `main`:
- Allocates single integer on heap: `int *p = new int; delete p;`.
- Allocates integer array of size 3: `int *arr = new int[3]; delete[] arr;`.
- Allocates memory using C-style malloc: `int *brr = (int*) malloc(3 * sizeof(int)); free(brr);`.
- Demonstrates `void*`: stores address of double variable `pi = 3.1416` in `void *ptr = &pi;`.
- Casts `ptr` to integer pointer via `int *pii = reinterpret_cast<int*>(ptr);` and prints `*pii`, interpreting the IEEE 754 floating-point byte representation of `pi` directly as an integer.
- Copies the first 4 bytes of `pi` into integer `PII` using `memcpy(&PII, &pi, sizeof(int));` and prints `PII`.
- Performs standard value conversion using `static_cast<int>(pi)` and prints `PII`, outputting the truncated integer value `3`.
- Returns 0.

## Key excerpt

```cpp
    // void* type
    double pi = 3.1416;
    void *ptr = &pi;    // typeless-pointer, can point anything

    int *pii = reinterpret_cast<int*>(ptr); // interpret the memory(double*) as *int

    cout << *pii << endl;

    int PII;
    memcpy(&PII, &pi, sizeof(int));

    cout << PII << endl;

    PII = static_cast<int>(pi);
    cout << PII << endl;
```

## Things to watch

- **Strict aliasing violation:** Dereferencing `*pii` (where `pii` points to a `double` variable) violates C++ strict aliasing rules, resulting in undefined behavior. The standard, well-defined way to inspect underlying object representations is using `memcpy` or C++20 `std::bit_cast`.
- **Array delete matching:** Pairing array allocation `new[]` with scalar `delete` (instead of `delete[]`) is undefined behavior. The code correctly uses `delete[] arr`.

## Terms

- **reinterpret_cast:** A C++ type-casting operator that reinterprets the bit pattern of an object or pointer as another type without value conversion.
- **static_cast:** A compile-time checked cast that performs well-defined implicit and standard conversions (such as double to int).
- **Strict Aliasing Rule:** A compiler rule stipulating that two pointers of incompatible types cannot point to the same memory location, allowing optimization assumptions.
