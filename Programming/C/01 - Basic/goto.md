## How it works

The program initializes integer variable `a = 20`:
1. It evaluates `if (a > 10)`. Since 20 is greater than 10, the condition is true.
2. It executes `goto RESET;`, which transfers control directly to label `RESET:`.
3. At `RESET:`, `a -= 10` executes, reducing `a` to 10.
4. `printf("a=%d\n", a)` outputs the final value of `a`.

## Key excerpt

```c
int main() {

    int a = 20;
    
    if (a > 10) {
        goto RESET;
    }

    RESET:
        a -= 10;

    printf("a=%d
", a);

    return 0;
}
```

## Things to watch

- **Code readability**: Excessive use of `goto` can create "spaghetti code" that makes program flow difficult to reason about. In idiomatic C, `goto` is primarily reserved for centralized error-handling and resource-cleanup paths at the end of functions.
- **Scope limitations**: `goto` can only transfer control within the same function; it cannot jump across function boundaries (which requires `setjmp`/`longjmp`).

## Terms

- **goto**: A keyword in C for unconditional jumping to a labeled statement.
- **Label**: An identifier followed by a colon marking a target location in code.
