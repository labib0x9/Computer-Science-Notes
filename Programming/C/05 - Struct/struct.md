## Things to watch

- **sizeof is a compile-time operator**: `sizeof` evaluates expressions at compile time without executing code.
- **Uninitialized struct fields**: In C, local struct variables allocated on the stack contain indeterminate garbage memory unless explicitly initialized with `{0}` or field initializers.

## Terms

- **Struct**: A composite data type in C grouping multiple variables under a single name in contiguous memory.
- **Union**: A data type where all members share the same base memory location.
