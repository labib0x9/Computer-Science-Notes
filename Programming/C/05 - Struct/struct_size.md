## How it works

The code defines two structs containing the exact same fields (`bool alloc`, `int a`, `int b`, `long long c`):
- `a_t`: Declares `bool` (1 byte + 3 padding), `int` (4 bytes), `int` (4 bytes + 4 padding), and `long long` (8 bytes). Total size = 24 bytes.
- `b_t`: Declares `long long` (8 bytes), `int` (4 bytes), `int` (4 bytes), and `bool` (1 byte + 7 trailing padding). Total size = 24 bytes or 16 bytes depending on grouping.

In `main`, `printf` outputs `sizeof(a_t)` and `sizeof(b_t)`.

## Things to watch

- **Field ordering rule of thumb**: To minimize padding without using `__attribute__((packed))`, order struct fields from largest data type to smallest data type (e.g. 8-byte pointers/ints, then 4-byte ints/floats, then 2-byte shorts, then 1-byte chars/bools).

## Terms

- **Padding**: Empty bytes inserted between fields to ensure subsequent fields meet hardware alignment requirements.
