## Overview

This program demonstrates how to configure a file descriptor for non-blocking I/O using the `fcntl` system call in C. Enabling `O_NONBLOCK` ensures that system calls such as `read()`, `write()`, `accept()`, and `recv()` return immediately with `EAGAIN` or `EWOULDBLOCK` instead of blocking the calling thread.

## How it works

The code implements `set_fd_nonblock(int fd)`:
1. `fcntl(fd, F_GETFL, 0)` retrieves the current file status flags.
2. If `F_GETFL` fails and returns `-1`, the error is propagated.
3. `fcntl(fd, F_SETFL, flags | O_NONBLOCK)` performs a bitwise OR to append the `O_NONBLOCK` flag without clearing existing flags, updating the descriptor's operating mode.
4. In `main`:
   - A TCP stream socket `fd` is created via `socket(AF_INET, SOCK_STREAM, 0)`.
   - `set_fd_nonblock(fd)` is invoked to set the socket to non-blocking mode.
   - The file descriptor is closed with `close(fd)`.

## Key excerpt

```c
int set_fd_nonblock(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);
    if (flags == -1) {
        return -1;
    }
    return fcntl(fd, F_SETFL, flags | O_NONBLOCK);
}
```

## Things to watch

- **Preserve existing flags**: Always read existing flags with `F_GETFL` before setting them with `F_SETFL`. Calling `fcntl(fd, F_SETFL, O_NONBLOCK)` directly would overwrite other flags (like `O_APPEND` or `O_ASYNC`).
- **Error handling**: In non-blocking sockets, operations that would block return `-1` with `errno` set to `EAGAIN` or `EWOULDBLOCK`, which must be handled as normal waiting states rather than fatal errors.

## Terms

- **fcntl**: System call for manipulating file descriptor properties and flags.
- **O_NONBLOCK**: A file status flag indicating that I/O operations should return immediately rather than putting the thread to sleep.
