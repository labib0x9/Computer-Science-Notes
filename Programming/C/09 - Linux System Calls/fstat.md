## Overview

This program demonstrates how to query file metadata using the `fstat` system call in C. Unlike `stat` which operates on a file path, `fstat` queries an already open file descriptor, avoiding race conditions (TOCTOU) between path lookup and file inspection.

## Concepts used

## How it works

1. It opens `test.txt` in read-only mode using `open("test.txt", O_RDONLY)`.
2. It declares a `struct stat st;` buffer.
3. It calls `fstat(fd, &st)`. The kernel writes the file's metadata directly into `st`.
4. It prints file properties:
   - File size: `st.st_size` in bytes
   - Inode number: `st.st_ino`
   - Permissions and file type: `st.st_mode`
5. It closes the file descriptor with `close(fd)`.

## Key excerpt

```c
int main() {

    // File descriptor
    int fd = open("test.txt", O_RDONLY);
    if (fd == -1) {
        // error
        perror("open");
        return 0;
    }

    struct stat st;
    if (fstat(fd, &st) == -1) {
        perror("fstat");
        close(fd);
        return 0;
    }

    printf("File size: %jd bytes
", (intmax_t)st.st_size);
```

## Things to watch

- **TOCTOU prevention**: Using `fstat` on an open file descriptor ensures the metadata corresponds exactly to the opened file, preventing Time-Of-Check to Time-Of-Use race conditions where a symlink or file could be swapped between `stat()` and `open()`.

## Terms

- **fstat**: POSIX system call that returns status information about the file referenced by a file descriptor.
- **Inode**: A filesystem data structure storing all metadata about a file except its name and actual content.
