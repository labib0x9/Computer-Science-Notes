## Overview

This program demonstrates how to tune network socket behavior using the `setsockopt` system call in C. It configures address reuse (`SO_REUSEADDR`) on server listening sockets and sets socket read timeouts (`SO_RCVTIMEO`) using `struct timeval` on accepted client connections.

## How it works

1. It creates a TCP socket with `socket(AF_INET, SOCK_STREAM, 0)`.
2. It sets `SO_REUSEADDR`:
   ```c
   int opt = 1;
   setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
   ```
   This allows immediate binding to port 8080 even if previous sockets remain in the kernel `TIME_WAIT` state.
3. It binds to `INADDR_ANY:8080` and calls `listen()`.
4. When a client connects via `accept()`, it configures a 5-second receive timeout on the client socket:
   ```c
   struct timeval tv = {.tv_sec = 5, .tv_usec = 0};
   setsockopt(client_fd, SOL_SOCKET, SO_RCVTIMEO, &tv, sizeof(tv));
   ```
5. If the client stays idle for 5 seconds without sending data, subsequent `recv()` calls return `-1` with `errno == EAGAIN` or `EWOULDBLOCK`, allowing the server to terminate dead connections.

## Key excerpt

```c
    // Enable SO_REUSEADDR to avoid "Address already in use"
    int opt = 1;
    if (setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) < 0) {
        perror("setsockopt SO_REUSEADDR");
        close(server_fd);
        exit(EXIT_FAILURE);
    }

    // Set receive timeout on accepted client connection
    struct timeval timeout;
    timeout.tv_sec = 5;
    timeout.tv_usec = 0;
    if (setsockopt(client_fd, SOL_SOCKET, SO_RCVTIMEO, &timeout, sizeof(timeout)) < 0) {
        perror("setsockopt SO_RCVTIMEO");
    }
```

## Things to watch

- **Timeout error code**: When `SO_RCVTIMEO` expires, `recv()` returns `-1`. Depending on the OS, `errno` is set to `EAGAIN` or `EWOULDBLOCK`.
- **SO_REUSEPORT**: On Linux and modern BSDs, `SO_REUSEPORT` allows multiple independent processes or threads to bind to the exact same port for kernel-level load balancing.

## Terms

- **setsockopt**: POSIX system call that manipulates options associated with a socket.
- **TIME_WAIT**: TCP state ensuring delayed packets from a terminated connection do not interfere with new connections.
