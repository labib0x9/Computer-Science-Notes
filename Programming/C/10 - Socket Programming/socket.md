## Overview

This program demonstrates the core lifecycle of a TCP network server in C. It covers creating an IPv4 stream socket, binding to an address and port, listening for connections, accepting incoming clients, reading payloads with `recv()`, and replying with `send()`.

## Concepts used

- Socket creation (`socket(AF_INET, SOCK_STREAM, 0)`)
- Configuring endpoint addresses with `struct sockaddr_in`
- Port byte ordering conversion via `htons`
- Socket lifecycle: `bind()`, `listen()`, `accept()`, `recv()`, `send()`, `close()`

## How it works

1. `socket(AF_INET, SOCK_STREAM, 0)` initializes an IPv4 TCP communication endpoint.
2. `struct sockaddr_in server_addr` configures the listening address:
   - `sin_family = AF_INET`
   - `sin_addr.s_addr = INADDR_ANY` (listens on all network interfaces)
   - `sin_port = htons(8080)` (converts port 8080 to network byte order)
3. `bind(fd, (struct sockaddr*)&server_addr, sizeof(server_addr))` binds the socket to the port.
4. `listen(fd, 10)` marks the socket as passive, with a backlog of 10 connection requests.
5. `accept(fd, ...)` blocks until a client connects, returning a new client socket descriptor.
6. `recv(client_fd, buf, sizeof(buf), 0)` reads incoming client data.
7. Both client and server descriptors are closed cleanly.

## Key excerpt

```c
	// create a socket endpoint
	int fd = socket(AF_INET, SOCK_STREAM, 0);
	if (fd < 0) {
		perror("socket create");
		exit(EXIT_FAILURE);
	}

	struct sockaddr_in server_addr;
	server_addr.sin_family = AF_INET;
	server_addr.sin_port = htons(8080);
	server_addr.sin_addr.s_addr = INADDR_ANY;

	if (bind(fd, (struct sockaddr*) &server_addr, sizeof(server_addr)) < 0) {
		perror("bind error");
		close(fd);
		exit(EXIT_FAILURE);
	}

	listen(fd, 10);
```

## Things to watch

- **Network Byte Order**: Network protocols use big-endian format. Always use `htons()` (Host To Network Short) for port numbers and `htonl()` for IP integers.
- **accept creates a new descriptor**: `accept()` returns a brand new socket descriptor for communication with that specific client; the original listening socket remains open to accept more clients.

## Terms

- **AF_INET**: Address family for IPv4 protocols.
- **SOCK_STREAM**: Socket type providing sequenced, reliable, two-way connection-based byte streams (TCP).
