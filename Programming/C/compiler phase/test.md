## Concepts used

- Preprocessor macro substitution with `#define`
- Header file inclusion via `#include <stdio.h>`
- C compilation phases (`gcc -E`, `gcc -S`, `gcc -c`, `gcc`)

## How it works

1. The preprocessor replaces `#include <stdio.h>` with the full contents of the standard I/O header file.
2. It expands the macro `MSG` into the string literal `"Compiler phase"`.
3. The compiler translates the preprocessed code into assembly code.
4. The assembler translates the assembly code into machine-readable object code (`.o`).
5. The linker resolves external symbols (such as `printf` from `libc`) and generates the final binary executable.

## Terms

- **Preprocessing**: The initial phase where directives (`#include`, `#define`, `#ifdef`) are evaluated and expanded before syntactic analysis.
- **Linking**: Combining object files and libraries into a runnable executable.
