## Overview

This program demonstrates modular multi-file C programming. It includes a user-defined header `math.h` and calls function `Add`, linking against its implementation in `math.c`.

## Concepts used

- Custom header inclusion with double quotes (`#include "math.h"`)
- Function declaration vs definition separation
- Multi-file compilation and linking (`gcc math.c main.c`)

## How it works

1. `main.c` includes `"math.h"`, bringing in the forward function prototype `int Add(int a, int b);`.
2. In `main()`, it calls `Add(2, 3)`.
3. During compilation, the linker pairs the call in `main.o` with the actual implementation found in `math.o`.
4. `printf("%d\n", Add(2, 3))` prints `5`.

- Attempting to compile `main.c` alone without `math.c` causes an `undefined reference to 'Add'` linker error.

## Things to watch

- **Quotes vs Angle Brackets**: `#include "..."` searches the current directory before system include directories; `#include <...>` searches standard library system include paths directly.
- **Header guards**: Custom header files should always include header guards (`#ifndef MATH_H ... #endif`) or `#pragma once` to prevent double-declaration errors.

## Terms

- **Translation Unit**: A single C source file plus all header files included by it.
- **Linker**: Program that combines translation units and resolves symbolic references between them.
