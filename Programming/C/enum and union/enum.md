## Things to watch

- **Underlying representation**: In C, enums are treated as integer constants (`int`). The compiler does not strictly prevent assigning an arbitrary integer value to an enum variable.
- **Custom values**: If a value is explicitly assigned (e.g. `FRIDAY = 10`), subsequent unassigned enum members increment from that value (`11`, `12`, etc.).

## Terms

- **Enum**: A user-defined data type consisting of a set of named integer constants.
- **Anonymous Enum**: An enum defined without a type name, commonly used in C to define scoped constants without macro `#define`.
