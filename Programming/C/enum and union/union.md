## How it works

The code presents two unions:
1. `union SAME_MEMORY`: Contains `int val` (4 bytes) and `long long err` (8 bytes). Its size is 8 bytes. Assigning to `err` overwrites the memory occupied by `val`.
2. `union Color`: Contains an anonymous struct of 4 `uint8_t` bytes (`r, g, b, a`) overlaying a single `uint32_t rgba` integer. Writing to `c.rgba = 0xAABBCCDD` instantly sets the individual byte channels.

## Things to watch

- **Endianness**: On little-endian architectures (x86_64, modern ARM), the least significant byte of `rgba` maps to the first byte in memory (`components.r`). On big-endian architectures, it maps to `components.a`.
- **Undefined behavior in C++**: Type punning through unions is well-defined in C99/C11 (Annex J.1), but is technically undefined behavior in standard C++ (which prefers `std::bit_cast`).

## Terms

- **Union**: A data structure where all members start at the same memory offset.
- **Type Punning**: Reinterpreting the bit pattern of one data type as another data type without explicit conversion.
