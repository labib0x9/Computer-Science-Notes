## Overview

This program demonstrates how to use GCC's `__attribute__((constructor))` function attribute to automatically run initialization functions before `main()` begins execution.

## Concepts used

- GCC function attributes (`__attribute__((constructor))`)
- Pre-main initialization routines
- Fixed-width integer typedefs (`uint8_t`, `uint16_t`, `uint32_t`, `uint64_t`)

## How it works

1. The function `init()` is decorated with `__attribute__((constructor))`.
2. When the operating system loads the binary and the C runtime startup code (`crt0`) executes, it invokes functions listed in the constructor table (`.init_array`) before invoking `main()`.
3. `init()` prints `Hello From init()
`.
4. Control passes to `main()`, which performs standard program operations.

## Key excerpt

```c
// runs before main().
__attribute__((constructor)) void init() {
	printf("Hello From init()
");
}
```

## Things to watch

- **Execution order with multiple constructors**: If multiple constructor functions exist, their execution order is undefined unless explicit priorities are specified (e.g. `__attribute__((constructor(101)))`).
- **Destructor attribute counterpart**: GCC also provides `__attribute__((destructor))`, which executes functions automatically when `main()` exits or `exit()` is called.

## Terms

- **Constructor Attribute**: A compiler extension that places function pointers into the ELF `.init_array` section for execution before `main`.
- **crt0**: C runtime initialization routine that prepares the environment, stack, and arguments before jumping to `main`.
