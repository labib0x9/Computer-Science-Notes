## How it works

The code defines tracking structs:
1. `GarbageObject` (`garbaje_object_t` in source): Wraps an arbitrary heap pointer `void* ptr`, integer `ref_count`, size in bytes `size`, and a pointer `next` to form a linked list of managed objects.
2. `GarbageCollector`: Represents the collection context, holding a pointer to the head of the allocated object list.

The author notes in comments that this file is an incomplete preliminary design sketch.
