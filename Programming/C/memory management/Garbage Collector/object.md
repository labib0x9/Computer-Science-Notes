## Overview

This program demonstrates how to design a dynamically typed, tagged object system in C suitable for runtime environments and garbage collectors. It combines enums and unions to encapsulate primitive values alongside GC metadata such as mark bits and reference counts.

## How it works

The code defines:
1. `object_kind_t`: Enum discriminating object types (`INT`, `FLOAT`).
2. `object_data_t`: Union holding the raw primitive payload (`int v_int`, `float v_float`).
3. `Object`: Struct binding the type tag `Kind`, payload union `data`, boolean GC flag `is_marked`, and integer `ref_count`.
4. Factory functions `NewInt(int val)` and `NewFloat(float val)` allocate an `Object` on the heap via `malloc`, assign fields, and set `ref_count = 1`.
5. `PrintObject(Object* obj)` inspects `obj->Kind` and prints the appropriate union member.

## Key excerpt

typedef enum {
	INT,
	FLOAT,
} object_kind_t;

typedef union {
	int v_int;
	float v_float;
} object_data_t;

typedef struct Object {
	object_kind_t Kind;	// what kind of object
	object_data_t data;
	bool is_marked;
	int ref_count;
} object_t;

## Terms

- **Tagged Union**: A data structure holding a value of one of several types alongside a tag indicating which type is currently held.
- **Mark Bit**: A boolean flag used by tracing garbage collectors during the mark phase to track reachable objects.
