## Overview

This program implements an efficient, constant-time $O(1)$ object pool in C using an embedded free-list. Instead of searching an array linearly for free slots, available pool elements are linked together in a singly linked list, allowing instantaneous allocation and deallocation.

## How it works

The pool manages instances of `pair_t` (`first, second`):
1. `PoolElem` struct: Bundles `pair_t obj` with a pointer `struct PoolElem* next`.
2. Initialization: A global array `object_pool[POOL_SIZE]` is initialized. Each element's `next` pointer points to the following element in the array (`object_pool[i].next = &object_pool[i+1]`), and `free_list_head` points to `&object_pool[0]`.
3. `Alloc()`:
   - If `free_list_head == NULL`, the pool is exhausted.
   - Otherwise, pops the head element: `elem = free_list_head; free_list_head = elem->next;`.
   - Returns `&elem->obj` in $O(1)$ time.
4. `Free(pair_t* ptr)`:
   - Uses pointer arithmetic / casting to locate the parent `PoolElem`.
   - Pushes the element back onto the front of the free list: `elem->next = free_list_head; free_list_head = elem;`.

## Key excerpt

```c
typedef struct Pair {
	int first, second;
} pair_t;

typedef struct PoolElem{
	pair_t obj;
	struct PoolElem* next;
} pool_elem_t;

pool_elem_t* free_list_head = NULL;

pair_t* Alloc() {
	if (free_list_head == NULL) {
		return NULL;
	}
	pool_elem_t* elem = free_list_head;
	free_list_head = free_list_head->next;
	return &elem->obj;
}

void Free(pair_t* ptr) {
	pool_elem_t* elem = (pool_elem_t*) ptr;
	elem->next = free_list_head;
	free_list_head = elem;
}
```

## Things to watch

- **Container casting safety**: Casting `(pool_elem_t*) ptr` in `Free` relies on `pair_t obj` being the very first member of `PoolElem`. If other members precede `obj`, use the `offsetof` or `container_of` macro.
- **Double free hazard**: Freeing the same pointer twice creates an infinite cycle in the free list.
