## Overview

This program demonstrates how to inspect runtime stack frames and function return addresses in C using GCC compiler built-in functions `__builtin_frame_address` and `__builtin_return_address`.

## Concepts used

- Call stack organization and stack frame levels
- GCC builtin `__builtin_frame_address(level)`
- GCC builtin `__builtin_return_address(level)`
- Pointer casting to integer types (`uintptr_t`)

## How it works

In `call_me()`:
1. `__builtin_frame_address(0)` retrieves the base pointer (frame address) of the current function `call_me`.
2. `__builtin_return_address(0)` retrieves the instruction address in `main()` that `call_me()` will return to after completion (pointing into the executable's `.text` segment).
3. The addresses are printed as hexadecimal pointers (`%p`) and as unsigned integer values via `(uintptr_t)`.
4. In `main()`, `__builtin_frame_address(0)` is also printed, showing that `main`'s frame resides at a higher memory address than `call_me` on downward-growing stack architectures.

## Key excerpt

```c
void call_me() {
	int x = 10;
	printf("Call Me: (top) = %p
", __builtin_frame_address(0));	// call_me() stack frame address -> lower than the main()
	printf("Call Me: (top) = %lu
", (uintptr_t) __builtin_frame_address(0));
	printf("Call Me: (ret) = %p
", __builtin_return_address(0));	// .text section
	printf("Call Me: (ret) = %lu
", (uintptr_t) __builtin_return_address(0));
}
```

## Expected behavior (from reading the code, not run)

- Prints the frame address of `call_me()` and its return address into `main()`.
- Demonstrates that `call_me`'s stack address is numerically lower than `main`'s stack address on x86_64 systems where stacks grow downward.

## Things to watch

- **Compiler optimization effects**: When functions are inlined or compiled with `-fomit-frame-pointer`, frame address builtins may return approximate or altered addresses.
- **Portability**: These built-in functions are specific to GCC and Clang; they are not part of standard ISO C.

## Terms

- **Stack Frame**: An area on the call stack holding local variables, parameters, and register state for a single function execution.
- **Return Address**: The memory location in the code segment where the CPU resumes execution after returning from a function.
