## Overview

This program demonstrates how to declare, assign, and invoke function pointers in C. It shows how functions can be treated as first-class citizens and passed as callback parameters to implement generic, decoupled execution routines.

## Concepts used

- Function pointer syntax: `return_type (*pointer_name)(arg_types)`
- Generic callback signatures using `void* (*)(void*)`
- Dynamic memory allocation inside callbacks (`malloc`)
- Explicit type casting of `void*` arguments

## How it works

The code defines arithmetic functions:
- `minus(a, b)` and `mult(a, b)`: Standard two-argument integer functions.
- `add(args)`: A generic callback taking a `void*` pointer to an array of integers, allocating heap memory for the sum, and returning `void*`.

In `main`:
1. It declares function pointers matching the function signatures.
2. It calls functions through their pointers.
3. For `add`, it packages two integer arguments into an array, passes the pointer to `add`, casts the returned `void*` pointer to `int*`, dereferences the result, and frees the allocated memory.

## Key excerpt

```c
void* add(void* args) {
	int* A = (int*) args;
	int* res = (int*) malloc(sizeof(int));
	*res = A[0] + A[1];
	return res;
}

int minus(int a, int b) {
	return a - b;
}

int mult(int a, int b) {
	return a * b;
}
```

## Things to watch

- **Syntax readability**: Function pointer syntax can become difficult to read. Defining a `typedef` (e.g. `typedef int (*binary_op_t)(int, int);`) significantly improves clarity.
- **Memory leaks in callbacks**: The `add` function allocates an integer on the heap via `malloc`. The caller must save the returned pointer and explicitly `free` it to prevent memory leaks.

## Terms

- **Function Pointer**: A pointer variable that stores the memory address of an executable function.
- **Callback**: A function passed as an argument to another function to be invoked when an event or task completes.
