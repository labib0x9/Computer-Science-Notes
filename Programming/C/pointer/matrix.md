## Overview

This program demonstrates how to dynamically allocate, populate, and free a two-dimensional grid (matrix) in C using pointer-to-pointer (`int**`) dynamic memory allocation.

## Concepts used

- Two-dimensional dynamic memory allocation with `int**`
- Two-stage allocation (row pointer array followed by individual row buffers)
- Two-stage deallocation to prevent memory leaks
- Encapsulating dimensions and data within a `matrix_t` struct

## How it works

The code encapsulates matrices in `matrix_t` containing row count `n`, column count `m`, and pointer `int** mat`:
1. `NewMatrix(n, m)`:
   - Allocates an array of `n` row pointers: `malloc(sizeof(int*) * n)`.
   - Iterates through each row index `i` from `0` to `n-1`, allocating an array of `m` integers: `malloc(sizeof(int) * m)`.
2. Accessing cells: Uses standard 2D array syntax `mat[i][j]` (which expands to `*(*(mat + i) + j)`).
3. `FreeMatrix(matrix_t* m)`: Frees each individual row buffer first, then frees the top-level pointer array `m->mat`.

## Key excerpt

```c
typedef struct Matrix {
    int n, m;
    int** mat;
} matrix_t;

matrix_t NewMatrix(int n, int m) {
    matrix_t new = {.n = n, .m = m, .mat = NULL};
    new.mat = (int**) malloc(sizeof(int*) * n);
    if (new.mat == NULL) {
        return new;
    }
    for (int i = 0; i < n; i++) {
        new.mat[i] = (int*) malloc(sizeof(int) * m);
    }
    return new;
}
```

## Things to watch

- **Memory fragmentation**: Allocating each row separately results in $N + 1$ distinct heap allocations, which causes memory fragmentation and poor cache locality. For high-performance matrix operations, allocate a single contiguous buffer (`malloc(n * m * sizeof(int))`) and index using `arr[i * m + j]`.
- **Freeing order**: Always free child row buffers before freeing the parent pointer array; freeing `mat` first loses references to the row buffers, causing memory leaks.

## Terms

- **Pointer to Pointer (`int**`)**: A pointer variable storing the memory address of another pointer.
- **Row-major Order**: Storing multidimensional array elements row by row in memory.
