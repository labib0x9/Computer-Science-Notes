## How it works

The function `swap(void* a, void* b, int size)`:
1. Validates that pointers `a` and `b` are not `NULL` and `size > 0`.
2. Allocates a temporary heap buffer `tmp` of size `size`.
3. Copies `size` bytes from `a` into `tmp` using `memmove(tmp, a, size)`.
4. Copies `size` bytes from `b` into `a` using `memmove(a, b, size)`.
5. Copies `size` bytes from `tmp` into `b` using `memmove(b, tmp, size)`.
6. Frees `tmp`.

In `main`, `swap` is tested on:
- Primitive integers (`int`) with `sizeof(int)`.
- Complex structs (`test_t`) containing strings and integers with `sizeof(test_t)`.

## Key excerpt

```c
void swap(void* a, void* b, int size) {
	if (a == NULL || b == NULL || size == 0) return;
	void* tmp = (void*) malloc(size);
	if (tmp == NULL) return;

	// tmp = a;
	memmove(tmp, a, size);
	// a = b;
	memmove(a, b, size);
	// b = tmp;
	memmove(b, tmp, size);

	free(tmp);
}
```

## Things to watch

- **Performance of dynamic allocation**: Calling `malloc` and `free` on every swap incurs performance overhead. For small types, using a fixed-size stack buffer or variable-length array (`char tmp[size]`) avoids heap allocations.
- **Deep vs Shallow copy**: `memmove` performs a shallow byte-for-byte copy. If the struct contains pointers to dynamically allocated heap memory, only the pointer addresses are exchanged.

## Terms

- **void* Pointer**: A generic pointer type that can hold the address of any data type without type information.
- **memmove**: Standard library function that copies bytes between memory areas, handling overlapping regions safely.
