## Things to watch

- **In-band sentinel collision**: Using `-1` as a sentinel means `-1` cannot be used as a valid data value. If `-1` is a legitimate input, use an explicit boolean flag (`has_value`) or optional wrapper struct.

## Terms

- **Sentinel Value**: A special predetermined value used to indicate the absence of valid data or end of input.
