## Overview

This program demonstrates how to use `khash.h` (from attractivechaos/klib), a fast, lightweight, header-only generic hash table implementation in C. It shows how macro templates generate type-safe string-to-integer maps using open addressing and linear probing.

## Concepts used

- Generic hash map instantiation via macro templates (`KHASH_MAP_INIT_STR`)
- Open addressing with linear probing and double hashing
- Memory management of dynamic string keys
- Iterating and querying keys using `kh_get`, `kh_put`, and `kh_val`

## How it works

1. `KHASH_MAP_INIT_STR(map, int)` instantiates type definitions and inline functions for a hash map named `map` with string keys (`const char*`) and `int` values.
2. In `main`:
   - `kh_init(map)` initializes a new hash table pointer `h`.
   - `kh_put(map, h, key, &ret)` inserts or looks up the bucket index for `key`. `ret` returns whether the key was newly added.
   - `kh_val(h, k) = 42` stores the value in the returned bucket.
   - `kh_get(map, h, "search_key")` searches for an existing entry. If found (`k != kh_end(h)`), its value is retrieved with `kh_val(h, k)`.
   - `kh_destroy(map, h)` frees the internal hash table arrays.

## Key excerpt

```c
// initailizes a hash table named map, which stores as string-int
// also map is just a name, not a variable
// uses Open addressing + linear probing
KHASH_MAP_INIT_STR(map, int);

int main() {
    khash_t(map) *h = kh_init(map);
    int ret;
    khiter_t k;

    // Insert key "apple" with value 10
    k = kh_put(map, h, "apple", &ret);
    kh_val(h, k) = 10;

    // Lookup
    k = kh_get(map, h, "apple");
    if (k != kh_end(h)) {
        printf("Found apple: %d
", kh_val(h, k));
    }

    kh_destroy(map, h);
    return 0;
}
```

## Things to watch

- **Key string lifetime**: `khash` stores the pointer `const char* key` without copying the string characters. If dynamically allocated strings are used as keys, the caller must ensure the string memory remains allocated until deleted or destroyed, and free the keys manually before calling `kh_destroy`.

## Terms

- **Open Addressing**: A method of collision resolution in hash tables where all elements are stored directly in the hash table array.
- **khiter_t**: An iterator/index type representing a bucket location within the khash table.
