## Overview

This program demonstrates how to parse raw HTTP/1.1 requests using `llhttp`, the high-performance C HTTP parser developed for Node.js. It registers callback hooks for request elements (method, URL, headers, and body) and processes raw request chunks.

## Concepts used

- Streaming HTTP parsing with `llhttp`
- Event-driven parsing callbacks (`on_url`, `on_header_field`, `on_header_value`, `on_message_complete`)
- Configuring parser settings structs (`llhttp_settings_t`)
- Incremental buffer parsing via `llhttp_execute`

## How it works

1. It defines callback functions matching `llhttp_data_cb` and `llhttp_cb` prototypes:
   - `handle_on_url`: Receives the request URL slice and prints it.
   - `handle_on_header_field` / `handle_on_header_value`: Streams HTTP header key-value pairs.
   - `handle_on_message_complete`: Triggered when the full HTTP request is parsed.
2. In `main`:
   - `llhttp_settings_init(&settings)` initializes the callback dispatch table.
   - Callbacks are assigned to `settings.on_url`, `settings.on_header_field`, etc.
   - `llhttp_init(&parser, HTTP_REQUEST, &settings)` initializes the parser state machine for incoming HTTP requests.
   - A raw sample HTTP GET request string `CONN` is passed to `llhttp_execute(&parser, CONN, strlen(CONN))`.
   - The parser evaluates the protocol wire format, invoking the callbacks in sequence.

## Key excerpt

```c
int handle_on_url(llhttp_t* parser, const char *at, size_t length) {
    printf("URL: %.*s
", (int)length, at);
    return 0;
}

int handle_on_header_field(llhttp_t* parser, const char *at, size_t length) {
    printf("Header: %.*s
", (int)length, at);
    return 0;
}

int main() {
    llhttp_t parser;
    llhttp_settings_t settings;
    llhttp_settings_init(&settings);

    settings.on_url = handle_on_url;
    settings.on_header_field = handle_on_header_field;

    llhttp_init(&parser, HTTP_REQUEST, &settings);
    llhttp_execute(&parser, CONN, strlen(CONN));
```

## Things to watch

- **Chunked callback delivery**: Callbacks like `on_header_field` may be called multiple times for a single header if the header spans packet or buffer boundaries. Production implementations must buffer chunk fragments until the delimiter or value callback fires.
- **Return codes**: Callback handlers must return 0 to continue parsing; returning non-zero aborts parsing with an error.

## Terms

- **llhttp**: The current standard HTTP/1.1 and HTTP/2 parser used by Node.js, replacing the legacy `http-parser`.
- **Stream Parser**: A parser capable of processing byte streams incrementally without requiring the entire payload in memory upfront.
