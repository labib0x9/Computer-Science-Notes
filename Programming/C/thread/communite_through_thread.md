## Overview

This program demonstrates how to communicate and return computation results from a worker thread back to the main thread using POSIX Threads (`pthreads`) and `pthread_join`.

## Concepts used

- Thread creation with `pthread_create`
- Heap allocation inside thread functions (`malloc`)
- Returning `void*` pointers from thread routines
- Collecting thread exit values with `pthread_join(t, &retval)`

## How it works

1. `AliceTurn(void* args)`:
   - Allocates an integer on the heap: `int* ptr = (int*)malloc(sizeof(int));`.
   - Accumulates values in `*ptr` in a loop.
   - Returns the heap pointer `return ptr;` when the thread completes.
2. In `main`:
   - `pthread_create(&alice, NULL, AliceTurn, NULL)` spawns the thread.
   - `pthread_join(alice, (void**)&res)` blocks until Alice completes and stores Alice's return pointer into `res`.
   - `printf("Alice returned = %d\n", *res)` dereferences the result.
   - `free(res)` deallocates the heap memory.

## Key excerpt

```c
void* AliceTurn(void* args) {
   int* ptr = (int*)malloc(sizeof(int)); // alloc 4bytes
   *ptr = 0;
   for (int i = 0; i <= 10; i++) {
      sleep(1);
      printf("Alice = %d
", i);
      (*ptr) += 2;
   }
   return ptr; // return result pointer
}

int main() {
   pthread_t alice;
   pthread_create(&alice, NULL, AliceTurn, NULL);

   int* res;
   pthread_join(alice, (void**)&res);
   printf("Alice returned = %d
", *res);
   free(res);
```

## Expected behavior (from reading the code, not run)

- Alice counts from 0 to 10 with 1-second delays.
- Main thread waits on `pthread_join`.
- Main prints Alice's accumulated calculation and frees the result pointer.

## Things to watch

- **Never return stack pointers**: Returning the address of a local variable allocated on the thread's stack causes undefined behavior because the thread's stack is deallocated when it terminates. Always allocate return data on the heap via `malloc` or pass in a caller-allocated result pointer.

## Terms

- **pthread_join**: Suspends execution of the calling thread until the target thread terminates and retrieves its exit value.
