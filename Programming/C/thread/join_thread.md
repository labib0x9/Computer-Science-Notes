## Overview

This program demonstrates fundamental multi-threading concurrency in C using POSIX Threads (`pthreads`). It launches two worker threads (`AliceTurn` and `BobTurn`) that run concurrently, and uses `pthread_join` to ensure the main program waits for both threads to finish before exiting.

## How it works

1. It defines two thread worker functions:
   - `AliceTurn`: Loops from 0 to 10 with a 1-second `sleep(1)`, printing `Alice = %d`.
   - `BobTurn`: Loops similarly, printing `Bob = %d`.
2. In `main()`:
   - Spawns Alice: `pthread_create(&alice, NULL, AliceTurn, NULL)`.
   - Spawns Bob: `pthread_create(&bob, NULL, BobTurn, NULL)`.
   - Both threads execute in parallel; their output lines interleave in real-time.
   - Calls `pthread_join(alice, NULL)` and `pthread_join(bob, NULL)` to block until both threads finish.

## Key excerpt

```c
int main() {
   pthread_t alice, bob;

   pthread_create(&alice, NULL, AliceTurn, NULL);
   pthread_create(&bob, NULL, BobTurn, NULL);

   pthread_join(alice, NULL);
   pthread_join(bob, NULL);

   return 0;
}
```

## Expected behavior (from reading the code, not run)

- Outputs interleaved lines from Alice and Bob every second.
- Terminates after approximately 11 seconds when both loops complete.

## Things to watch

- **Main thread premature exit**: If `main()` returns without calling `pthread_join` (or `pthread_exit`), the entire process and all child threads terminate immediately, aborting active work.

## Terms

- **POSIX Threads (pthreads)**: An IEEE POSIX standard defining a C language interface for creating and synchronizing threads.
- **Interleaving**: The arbitrary, non-deterministic scheduling order in which statements from concurrent threads execute.
