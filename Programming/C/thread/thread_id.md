## Concepts used

- Retrieving calling thread IDs via `pthread_self()`
- POSIX thread identifier type `pthread_t`
- Comparing thread IDs with `pthread_equal`

## How it works

1. In `main()`, `pthread_self()` retrieves the thread ID of the main thread and prints it as an unsigned long integer.
2. It launches worker thread `Calc` using `pthread_create`.
3. Inside `Calc()`, `pthread_self()` retrieves the child thread's identifier and prints it to stdout.
4. Comparing the two outputs verifies that the worker and main threads operate with distinct thread identifiers.

## Things to watch

- **pthread_t opacity**: The POSIX standard defines `pthread_t` as an opaque type; on some systems it is an integer, while on others it is a pointer to an internal thread control block. To compare two thread IDs portably, use `pthread_equal(t1, t2)` rather than `==`.

## Terms

- **pthread_self**: Returns the identifier of the calling thread.
- **pthread_t**: The data type used to represent POSIX thread handles.
