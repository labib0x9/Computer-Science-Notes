## Overview

This program demonstrates buffered I/O operations using Go's standard library `bufio` package. It explores how `bufio.Reader` and `bufio.Writer` buffer I/O calls to minimize underlying system calls, demonstrates buffer state tracking with `Available()` and `Buffered()`, explains the necessity of `Flush()`, and shows how `.Reset()` enables reusing buffers across multiple files.

## Concepts used

- Buffered I/O streaming with `bufio.Reader` and `bufio.Writer`
- Buffer flushing with `writer.Flush()`
- Tracking buffer metrics via `Available()` and `Buffered()`
- Buffer instance reuse with `Reset()`
- Lookahead inspection using `Peek()` and `Discard()`

## How it works

The `main` function demonstrates:
- Initializes a standard buffered writer `writer := bufio.NewWriter(os.Stdout)` and writes character `'a'`.
- Calls `writer.Flush()`. Without `Flush()`, buffered data remains in the internal byte slice in memory and is not emitted to `os.Stdout`.
- Creates a 1024-byte slice `p` and reads up to 1KB from `os.Stdin` via `reader.Read(p)`.
- Uses `reader.Peek(10)` to inspect the next 10 bytes without consuming them.
- Uses `reader.Discard(5)` to advance the read position forward by 5 bytes without copying.
- Demonstrates buffer reuse: resets `fileReader` across a loop of filenames using `fileReader.Reset(file)`, avoiding new allocations per file.
- Creates a small 10-byte writer `writer = bufio.NewWriterSize(os.Stdout, 10)` to demonstrate internal accounting:
  - Prints initial `Available: 10`, `Buffered: 0`.
  - Writes `"abc"`, updating `Available after Write: 7` and `Buffered after Write: 3`.
  - Calls `writer.Flush()`, writing `"abc"` to `os.Stdout` and restoring `Available: 10` and `Buffered: 0`.

## Key excerpt

```go
	writer = bufio.NewWriterSize(os.Stdout, 10) // small buffer for demo

	fmt.Println("Available:", writer.Available()) // 10 (buffer size)
	fmt.Println("Buffered:", writer.Buffered())   // 0

	writer.WriteString("abc")
	fmt.Println("Available after Write:", writer.Available()) // 7 (10 - 3)
	fmt.Println("Buffered after Write:", writer.Buffered())   // 3

	writer.Flush()
	fmt.Println("Available after Flush:", writer.Available()) // 10
	fmt.Println("Buffered after Flush:", writer.Buffered())   // 0
```

## Terms

- **bufio:** A standard Go package implementing buffered wrappers around `io.Reader` and `io.Writer`.
- **Flush:** Copying all buffered data from memory to the underlying I/O device or network stream.
