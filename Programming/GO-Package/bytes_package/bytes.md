## Overview

This program demonstrates in-memory byte manipulation using `bytes.Buffer` from Go's standard library `bytes` package. A `bytes.Buffer` is a variable-sized buffer of bytes with `Read` and `Write` methods, widely used as an in-memory stream for assembling and parsing binary or text payloads.

## Concepts used

- Variable-sized byte accumulator (`bytes.Buffer`)
- Writing scalar types (`WriteByte`, `WriteRune`, `WriteString`)
- Sequential reading (`ReadByte`, `ReadRune`, `ReadBytes`, `ReadString`)
- Buffer slicing and truncation (`Next`, `Truncate`, `Reset`)

## How it works

In `main`:
- Declares `var buffer bytes.Buffer`. The zero value of a `bytes.Buffer` is ready to use without explicit initialization.
- Appends data: writes byte `'a'`, UTF-8 rune `'a'`, and string `"str"`.
- Prints `buffer.String()`, outputting `"aastr"`.
- Reads from buffer: consumes a byte with `ReadByte()` and a rune with `ReadRune()`.
- Attempts to read up to delimiter `\n` with `ReadBytes` and `ReadString`.
- Calls `buffer.Next(5)` to slice the next 5 bytes directly from the buffer.
- Cleans and resets the buffer using `buffer.Reset()`.

## Key excerpt

```go
func main() {
	var buffer bytes.Buffer

	buffer.WriteByte(byte('a'))
	buffer.WriteRune(rune('a'))
	buffer.WriteString("str")

	fmt.Println(buffer.String())

	b, err := buffer.ReadByte()
	r, _, err := buffer.ReadRune()

	line, err := buffer.ReadBytes(byte('
'))
	str, err := buffer.ReadString('
')

	fmt.Println(b, line, r, str)
}
```

## Things to watch

- **EOF behavior on ReadBytes:** Because no newline `\n` was written to `buffer`, calling `ReadBytes('\n')` reads the remaining bytes and returns `io.EOF`.

## Terms

- **bytes.Buffer:** An in-memory buffer implementing both `io.Reader` and `io.Writer`.
- **Rune:** An alias for `int32` representing a Unicode code point in Go.
