## Overview

This program demonstrates how to implement a binary min-heap priority queue in Go using the standard library `container/heap` package. By implementing the five methods of `heap.Interface` (`Len`, `Less`, `Swap`, `Push`, `Pop`), any custom slice type can be transformed into an efficient priority queue with $O(\log n)$ insertions and deletions.

## How it works

Defines type `PriorityQueue []int`.

Implements `sort.Interface`:
- `Len() int`: returns `len(pq)`.
- `Less(i, j int) bool`: returns `pq[i] < pq[j]` (min-heap ordering).
- `Swap(i, j int)`: swaps `pq[i], pq[j] = pq[j], pq[i]`.

Implements `heap.Interface` extension:
- `Push(x interface{})`: asserts `x.(int)` and appends it to `*pq`.
- `Pop() interface{}`: extracts the last element `old[n-1]`, reslices `*pq = old[0:n-1]`, and returns the element.

In `main`:
- Initializes slice `pq := &PriorityQueue{3, 2, 1}`.
- Calls `heap.Init(pq)`: reorganizes the elements in $O(n)$ time to establish the min-heap invariant.
- Inserts an element via `heap.Push(pq, 2)`.
- Extracts the minimum element via `heap.Pop(pq)`.

## Key excerpt

```go
type PriorityQueue []int

func (pq PriorityQueue) Len() int           { return len(pq) }
func (pq PriorityQueue) Less(i, j int) bool { return pq[i] < pq[j] }
func (pq PriorityQueue) Swap(i, j int)      { pq[i], pq[j] = pq[j], pq[i] }

func (pq *PriorityQueue) Push(x interface{}) {
	*pq = append(*pq, x.(int))
}

func (pq *PriorityQueue) Pop() interface{} {
	old := *pq
	n := len(old)
	x := old[n-1]
	*pq = old[0 : n-1]
	return x
}
```

## Things to watch

- **Direct method invocation pitfall:** Always invoke heap operations through the package functions `heap.Push(pq, v)` and `heap.Pop(pq)`. Invoking `pq.Push()` or `pq.Pop()` directly only modifies the slice without maintaining the heap tree invariant.

## Terms

- **Min-Heap:** A complete binary tree where the key at the root is less than or equal to the keys of its children.
- **heap.Interface:** A Go interface embedding `sort.Interface` along with `Push(x any)` and `Pop() any`.
