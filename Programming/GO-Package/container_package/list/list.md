## Overview

This program demonstrates doubly linked list operations in Go using the standard library `container/list` package. It showcases creating an empty list, inserting elements at the head and tail, inserting relative to specific elements, removing nodes, and traversing the list sequentially.

## How it works

In `main`:
- Initializes an empty doubly linked list with `l := list.New()`.
- Inserts `1` at the head with `l.PushFront(1)`.
- Inserts `2` at the tail with `Element := l.PushBack(2)`.
- Inserts `2` before `Element` with `l.InsertBefore(2, Element)`.
- Inserts `2` after `Element` with `l.InsertAfter(2, Element)`.
- Deletes `Element` with `l.Remove(Element)`.
- Queries list metadata: `l.Front()`, `l.Back()`, and `l.Len()`.
- Iterates through the list starting at `l.Front()`, printing each `e.Value` until `e == nil`.

## Key excerpt

```go
func main() {
	l := list.New()             // creates a new list
	l.PushFront(1)              // insert at front
	Element := l.PushBack(2)               // insert at back
	l.InsertBefore(2, Element) // insert before a node
	l.InsertAfter(2, Element)  // insert after a node
	l.Remove(Element)          // remove a node

	for e := l.Front(); e != nil; e = e.Next() {
		fmt.Println(e.Value)
	}
}
```

## Things to watch

- **Generic type boxing:** `container/list` was written prior to Go 1.18 generics and stores elements as `interface{}` (`any`). Accessing stored values requires explicit type assertions (e.g. `e.Value.(int)`).

## Terms

- **Doubly Linked List:** A linked data structure whose nodes maintain pointers to both the next and preceding elements.
- **container/list.Element:** A struct representing an individual node in the doubly linked list.
