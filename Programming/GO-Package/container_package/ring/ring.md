## Overview

This program demonstrates circular linked list (ring) mechanics in Go using the standard library `container/ring` package. Unlike linear linked lists, a ring has no designated head or tail; every element links continuously to its neighbors in a closed circle.

## Concepts used

- Circular doubly linked lists (`ring.Ring`)
- Ring traversal with `Next()` and `Prev()`
- Applying functions over rings with `r.Do()`
- Splicing and splitting rings via `Link()` and `Unlink()`

## How it works

In `main`:
- Creates circular list `r := ring.New(3)` with 3 elements.
- Navigates forwards (`r.Next()`) and backwards (`r.Prev()`).
- Creates a second ring `r2 := ring.New(3)`.
- Populates values `0, 1, 2` into both rings by setting `r.Value` and advancing with `.Next()`.
- Iterates over all elements in `r` using `r.Do(func(v interface{}) { fmt.Println(v) })`.
- Merges `r2` into `r` using `r.Link(r2)`.
- Splices out 2 elements following `r` using `r.Unlink(2)`.

## Key excerpt

```go
func main() {
	r := ring.New(3) // create new ring of size n
	r2 := ring.New(3)

	// Initialize values
	for i := 0; i < 3; i++ {
		r.Value = i
		r = r.Next()

		r2.Value = i
		r2 = r2.Next()
	}

	// iterate and apply func
	r.Do(func(v interface{}) {
		fmt.Println(v)
	})

	r.Link(r2) // link r2 after r
	r2 = r.Unlink(2) // unlink n elements after r
}
```

## Things to watch

- **Infinite loop hazard:** Because a ring is circular, standard loops using `for r != nil; r = r.Next()` will loop infinitely. Always use `r.Do()`, track traversal count via `r.Len()`, or compare against an initial starting pointer.

## Terms

- **Circular List:** A linked list where the last element points back to the first element.
- **r.Do:** A method that invokes a callback function on each element of the ring in forward order.
