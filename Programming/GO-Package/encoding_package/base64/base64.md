## Overview

This program demonstrates binary-to-text encoding and decoding in Go using the standard library `encoding/base64` package. It showcases standard RFC 4648 encoding (`StdEncoding`) and URL-safe encoding (`URLEncoding`), commonly used for transmitting binary data across text-based protocols, JWTs, and web URLs.

## How it works

In `main`:
- Encodes byte slice `[]byte("Hello")` with `base64.StdEncoding.EncodeToString(p)` (yielding `"SGVsbG8="`).
- Decodes the string back into bytes with `base64.StdEncoding.DecodeString(encoded)`.
- Outlines stream wrappers `base64.NewDecoder` and `base64.NewEncoder`.
- Outlines file encoding and URL-safe encoding using `base64.URLEncoding`.

## Things to watch

- **URL-safe encoding differences:** `StdEncoding` uses `+` and `/` with `=` padding, which break query parameters and URLs. `URLEncoding` replaces `+` and `/` with `-` and `_` to remain URL-safe.

## Terms

- **Base64:** A binary-to-text encoding scheme representing binary data in an ASCII string format by translating it into radix-64 representation.
