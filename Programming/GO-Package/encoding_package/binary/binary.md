## Overview

This program demonstrates binary serialization in Go using `encoding/binary`. It illustrates byte ordering (Big-Endian vs. Little-Endian), fixed-size binary read and write operations via `binary.Read` and `binary.Write`, and variable-length integer compression (`PutUvarint`, `Uvarint`).

## Concepts used

- Endianness (Byte Ordering): `binary.BigEndian` vs. `binary.LittleEndian`
- Binary streaming with `binary.Write` and `binary.Read`
- Variable-length integer encoding (varints)
- Fixed-width numeric encoding into byte slices (`PutUint64`)

## How it works

In `main`:
- Writes integer `uint32(124)` into a buffer in Big-Endian order, followed by Little-Endian order.
- Reads `uint32` back from the buffer using `binary.Read`.
- Encodes integer `300` using variable-length encoding via `binary.PutUvarint`. Varints encode small numbers in fewer bytes (e.g. 10 bits in 2 bytes).
- Decodes varint using `binary.Uvarint`.
- Uses `binary.BigEndian.PutUint64` to write an 8-byte integer directly into a pre-allocated byte slice.
- Calculates memory sizes of structs using `binary.Size`.

## Key excerpt

```go
	var buf bytes.Buffer
	binary.Write(&buf, msbOrder, uint32(124)) // write binary-encoded data into writer (buf)
	binary.Write(&buf, lsbOrder, uint32(124))

	var value uint32
	binary.Read(&buf, msbOrder, &value) // read binary-encoded data from reader (buf) and store to value

	// variable-length encoding of integers
	buffer := make([]byte, binary.MaxVarintLen64)
	n := binary.PutUvarint(buffer, 300)
	fmt.Println(buffer[:n]) // Compact byte representation

	x, n := binary.Uvarint(buffer)
	fmt.Println(x) // 300
```

## Things to watch

- **Struct field visibility for binary.Read/Write:** `binary.Read` and `binary.Write` require structs to have only exported (capitalized) fields of fixed size. Unexported fields cause runtime errors.

## Terms

- **Big-Endian (Network Byte Order):** Most significant byte is stored at the lowest memory address.
- **Little-Endian:** Least significant byte is stored at the lowest memory address (standard on x86/ARM).
- **Varint:** A method of serializing integers using one or more bytes where smaller values occupy fewer bytes.
