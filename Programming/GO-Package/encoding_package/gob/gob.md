## Overview

This program demonstrates Go-specific binary serialization using the standard library `encoding/gob` package. Gob streams are self-describing binary encodings optimized for high-performance communication between Go services, RPC mechanisms (`net/rpc`), and local struct persistence.

## Concepts used

## How it works

The struct `Person` defines `Name string` and `Age int`.

The `Memory()` function:
- Encodes a `Person` struct into a `bytes.Buffer` using `gob.NewEncoder(&buf).Encode(p)`.
- Decodes the binary buffer into a new `Person` struct using `gob.NewDecoder(&buf).Decode(&p1)` and prints the result.

The `File()` function:
- Opens a file `test.gob` with read/write/create permissions.
- Encodes integer `10` to the file using a `gob.Encoder`.
- Demonstrates file pointer mechanics: resets the file read offset to 0 using `file.Seek(0, io.SeekStart)` so the decoder can read from the beginning of the file rather than hitting `io.EOF`.

## Key excerpt

```go
func Memory() {
	var buf bytes.Buffer
	enc := gob.NewEncoder(&buf)

	p := Person{Name: "Alice", Age: 30}
	if err := enc.Encode(p); err != nil {
		return
	}

	var p1 Person
	dec := gob.NewDecoder(&buf)
	if err := dec.Decode(&p1); err != nil {
		return
	}

	fmt.Println(p1)
}
```

## Things to watch

- **File seek requirement:** After writing to a file, the file offset points to the end of the written data. Attempting to decode immediately without calling `file.Seek(0, io.SeekStart)` triggers an `io.EOF` error.
- **Go-to-Go exclusivity:** Gob is a proprietary Go-specific binary protocol and cannot be parsed natively by non-Go clients without custom decoders.

## Terms

- **Gob:** A binary encoding format designed exclusively for transmitting Go data structures across networks or storing them on disk.
- **Seek:** An operation that moves the current read/write pointer within an open file to an arbitrary byte offset.
