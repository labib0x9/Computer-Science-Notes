## Overview

This program demonstrates hexadecimal encoding, decoding, and byte dump utilities using Go's standard library `encoding/hex` package. Hexadecimal representations are standard for inspecting hash digests, network packet byte sequences, and binary data debugging.

## How it works

The file is an exploratory overview listing `encoding/hex` functions:
- `hex.EncodeToString`: converts raw byte slices into lowercase hex strings.
- `hex.DecodeString`: parses hex strings back into binary bytes.
- `hex.Dump`: creates human-readable hex dumps with offsets and ASCII representations.
- `hex.NewDecoder` and `hex.NewEncoder`: streaming wrappers over `io.Reader` and `io.Writer`.

## Terms

- **Hexadecimal:** A base-16 numeral system using digits 0–9 and letters a–f.
