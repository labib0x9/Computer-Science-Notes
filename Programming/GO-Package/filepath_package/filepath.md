## Overview

This program demonstrates cross-platform filesystem path manipulation in Go using the `path/filepath` package. Unlike the generic `path` package which assumes forward slashes, `path/filepath` adapts dynamically to target operating system separators (`/` on Unix, `\` on Windows).

## Concepts used

- OS-aware path construction (`filepath.Join`)
- Path component extraction (`Base`, `Ext`, `Dir`)
- Recursive directory traversal with `filepath.Walk`

## How it works

The function `getFileType(filename string)` uses a switch statement on `filepath.Ext(filename)` to classify files by extension.

In `main`:
- Joins path components: `filepath.Join("golang", "dsa", "algo", "stack.go")`.
- Extracts filename component via `filepath.Base(path)` -> `"stack.go"`.
- Extracts file extension via `filepath.Ext(base)` -> `".go"`.
- Extracts parent directory via `filepath.Dir(path)` -> `"golang/dsa/algo"`.
- Illustrates recursive directory walking with `filepath.Walk(dirName, ...)`.

## Key excerpt

```go
func main() {

	path := filepath.Join("golang", "dsa", "algo", "stack.go")
	fmt.Println(path)

	base := filepath.Base(path)
	fmt.Println(base)

	extension := filepath.Ext(base)
	fmt.Println(extension)

	dirName := filepath.Dir(path)
	fmt.Print(dirName)
}
```

## Things to watch

- **filepath vs. path:** Use `path/filepath` for filesystem paths and `path` for URL or cloud storage paths that always require forward slashes.

## Terms

- **filepath.Join:** Combines path elements using the operating system's native separator and cleans the result.
- **filepath.Ext:** Returns the file name extension starting from the final dot.
