## How it works

The `main` function illustrates several `io` constructs:
- Copies standard input directly to standard output: `io.Copy(os.Stdout, os.Stdin)`.
- Concatenates multiple readers into a single sequential stream: `io.MultiReader(r1, r2)`.
- Duplicates writes to multiple destinations simultaneously: `io.MultiWriter(os.Stdout, os.Stderr)`.
- Limits byte transfer using `io.CopyN(w, r, 10)` to copy at most 10 bytes.
- Copies with a custom pre-allocated buffer using `io.CopyBuffer(w, r, buf)`.
- Duplicates reads to a writer on-the-fly using `io.TeeReader(r, w)`.
- Creates a synchronous in-memory pipe with `pr, pw := io.Pipe()`.

## Key excerpt

```go
func main() {
	r1 := strings.NewReader("Labib")
	r2 := strings.NewReader("Faisal")
	r := io.MultiReader(r1, r2)

	w1 := os.Stdout
	w2 := os.Stderr
	w := io.MultiWriter(w1, w2)

	io.CopyN(w, r, 10)

	buf := make([]byte, 10)
	io.CopyBuffer(w, r, buf)

	_ = io.TeeReader(r, w)

	pr, pw := io.Pipe()
}
```

## Things to watch

- **Incomplete pipe calls:** Lines 33 and 38 call `pr.Read()` and `pw.Write()` without arguments in the scratch draft, which causes a compilation error if executed as-is.
- **Pipe deadlock rule:** Reads and writes on an `io.Pipe` block synchronously. Reading and writing on the same goroutine will cause a permanent deadlock.

## Terms

- **MultiReader:** A logical reader that sequentially reads from a list of underlying readers until all reach EOF.
- **MultiWriter:** A writer that duplicates every write operation across multiple underlying writers.
- **TeeReader:** Returns a reader that writes to `w` whatever it reads from `r`.
