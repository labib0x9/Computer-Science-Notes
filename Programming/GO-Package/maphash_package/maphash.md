## Overview

This program demonstrates fast in-memory hashing using Go's `hash/maphash` package. Designed to provide the same high-performance, collision-resistant hash function used internally by Go maps, `maphash` is ideal for hash tables, caches, and bloom filters.

## Concepts used

- Seed generation with `maphash.MakeSeed()`
- Cumulative hash generation (`Write`, `WriteString`)
- Hash state resetting with `h.Reset()`
- Non-cryptographic 64-bit hashing (`h.Sum64()`)

## How it works

In `main`:
- Generates a random seed using `seed := maphash.MakeSeed()`.
- Declares `var h maphash.Hash` and sets the seed via `h.SetSeed(seed)`.
- Hashes bytes: writes `"hello"`, outputs `h.Sum64()`.
- Resets state with `h.Reset()`, writes `"world"`, and outputs the new hash.
- Demonstrates incremental streaming: writes `"hello"`, `" "`, and `"world"` sequentially, then calls `h.Sum64()` to obtain the composite hash for `"hello world"`.

## Key excerpt

```go
func main() {

	seed := maphash.MakeSeed()

	// create a new maphash.Hash
	var h maphash.Hash
	h.SetSeed(seed)

	// Hash
	h.Write([]byte("hello"))
	fmt.Println(h.Sum64())

	h.Reset()
	h.Write([]byte("world"))
	fmt.Println(h.Sum64())

	h.Reset()
	h.WriteString("hello")
	h.WriteString(" ")
	h.Write([]byte("world"))

	h.Sum64() // hash for "hello world"
}
```

## Things to watch

- **Non-persistent seeds:** Hashes generated by `maphash` are valid only within the current execution session. Seeds cannot be serialized or reused across process restarts.
- **Not cryptographically secure:** `maphash` is optimized for speed and hash table distribution, not cryptographic security. Do not use for passwords or digital signatures.

## Terms

- **maphash:** A Go standard library package providing byte and string hash functions based on Wyhash or AES hash instructions.
- **Seed:** An initial random value applied to a hash function to prevent hash-flooding DoS attacks.
