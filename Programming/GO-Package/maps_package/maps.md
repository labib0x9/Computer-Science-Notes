## Overview

This program outlines generic map operations introduced in modern Go via the `maps` package (standardized in Go 1.21). It illustrates generic helper functions that simplify cloning, copying, comparing, and extracting keys and values from Go maps without requiring manual loops.

## How it works

In `main`:
- Allocates two maps `m1` and `m2` of type `map[string]int`.
- Calls `maps.Clone(m1)`: creates a shallow copy of the map.
- Calls `maps.Copy(m1, m2)`: copies key/value pairs from `m2` into `m1`.
- Calls `maps.Equal(m1, m2)`: compares two maps for equality using `==` on keys and values.
- References `maps.Keys` and `maps.Values` (utility functions commonly found in `golang.org/x/exp/maps` or custom helpers).

## Key excerpt

```go
func main() {
	m1 := make(map[string]int)
	m2 := make(map[string]int)

	maps.Clone(m1)
	maps.Copy(m1, m2)
	maps.Equal(m1, m2)
	maps.Keys(m1)
	maps.Values(m1)
}
```

## Expected behavior (from reading the code, not run)

In standard Go 1.21+, `maps.Keys` and `maps.Values` were excluded from the standard `maps` package and moved to `slices.Collect(maps.Keys(...))` in Go 1.23. Attempting to compile this code on standard Go without those definitions will report `undefined: maps.Keys`.

## Things to watch

- **Go version requirement:** The `maps` package requires Go 1.21 or newer.
- **Shallow copy behavior:** `maps.Clone` produces a shallow copy. If values are pointers, slices, or reference types, modifying the inner data affects both maps.

## Terms

- **Shallow Copy:** Duplicating the outer container structure while retaining shared references to underlying pointed-to values.
