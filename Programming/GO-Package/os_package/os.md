## Key excerpt

```go
	// Environment variable
	os.Setenv("APP_ENV", "dev")
	os.Getenv("APP_ENV")
	os.Unsetenv("APP_ENV")
	os.Environ()
	os.Clearenv()

	os.Symlink("example.txt", "example-link.txt")
	os.Readlink("example-link.txt")

	// in-memory stream
	reader, writer, err := os.Pipe()
	p := make([]byte, 512)
	reader.Read(p)
	writer.Write(p)

	os.Exit(34)
```

## Terms

- **os.DirFS:** Returns an `io/fs.FS` filesystem implementation rooted at the specified directory.
- **os.Pipe:** Returns a connected pair of `*os.File` pointers where reads from `reader` consume bytes written to `writer`.
