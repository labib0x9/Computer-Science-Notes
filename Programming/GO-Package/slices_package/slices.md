## Overview

This program surveys the generic slice utilities introduced in Go 1.21 via the standard library `slices` package. It showcases high-performance generic algorithms that eliminate the need for manual loops or boilerplate slice manipulation for sorting, binary search, element deletion, insertion, deduplication, and reversal.

## How it works

In `main`:
- Initializes slice `s := []int{1, 2, 3, 4, 5, 6}`.
- `slices.BinarySearch(s, 10)`: performs $O(\log n)$ binary search on a sorted slice.
- `slices.Clone(s)`: creates a shallow copy.
- `slices.Compare(s, s)`: performs three-way lexicographical comparison (-1, 0, 1).
- `slices.Sort(s)`: sorts elements in-place using pdqsort.
- `slices.Concat(s, s, s)`: concatenates multiple slices into a new slice.
- `slices.Contains(s, 10)`: tests for membership.
- `slices.Equal(s, s)`: tests element-wise equality.
- `slices.Delete(s, 1, 2)`: removes elements in index range `[1:2]`.
- `slices.Insert(s, 1, 10)`: inserts value `10` at index `1`.
- `slices.Compact(s)`: removes consecutive duplicate elements (like Unix `uniq`).
- `slices.Reverse(s)`: reverses the elements in-place.

## Things to watch

- **Go 1.21 requirement:** The `slices` package was standardized in Go 1.21; older Go versions cannot compile this file.
- **Sorted precondition for BinarySearch and Compact:** `BinarySearch` requires the slice to be pre-sorted. `Compact` only collapses adjacent duplicate elements.

## Terms

- **Compact:** Replacing consecutive runs of equal elements with a single copy in-place.
- **Pattern-defeating Quicksort (pdqsort):** The highly optimized hybrid sorting algorithm used internally by `slices.Sort`.
