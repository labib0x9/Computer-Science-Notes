## Overview

This program demonstrates sorting and search techniques using Go's classic `sort` package. It showcases built-in helpers for primitive slices (`sort.Ints`), binary searching on monotonic functions with `sort.Search`, and custom struct slice sorting using closures with `sort.Slice` and `sort.SliceStable`.

## How it works

In `main`:
- Sorts an integer slice: `sort.Ints([]int{1, 2, 3, 4})`.
- Performs binary search on sorted slice `arr := []int{1, 2, 3, 4, 5, 6, 8, 9}` using `sort.Search(len(arr), func(i int) bool { return arr[i] >= 7 })`. It returns the lowest index where the predicate evaluates to true (index 6, where value is 8).
- Defines a struct slice of `people` containing Name and Age.
- Sorts `people` by ascending age using `sort.Slice(people, func(i, j int) bool { return people[i].Age < people[j].Age })`.
- Demonstrates stable sorting using `sort.SliceStable` to guarantee that elements with equal ages retain their original relative order.

## Things to watch

- **Reflection overhead in sort.Slice:** `sort.Slice` and `sort.SliceStable` take an `interface{}` parameter and use reflection internally. For maximum performance in modern Go, prefer `slices.SortFunc` (Go 1.21+) or implementing `sort.Interface`.
- **sort.Search contract:** `sort.Search` assumes that the predicate function is monotonic (returns `false` up to some index, then `true` for all subsequent indices).

## Terms

- **sort.Search:** A generic binary search algorithm finding the smallest index where a monotonic boolean function is true.
- **Stable Sort:** A sorting algorithm that preserves the original relative order of elements with equal keys.
