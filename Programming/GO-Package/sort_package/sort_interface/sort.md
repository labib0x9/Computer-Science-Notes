## Overview

This program demonstrates how to sort custom data structures in Go by implementing the classic `sort.Interface`. By defining `Len()`, `Swap(i, j int)`, and `Less(i, j int) bool` on a dedicated slice type, custom collections can be sorted using `sort.Sort()` and `sort.Stable()` without reflection overhead.

## Concepts used

- The three methods of `sort.Interface`: `Len`, `Swap`, `Less`
- Type definition on slices (`type NewType []Person`)
- Reflection-free sorting via `sort.Sort`
- Stable sorting with `sort.Stable`

## How it works

Defines `type Person struct { Name string; Age int }`.

Defines named slice type `type NewType []Person` and implements `sort.Interface`:
- `Len() int`: returns `len(n)`.
- `Swap(i, j int)`: swaps `n[i], n[j] = n[j], n[i]`.
- `Less(i, j int) bool`: returns `n[i].Age < n[j].Age` to order by age ascending.

In `main`:
- Allocates `people := []Person{{"Alice", 30}, {"Bob", 20}, {"Charlie", 25}}`.
- Converts `people` to `NewType` and sorts via `sort.Sort(NewType(people))`.
- Demonstrates stable sorting via `sort.Stable(NewType(people))`.

## Key excerpt

```go
type Person struct {
	Name string
	Age  int
}

type NewType []Person

// Implement the sort.Interface
func (n NewType) Len() int           { return len(n) }
func (n NewType) Swap(i, j int)      { n[i], n[j] = n[j], n[i] }
func (n NewType) Less(i, j int) bool { return n[i].Age < n[j].Age }

func main() {

	people := []Person{
		{"Alice", 30},
		{"Bob", 20},
		{"Charlie", 25},
	}

	sort.Sort(NewType(people))
	sort.Stable(NewType(people))
}
```

## Things to watch

- **Value vs. pointer receiver:** `sort.Interface` methods are defined with value receivers `(n NewType)` because a slice header itself contains the pointer to the underlying backing array; modifying elements through indices affects the underlying array directly.

## Terms

- **sort.Interface:** A standard library interface specifying `Len() int`, `Less(i, j int) bool`, and `Swap(i, j int)`.
