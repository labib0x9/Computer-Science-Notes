## Overview

This program demonstrates string conversions to and from primitive numeric and boolean data types using Go's standard library `strconv` package. It showcases `Atoi`, `Itoa`, `ParseFloat`, `ParseInt`, `FormatInt`, `ParseBool`, and `FormatFloat`.

## Concepts used

- String to integer conversions (`Atoi`, `Itoa`)
- Base conversion with `ParseInt` and `FormatInt` (e.g. binary base 2)
- Floating-point formatting and precision parsing (`ParseFloat`, `FormatFloat`)
- Boolean parsing (`ParseBool`)

## How it works

In `main`:
- Converts ASCII string `"12"` to integer via `strconv.Atoi("12")` and prints `12`.
- Converts integer `12` to string via `strconv.Itoa(12)` and prints `"12"`.
- Parses float `"123.321"` with 32-bit precision via `strconv.ParseFloat` and prints `123.321`.
- Parses binary string `"12"` (which returns an error because '2' is not a binary digit) using base 2.
- Formats integer `12` into a binary string representation using `strconv.FormatInt(12, 2)` (yielding `"1100"`).
- Parses boolean string `"true"` via `strconv.ParseBool`.
- Formats floating-point number `3.1416` into fixed decimal format with 2 digits of precision (`strconv.FormatFloat(3.1416, 'f', 2, 64)` yielding `"3.14"`).

## Key excerpt

```go
func main() {
	// Convertion
	n, _ := strconv.Atoi("12")
	fmt.Println(n)

	m := strconv.Itoa(12)
	fmt.Println(m)

	flt, _ := strconv.ParseFloat("123.321", 32)
	flt32 := float32(flt)
	fmt.Println(flt32)

	strconv.ParseInt("12", 2, 64)
	strconv.FormatInt(12, 2)
	strconv.ParseBool("true")
	strconv.FormatFloat(3.1416, 'f', 2, 64)
}
```
