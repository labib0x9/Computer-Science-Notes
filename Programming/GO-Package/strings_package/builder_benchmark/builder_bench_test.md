## Overview

This test file benchmarks string concatenation performance in Go. It compares the highly optimized `strings.Builder` (which pre-allocates an in-memory byte buffer and avoids copying upon string conversion) against repeated `+` string concatenation (which allocates a new string on the heap on every iteration, incurring $O(n^2)$ copying overhead).

## How it works

The benchmark `BenchmarkConcatWithBuilder(b *testing.B)`:
- Iterates `b.N` benchmark runs.
- In each run, constructs `var sb strings.Builder` and appends `"Heeloo"` 10,000 times using `sb.WriteString`.
- Calls `_ = sb.String()` to extract the final combined string.

The benchmark `BenchmarkConcatWithPlus(b *testing.B)`:
- Iterates `b.N` runs.
- Initializes an empty string `s := ""` and appends `"Heeloo"` 10,000 times using `s += "Heeloo"`. Because Go strings are immutable, each `+` creates a brand new string and copies all previous characters.

## Key excerpt

```go
func BenchmarkConcatWithBuilder(b *testing.B) {
	for i := 0; i < b.N; i++ {
		var sb strings.Builder
		for j := 0; j < 10000; j++ {
			sb.WriteString("Heeloo")
		}
		_ = sb.String()
	}
}

func BenchmarkConcatWithPlus(b *testing.B) {
	for i := 0; i < b.N; i++ {
		s := ""
		for j := 0; j < 10000; j++ {
			s += "Heeloo"
		}
	}
}
```

## Terms

- **String Immutability:** In Go, string byte arrays cannot be modified after creation; any modification requires allocating a new string.
- **strings.Builder:** An efficient type for accumulating strings without copying memory when converting to a string.
