## Overview

This program demonstrates text processing and manipulation functions available in Go's standard library `strings` package. It covers prefix/suffix testing, case conversions, whitespace and character trimming, splitting and joining, case-insensitive comparison with `strings.EqualFold`, high-performance string construction with `strings.Builder`, and multi-pattern string replacement with `strings.NewReplacer`.

## How it works

In `main`:
- Tests string prefixes and suffixes on URL string `str`.
- Locates character indices with `strings.Index` and `strings.LastIndex`.
- Converts casing via `ToUpper` and `ToLower`.
- Cleans whitespace and affixes via `TrimSpace`, `Trim`, `TrimPrefix`, and `TrimSuffix`.
- Splits comma-separated values with `strings.Split` and whitespace-separated tokens with `strings.Fields`.
- Joins string slices using `strings.Join`.
- Compares `"abx"` and `"Abx"`: case-sensitive comparison evaluates to false, while `strings.EqualFold` evaluates to true.
- Constructs strings efficiently using `strings.Builder` (`WriteString`, `WriteByte`, `Write`, `WriteRune`).
- Demonstrates `strings.NewReplacer` for HTML escaping and string template variable substitution (`{name}`, `{lang}`).

## Key excerpt

```go
	// Case insensitive
	if strings.EqualFold(a, b) {
		fmt.Println("Equal")
	}

	// Efficient concatanation
	var strB strings.Builder
	strB.WriteString("Hello")
	strB.WriteString("Go")
	strB.WriteByte('+')
	strB.Write([]byte("NewWorld"))
	strB.WriteRune(rune(233))
	print(strB.String())

	// Efficient replace
	r := strings.NewReplacer(
		"<", "&lt;",
		">", "&gt;",
		"&", "&amp;",
	)
	s := "<html> & go >"
	s = r.Replace(s)
	fmt.Println(s)
```

## Things to watch

- **EqualFold vs. ToLower:** `strings.EqualFold` performs Unicode case folding directly and is both faster and more linguistically accurate across Unicode alphabets than converting both strings to lowercase.

## Terms

- **EqualFold:** Compares two UTF-8 strings under Unicode case-folding rules without allocating new strings.
- **Replacer:** A pre-compiled multi-string replacement engine that scans the input text in a single pass.
