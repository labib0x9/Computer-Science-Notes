This program demonstrates date and time primitives in Go using the standard library `time` package. It showcases extracting date/time components (`Year`, `Month`, `Day`, `Hour`), arithmetic with `Add` and `AddDate`, pausing execution with `time.Sleep`, one-shot timers (`time.NewTimer`), periodic tickers (`time.NewTicker`), reference time formatting, and elapsed duration measurement (`time.Since`).

## How it works

In `main`:
- Captures current timestamp: `now := time.Now()`.
- Queries calendar and clock components: `Year()`, `Month()`, `Day()`, `Date()`, `Hour()`, `Minute()`, `Second()`, `Weekday()`.
- Calculates future timestamps: `now.Add(2 * time.Hour)` and calendar date jumps via `now.AddDate(1, 0, 0)`.
- Suspends goroutine with `time.Sleep(1 * time.Microsecond)`.
- Creates channels for events: one-shot `time.NewTimer` and recurring `time.NewTicker`.
- Formats timestamp using the canonical reference layout `"2006-01-02 15:04:05"`.
- Calculates elapsed duration since startup with `time.Since(now)`.

## Things to watch

- **The reference date layout:** Go does not use format tokens like `YYYY-MM-DD`. Instead, it uses a fixed reference timestamp: Mon Jan 2 15:04:05 MST 2006 (mnemonic: `1 2 3 4 5 6`). Using any other numbers in `Format()` will produce corrupt output.
- **Ticker leakage:** When done using `time.NewTicker`, always call `ticker.Stop()` to release underlying runtime resources.

## Terms

- **time.Duration:** An `int64` representing the elapsed nanoseconds between two instants.
- **Reference Time:** The canonical instant `01/02 03:04:05PM '06 -0700` used by Go to define format strings.
