## Overview

This program demonstrates character classification and casing operations in Go using the standard library `unicode` package. It illustrates how to test whether a Unicode rune is a letter, digit, whitespace, punctuation, or symbol, and how to apply Unicode-compliant uppercase, lowercase, and titlecase transformations.

## Concepts used

- Unicode character categories (`Letter`, `Digit`)
- Predicate checks: `IsDigit`, `IsLetter`, `IsSpace`, `IsSymbol`, `IsPunct`
- Case transformations: `ToLower`, `ToUpper`, `ToTitle`

## How it works

In `main`:
- Tests character membership against Unicode range tables: `unicode.Is(unicode.Letter, 'A')` and `unicode.Is(unicode.Digit, '4')`.
- Tests specific character classes:
  - `unicode.IsDigit('1')`: true.
  - `unicode.IsLetter('r')`: true.
  - `unicode.IsSpace('\n')`: true.
  - `unicode.IsSymbol(',')`: false (comma is punctuation).
  - `unicode.IsPunct('/')`: true.
- Transforms character casing: `unicode.ToLower('R')` yields `'r'`, `unicode.ToUpper('r')` yields `'R'`, and `unicode.ToTitle('r')` yields `'R'`.

## Things to watch

- **Rune vs. Byte:** All functions in `unicode` accept a `rune` (`int32`), allowing them to handle the entire Unicode codespace rather than just 8-bit ASCII characters.

## Terms

- **Unicode RangeTable:** A data structure defining a set of Unicode code point ranges belonging to a specific category or script.
- **Titlecase:** A casing mapping used for letters at the start of words in certain languages (e.g. Greek digraphs or German ligatures).
