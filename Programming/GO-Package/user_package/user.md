## Overview

This program demonstrates how to query operating system user account and group identity information in Go using the standard library `os/user` package. It showcases retrieving the current user's profile, resolving supplementary group IDs, and querying accounts by username or user ID.

## How it works

The file is an exploratory draft outlining `os/user` APIs:
- `user.Current()`: retrieves the `User` struct for the currently logged-in account.
- `User.GroupIds()`: returns a slice of supplementary group IDs.
- `User.Username`: accesses the login name.
- Outlines lookup functions: `user.Lookup` (by name), `user.LookupId` (by UID), `user.LookupGroup` (by group name), `user.LookupGroupId` (by GID).
- Outlines package error types: `user.UnknownUserError`, `user.UnknownGroupError`.

## Expected behavior (from reading the code, not run)

Because lookup functions are written without arguments (e.g. `user.Lookup()`), the file will not compile directly without passing query parameters (such as `user.Lookup("root")`). It serves as an exploratory cheatsheet of the package API.

## Things to watch

- **Cgo requirement on Linux:** In standard Linux builds, `os/user` utilizes Cgo to query NSS (Name Service Switch) libraries (`/etc/passwd`, LDAP). In pure Go static builds (`CGO_ENABLED=0`), `os/user` falls back to parsing `/etc/passwd` directly, which may not resolve network-authenticated domain users.

## Terms

- **UID / GID:** Unique numerical User Identifier and Group Identifier assigned by Unix operating systems.
- **HomeDir:** The path to the user's home directory.
