## Overview

This program demonstrates high-performance non-cryptographic hashing in Go using the `github.com/cespare/xxhash/v2` package, an implementation of the xxHash (XXH64) algorithm. xxHash operates at RAM speed limits, making it widely used in distributed caches, key-value stores (such as Prometheus and CockroachDB), and database indexing.

## How it works

In `main`:
- Instantiates a seeded hasher: `h := xxhash.NewWithSeed(11091021361343833604)`.
- Writes string data: `h.WriteString("Heelo")`.
- Computes and prints the 64-bit hash digest via `debug(h.Sum64())`.
- Resets the hasher with the identical seed: `h.ResetWithSeed(11091021361343833604)`.
- Writes `"Heelo"` again and prints `h.Sum64()`, proving determinism.

## Things to watch

- **Non-cryptographic usage:** xxHash is designed for throughput and dispersion, not security against deliberate collision attacks. Do not use for password hashing or cryptographic signatures.

## Terms

- **xxHash:** An extremely fast non-cryptographic hash algorithm working at speeds approaching RAM bus limits.
- **Determinism:** The property where identical inputs and seeds are guaranteed to produce identical hash outputs across platforms and executions.
