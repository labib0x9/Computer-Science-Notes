## How it works

1. `a1 := [...]int{}` declares an empty integer array of length 0 whose size is inferred from the literal elements.
2. `var a2 [3]int` declares an array of length 3, initialized with the default zero value (`[0, 0, 0]`).
3. `days := [...]string{1: "Saturday", 2: "Sunday"}` uses keyed composite literals:
   - Index 0 receives the zero value (`""`).
   - Index 1 is assigned `"Saturday"`.
   - Index 2 is assigned `"Sunday"`.
   - The array size is determined by the highest index specified ($2 + 1 = 3$).

## Things to watch

- **Arrays vs Slices**: An array in Go has a fixed size that is part of its type (e.g. `[3]int` is a completely different type from `[4]int`). Unlike slices, assigning or passing an array copies all its elements by value.

## Terms

- **Array**: A fixed-length sequence of contiguous elements of a single type.
- **Keyed Literal**: A composite literal syntax where elements are associated with specific indices or keys.
