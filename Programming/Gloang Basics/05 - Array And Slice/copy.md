## Overview

This program demonstrates common slice manipulation idioms in Go using the built-in `copy(dst, src)` function. It covers copying between distinct backing arrays, deleting a range of elements in-place, inserting elements at an arbitrary index, and clearing slices without reallocating memory.

## How it works

The code demonstrates four slice operations:
1. Independent copy:
   - `sl1 := []int{1, 2, 3, 4, 5}` and `sl2 := make([]int, 3)`.
   - `copy(sl2, sl1)` copies the first 3 elements into `sl2`. Modifying `sl1[0] = 1000` leaves `sl2` unchanged because they have independent backing arrays.
2. Range deletion:
   - Removes elements in index range `[2, 3]` from `s1` by shifting trailing elements left: `copy(s1[2:], s1[4:])`, followed by truncating the slice length.
3. Element insertion:
   - Appends a dummy element to `s2` to grow capacity, shifts elements at and after index 3 one position to the right with `copy(s2[4:], s2[3:])`, and assigns `s2[3] = 3`.
4. Fast zero-reallocation slice clearing:
   - Truncates slice length using sub-slice syntax: `s2 = s2[:0]`.

## Key excerpt

```go
	// Insert at index i = 3
	s2 := []int{0, 1, 2, 4, 5, 6}
	s2 = append(s2, -1)
	PrintSlice(s2[4:])
	PrintSlice(s2[3:])
	copy(s2[4:], s2[3:])
	s2[3] = 3
	PrintSlice(s2)

	// clear a slice without reallocation
	copy(s2, s2[:0])
	PrintSlice(s2)
```

## Things to watch

- **copy is bounded by len(dst)**: `copy` only copies `min(len(dst), len(src))` elements. If `dst` has length 0 (e.g. created with `var dst []int`), `copy(dst, src)` copies 0 elements.

## Terms

- **copy**: Built-in Go function that copies elements from a source slice into a destination slice, safely handling overlapping memory.
