## How it works

The `main` function serves as the entry point and demonstrates several declaration and slicing variations:
- Declares `var s1 []int`: creates a `nil` slice with a length of `0`, capacity of `0`, and an underlying pointer pointing to `nil`.
- Declares `s2 := []int{}`: creates an empty, non-nil slice with length `0` and capacity `0`, backed by an allocated empty array pointer.
- Allocates `s3 := make([]int, 0)`: creates an empty slice using `make`, specifying a length of `0` and defaulting capacity to `0`.
- Allocates `s4 := make([]int, 0, 10)`: creates an empty slice with length `0` while pre-allocating an underlying buffer capable of holding `10` elements before requiring reallocation.
- Initializes slice `arr := []int{1, 2, 4, 5, 6, 7, 8, 9, 10}`.
- Slices `arr` using standard two-index syntax: `s5 := arr[2:4]`. This creates a slice referencing elements at indices 2 and 3 (`[4, 5]`), with length `2` and capacity `7` (extending to the end of the backing array of `arr`).
- Slices `arr` using three-index syntax: `s6 := arr[3:5:5]`. This creates a slice referencing elements at indices 3 and 4 (`[5, 6]`), with length `2` (`5 - 3`) and capacity restricted to `2` (`5 - 3`).

## Things to watch

- **Compile-time enforcement:** Unused local variables (`s1` through `s6`) and the unused import `"fmt"` prevent the code from compiling directly under `go run` or `go build`.
- **Nil vs. Empty slice semantics:** `s1 == nil` evaluates to `true`, while `s2 == nil` and `s3 == nil` evaluate to `false`, even though `len` and `cap` equal `0` for all three. In JSON marshaling, a `nil` slice encodes as `null`, whereas an empty slice encodes as `[]`.
- **Three-index slice capacity control:** The full slice expression `arr[low:high:max]` caps the capacity at `max - low`. In `s6 := arr[3:5:5]`, capacity is set to 2. If a subsequent `append` is performed on `s6`, Go is forced to allocate a fresh backing array rather than overwriting existing elements in `arr`.

## Terms

- **Nil slice:** A slice whose underlying array pointer is `nil`, with length `0` and capacity `0`.
- **Capacity (cap):** The maximum number of elements a slice can hold without allocating a new backing array, measured from the slice's first element.
- **Full slice expression:** A slice expression of the form `a[low:high:max]` that sets both length (`high - low`) and capacity (`max - low`).
