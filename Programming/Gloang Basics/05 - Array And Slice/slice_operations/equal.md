## Overview

This file implements an element-by-element slice comparison function in Go. Because slices cannot be compared directly using the `==` operator (except against `nil`), this function validates that two integer slices have identical lengths and contain matching values at every corresponding index.

## How it works

The function `equal(a []int, b []int) bool`:
1. Compares slice lengths: `if len(a) != len(b) { return false }`.
2. Iterates from index 0 to `len(a) - 1`.
3. If any element `a[i] != b[i]`, it immediately returns `false`.
4. If all elements match, it returns `true`.

## Key excerpt

```go
func equal(a []int, b []int) bool {
	if len(a) != len(b){
		return false
	}

	for i := 0; i < len(a); i++ {
		if a[i] != b[i] {
			return false
		}
	}

	return true
}
```
