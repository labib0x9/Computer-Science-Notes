## How it works

The function `reverse(s []int) []int`:
1. Initializes two index pointers: `i = 0` (pointing to the first element) and `j = len(s) - 1` (pointing to the last element).
2. Runs a `for` loop while `i < j`, incrementing `i` and decrementing `j` after each iteration.
3. Swaps elements at `i` and `j` simultaneously using Go's tuple assignment: `s[i], s[j] = s[j], s[i]`.
4. Returns the modified slice `s`.

## Key excerpt

```go
func reverse(s []int) []int {
	for i, j := 0, len(s) - 1; i < j; i, j = i + 1, j - 1{
		s[i], s[j] = s[j], s[i]
	}
	return s
}
```
