## Concepts used

- The `main` package declaration (`package main`)
- Importing standard library packages (`import "fmt"`)
- Program entry point function (`func main()`)
- Formatted console output with `fmt.Println`

## How it works

1. `package main` declares that this source file belongs to the executable entry package.
2. `import "fmt"` imports the format I/O package.
3. `func main()` serves as the execution entry point called by the Go runtime.
4. `fmt.Println("Hello Goland !!")` outputs the greeting followed by a newline character.

## Key excerpt

