## Overview

This program demonstrates the fundamentals of memory pointers in Go. It shows how to obtain the memory address of a variable using `&`, store it in a pointer variable, and modify the underlying variable's value through pointer dereferencing with `*`.

## Concepts used

- Address-of operator (`&x`)
- Pointer types (`*int`)
- Pointer dereferencing operator (`*p`)
- Type safety in Go pointers (no arbitrary pointer arithmetic)

## How it works

1. `var x int` declares an integer initialized to 0.
2. `p := &x` assigns the memory address of `x` to pointer variable `p` of type `*int`.
3. `*p = 100` dereferences `p` and writes 100 to the memory location of `x`.
4. Printing `x` outputs `100`.

## Key excerpt

```go
func main() {

	var x int
	p := &x

	*p = 100 // dereferencing

	fmt.Println(x)
}
```

## Things to watch

- **No pointer arithmetic**: Go does not support C-style pointer arithmetic (e.g. `p++`). For low-level memory operations, Go requires the `unsafe` package.
- **Escape analysis**: In Go, variables whose addresses are taken can safely be returned from functions; the Go compiler's escape analysis automatically allocates them on the heap if they outlive their stack frame.

## Terms

- **Pointer**: A variable that holds the memory address of another variable.
- **Dereference**: Accessing or updating the value stored at the address contained in a pointer.
