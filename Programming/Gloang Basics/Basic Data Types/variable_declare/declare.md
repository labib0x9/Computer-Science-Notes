## Things to watch

- **Scope of :=**: The short variable declaration `:=` can only be used inside function bodies; package-level variables must be declared using `var`.
- **At least one new variable**: In multiple short assignment `a, b := ...`, at least one variable on the left side must be newly declared.

## Terms

- **Short Variable Declaration (`:=`)**: Shorthand syntax inside functions that infers the variable type from the right-hand expression.
- **Variadic Parameter**: A function parameter prefixed with `...` that accepts zero or more arguments of that type as a slice.
