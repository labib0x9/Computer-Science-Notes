## Overview

This program demonstrates Go's guarantee of zero initialization. Variables declared without an explicit initial value are automatically initialized with their type's default "zero value", preventing uninitialized memory bugs.

## Concepts used

- Zero value semantics in Go
- Primitive zero values (`0`, `0.0`, `false`, `""`)
- Reference and pointer zero values (`nil`)
- Composite struct zero values (all fields recursively zeroed)

## How it works

The code declares variables without values and inspects them:
1. `var name string`: Defaults to empty string `""`.
2. `var counter int`: Defaults to integer `0`.
3. `var flag bool`: Defaults to boolean `false`.
4. Pointers, slices, maps, channels, and interfaces default to `nil`.
5. Custom structs have each of their constituent fields initialized to their respective zero values.

## Things to watch

- **Nil slice vs Empty slice**: A nil slice (`var s []int`) has length 0 and capacity 0 and equals `nil`. It can be appended to with `append` safely without prior initialization.
- **Nil map hazard**: Reading from a nil map returns the zero value safely, but writing to a nil map (`m["key"] = 1`) triggers a runtime panic.

## Terms

- **Zero Value**: The default value assigned by Go when a variable is declared without an explicit value.
