## How it works

The code demonstrates:
1. `ifElse()`: Uses initialization expressions like `if val, err := strconv.Atoi(s); err == nil { ... }`. The variable `val` is scoped strictly within the `if` and `else` blocks.
2. `switchCase()`:
   - Standard switch matching integer cases. Go does not fall through to the next case by default (eliminating the need for explicit `break`).
   - Tagless switch evaluating arbitrary boolean conditions on each `case`.

## Things to watch

- **fallthrough keyword**: In Go, switch cases do not fall through by default. If fallthrough behavior is explicitly desired, the `fallthrough` keyword must be placed at the end of the case.
- **Variable shadowing in if init**: Declaring `if err := ...` shadows outer `err` variables within the scope of the if statement.

## Terms

- **Initialization Statement**: An optional simple statement executed before evaluating an if or switch condition.
