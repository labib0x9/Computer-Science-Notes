## Overview

This program demonstrates looping in Go. Since Go has only one looping keyword (`for`), it serves as while-loops, traditional three-component loops, and infinite loops. This example demonstrates three-component loops with `continue` and bitwise parity checks.

## Concepts used

- Three-component loop (`for init; condition; post`)
- Skipping loop iterations with `continue`
- Bitwise parity check (`i & 1 == 1`) to detect odd numbers

## How it works

1. It loops integer `i` from 0 to 15.
2. If `i % 5 == 0`, it skips the rest of the loop body using `continue`.
3. If `i & 1 == 1` (least significant bit is 1, meaning `i` is odd), it prints `"Odd"`.
4. Otherwise, it prints `"Even"`.

## Key excerpt

```go
func forLoop() {

	for i := 0; i <= 15; i++ {
		if i % 5 == 0 {
			continue
		}
		if i & 1 == 1 {
			fmt.Println("Odd")
		} else {
			fmt.Println("Even")
		}
	}
}
```

## Expected behavior (from reading the code, not run)

- Loops through numbers 0 to 15, skips multiples of 5 (0, 5, 10, 15), and prints `"Odd"` or `"Even"` for the remaining integers.

## Things to watch

- **Single loop construct**: Go intentionally omits `while` and `do-while` keywords. A while loop is written as `for condition { ... }`, and an infinite loop as `for { ... }`.

## Terms

- **continue**: Skips the current iteration of the innermost loop and advances to the post-statement.
- **Bitwise AND (&)**: Compares each bit of two numbers; `i & 1` tests if the lowest bit is set.
