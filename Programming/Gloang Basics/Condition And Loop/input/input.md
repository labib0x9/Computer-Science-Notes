## Overview

This program demonstrates multiple techniques for reading user input from standard input (`os.Stdin`) in Go, comparing formatted scanning via `fmt.Scanf` with buffered line-by-line reading using `bufio.Reader` and `bufio.Scanner`.

## Concepts used

- Reading formatted input with `fmt.Scanf`
- Buffered stream reading with `bufio.NewReader(os.Stdin).ReadString`
- Line scanning using `bufio.NewScanner`

## How it works

The code demonstrates:
1. `scanfInput()`: Reads formatted integers into pointers: `fmt.Scanf("%d %d", &a, &b)`.
2. `bufioInput()`: Reads raw input lines up to a delimiter character: `reader.ReadString('\n')`.
3. `scannerInput()`: Uses `bufio.NewScanner(os.Stdin)` in a `for scanner.Scan()` loop, reading tokens or lines via `scanner.Text()`.

## Key excerpt

```go
func scanfInput() {
	var a, b int
	fmt.Scanf("%d %d", &a, &b)
	fmt.Println("Scanned:", a, b)
}

func bufioInput() {
	reader := bufio.NewReader(os.Stdin)
	str, err := reader.ReadString('
')
	if err != nil && err != io.EOF {
		log.Fatal(err)
	}
	fmt.Print("Read:", str)
}
```

## Things to watch

- **Leftover newline characters**: `fmt.Scanf` does not consume trailing newline characters unless explicitly instructed in the format string (e.g. `"%d\n"`). For interactive CLI tools, `bufio.Scanner` is typically more robust.

## Terms

- **bufio.Scanner**: A helper providing a convenient interface for reading data such as a file of newline-delimited lines.
