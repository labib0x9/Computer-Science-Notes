## How it works

1. `division(a int, b int) (int, error)`:
   - Checks if divisor `b == 0`.
   - If true, returns `0` alongside a descriptive error created with `errors.New("error: can't divide by zero")`.
   - Otherwise, returns `a / b` and `nil` for error.
2. In `main`:
   - Calls `division(10, 2)`, checks `err != nil`, and prints result `5`.
   - Calls `division(10, 0)`, detects the non-nil error, and handles the error gracefully without crashing.

## Key excerpt

```go
func division(a int, b int) (int, error) {
	if b == 0 {
		return 0, errors.New("error: can't divide by zero")
	}
	return a / b, nil
}
```

## Expected behavior (from reading the code, not run)

- Prints successful division results.
- Prints `error: can't divide by zero` when division by zero is attempted.

## Things to watch

- **Always check errors first**: In Go, the value of the non-error return item is typically undefined or zeroed when `err != nil`; callers should never rely on result values when an error is returned.

## Terms

- **Multiple Return Values**: Go's ability for a function to return more than one value without requiring a wrapper struct or tuple.
