This program provides a comprehensive guide to file system operations in Go. It covers file creation, opening existing files, setting POSIX file permissions (`0644`), buffered reading with `bufio.Scanner`, reading entire files with `os.ReadFile`, and writing data with `os.WriteFile`.

## Concepts used

- Creating and truncating files via `os.Create`
- Opening files with flags (`os.OpenFile(path, os.O_RDWR|os.O_CREATE|os.O_APPEND, perm)`)
- Buffered line-by-line reading with `bufio.NewScanner`
- Atomic high-level utilities `os.ReadFile` and `os.WriteFile`
- Resource cleanup using `defer file.Close()`

## How it works

The code explores multiple file operations:
1. `os.Create("test.txt")`: Creates or truncates a file, returning an `*os.File`.
2. Writing data: Uses `file.WriteString()` or `io.WriteString()`.
3. Reading data:
   - Line-by-line streaming: `scanner := bufio.NewScanner(file)` in a `for scanner.Scan()` loop reads records without loading the whole file into RAM.
   - Bulk read: `os.ReadFile("test.txt")` loads all bytes into a slice.
4. Closing: Every opened file descriptor is paired with `defer file.Close()`.

## Key excerpt

```go
const FilePerm = 0644 // File permission: -rw-r--r--

func createFile(filename string) {
	file, err := os.Create(filename)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	_, err = file.WriteString("Hello, Go File Operations!\n")
	if err != nil {
		log.Fatal(err)
	}
}
```

## Things to watch

- **Check Close errors on write**: When writing to files, checking the error returned by `file.Close()` is important because buffered OS writes may fail during the final flush when closing.
- **Scanner line length limit**: `bufio.Scanner` defaults to a maximum token buffer of 64KB (`bufio.MaxScanTokenSize`). Lines exceeding 64KB trigger `bufio.ErrTooLong`; use `bufio.Reader` for arbitrarily long lines.

## Terms

- **os.File**: A struct representing an open file descriptor in Go.
- **File Permissions (0644)**: Octal notation for user read/write, group read, others read.
