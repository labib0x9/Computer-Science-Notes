## Overview

This program demonstrates Go's exception-like panic and recover mechanism. It shows how a deferred anonymous function intercepts an active panic using `recover()`, preventing process termination and allowing graceful error handling.

## Concepts used

- Triggering panics with `panic()`
- Capturing panics with `recover()`
- Deferring recovery closures
- Normal execution resumption after recovery

## How it works

1. `divide(a, b int)` registers a deferred anonymous function before executing arithmetic.
2. Inside the deferred closure:
   - `r := recover()` is called. If the function is panicking, `recover()` stops the panic unwinding and returns the value passed to `panic()`.
   - It logs `"Recieved :"` and prints the panic value.
3. When `b == 0`, `panic("Can't divide by zero")` triggers.
4. The panic unwinds the stack to the deferred closure, where `recover()` intercepts it.
5. In `main()`, `divide(10, 0)` is called; because the panic was recovered, `main()` continues and exits cleanly.

## Key excerpt

```go
func divide(a, b int) {

	defer func() {
		if r := recover(); r != nil {
			fmt.Println("Recieved :")
		}
	}()

	if b == 0 {
		panic("Can't divide by zero")
	}

	fmt.Println(a / b)
}
```

## Expected behavior (from reading the code, not run)

- Calling `divide(10, 0)` triggers a panic, which is caught by `recover()`.
- Prints `Recieved :` and completes without crashing the program.

## Things to watch

- **recover must be inside defer**: Calling `recover()` outside a deferred function returns `nil` and has no effect.
- **Idiomatic error handling**: In Go, `panic` and `recover` are reserved for truly unexpected or unrecoverable conditions (like programmer bugs or nil pointer dereferences). Normal operational failures should return `error` values.
- **Typo in string**: The print message outputs `"Recieved :"` (misspelled).

## Terms

- **panic**: Built-in function that stops the ordinary flow of control and begins unwinding the goroutine stack.
- **recover**: Built-in function that regains control of a panicking goroutine.
