## Overview

This program demonstrates higher-order functions in Go, showing how functions can be passed as arguments to other functions. It passes an inline comparison function to `sort.Slice` to sort a slice of `Person` structs by age.

## How it works

1. It defines struct `Person` with `Name string` and `Age int`.
2. It initializes a slice `people` containing multiple `Person` records with unsorted ages.
3. It invokes `sort.Slice(people, func(i, j int) bool { return people[i].Age < people[j].Age })`.
4. `sort.Slice` calls the comparison function repeatedly during sorting to determine relative element ordering.
5. `fmt.Println(people)` outputs the slice sorted in ascending order of `Age`.

## Key excerpt

```go
type Person struct {
	Name string
	Age int
}

func main() {

	people := []Person {
		{Name: "Alice", Age: 30},
		{Name: "Bob", Age: 25},
		{Name: "Charlie", Age: 35},
	}

	sort.Slice(people, func(i, j int) bool {
		return people[i].Age < people[j].Age
	})

	fmt.Println(people)
}
```

## Things to watch

- **sort.Slice vs sort.SliceStable**: `sort.Slice` does not guarantee stability (equal elements may change relative order). If preserving original ordering for equal keys is required, use `sort.SliceStable`.
- **Modern slices.SortFunc**: In Go 1.21+, `slices.SortFunc` provides generic sorting without reflection overhead.

## Terms

- **Higher-Order Function**: A function that accepts another function as an argument or returns a function.
- **Comparator**: A function defining the ordering relationship between two elements.
