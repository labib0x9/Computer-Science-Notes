## How it works

1. `sum(v ...int) int`:
   - Inside `sum`, `v` is treated as a standard integer slice `[]int`.
   - It iterates over `v`, accumulating `total` and logging running sums.
2. In `main`:
   - Calling `sum(1, 2, 3)` passes individual arguments.
   - Calling `nums := []int{4, 5, 6}; sum(nums...)` unpacks the slice into variadic arguments directly.
   - `reflect.TypeOf(v)` confirms that `v` has type `[]int`.

## Key excerpt

```go
func sum(v ...int) int {
	total := 0
	for i := range v {
		total += v[i]
		fmt.Println(v[i], total)
	}
	return total
}
```

## Things to watch

- **Variadic parameter placement**: A function can have at most one variadic parameter, and it must be the final parameter in the signature.
- **Slice sharing**: When passing an existing slice with `slice...`, no copy of the slice elements is created; the variadic parameter references the same backing array.

## Terms

- **Variadic Function**: A function that accepts a variable number of arguments.
- **Slice Unpacking**: Appending `...` to a slice argument to pass its elements as individual parameters to a variadic function.
