## Overview

This program demonstrates variable shadowing applied to function parameters in Go. It shows how an inner block can declare a new variable shadowing a parameter while simultaneously using the outer parameter's value during initialization.

## Concepts used

- Function parameter scoping
- Shadowing parameters in nested blocks
- Right-hand side evaluation precedence during declaration (`x := x + 10`)

## How it works

1. `foo(x int)`:
   - Prints parameter `x` (e.g. `5`).
   - Opens an inner block: `x := x + 10`.
   - On the right side, `x + 10` reads the outer parameter `5`, evaluating to `15`.
   - The left side declares a new local variable `x = 15` shadowing the parameter within that block.
   - Prints inner `x` (`15`).
2. Outside the block, `x` reverts to the unmodified parameter value (`5`).
3. In `main()`, `foo(5)` is called.

## Key excerpt

```go
func foo(x int) {
	fmt.Println(x)
	{
		x := x + 10
		fmt.Println(x)
	}
	fmt.Println(x)
}

func main() {
	foo(5)
}
```

## Things to watch

- **Right-hand side resolution**: During `x := x + 10`, the new variable `x` is not yet in scope when evaluating the right-hand expression, so the right-hand `x` safely binds to the outer parameter.

## Terms

- **Parameter Scope**: The scope of function arguments, which spans the entire function body unless shadowed by an inner block.
