## Overview

This program demonstrates foundational generic programming introduced in Go 1.18. It defines a generic utility function `Print[T any]` that operates on slices of any element type without sacrificing compile-time type safety.

## Concepts used

- Generic type parameter lists (`[T any]`)
- The `any` constraint (alias for `interface{}`)
- Slice iteration over parameterized types (`[]T`)
- Type inference at call sites

## How it works

1. `Print[T any](arr []T)` declares type parameter `T` constrained by `any`.
2. The function accepts a slice of `T` and iterates through elements using `for _, value := range arr`.
3. `fmt.Println(value)` prints each element.
4. Callers can invoke `Print([]int{1, 2, 3})` or `Print([]string{"a", "b"})`; the Go compiler automatically infers `T` from the argument type.

## Key excerpt

```go
func Print[T any] (arr []T) {
	for _, value := range arr {
		fmt.Println(value)
	}
}
```

## Things to watch

- **any vs comparable**: The `any` constraint allows any type, but does not permit comparison operators (`==`, `!=`). If elements must be compared for equality, use `comparable`.

## Terms

- **Type Parameter**: A placeholder for a concrete type specified in brackets `[...]` after a function or type name.
- **any**: A predeclared identifier in Go that is an alias for the empty interface (`interface{}`).
