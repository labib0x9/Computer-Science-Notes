## Overview

This program demonstrates generic struct types in Go. It implements a type-safe LIFO `Stack` that can store elements of any type `T` using an underlying slice.

## Concepts used

- Generic struct definitions (`type Stack[T any] struct`)
- Method receivers with type parameters (`func (s *Stack[T]) Push(val T)`)
- Type safety without `interface{}` boxing

## How it works

1. `type Stack[T any] struct { st []T }` declares a generic stack backed by slice `st`.
2. Method `Push(val T)` receives pointer `(s *Stack[T])` and appends `val` to `s.st`.
3. Instances can be declared for specific types: `sInt := Stack[int]{}` or `sStr := Stack[string]{}`.
4. Unlike pre-generics `interface{}` stacks, elements require no runtime type assertions when popped.

## Things to watch

- **Method type parameter naming**: Methods on generic types must repeat the type parameter list in the receiver (`*Stack[T]`), but cannot introduce new type parameters that were not defined on the struct itself.

## Terms

- **Generic Type**: A type whose definition includes type parameters, instantiated with concrete type arguments.
