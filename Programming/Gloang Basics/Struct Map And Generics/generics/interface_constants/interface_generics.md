## Overview

This program demonstrates how to define custom generic type constraints using interface type unions and the tilde (`~`) approximation operator in Go.

## Concepts used

- Interface type constraints with type union (`|`)
- The tilde approximation operator (`~T`)
- Generic operators (`+`) permitted by type constraints

## How it works

1. `Adder` interface:
   ```go
   type Adder interface {
       ~int | ~float32
   }
   ```
   - Specifies a type union accepting types that are `int` or `float32`.
   - The tilde `~` indicates that any custom defined type whose underlying type is `int` (e.g. `type MyInt int`) also satisfies `Adder`.
2. `Add[T Adder](a, b T) T`:
   - Since both `int` and `float32` support the `+` operator, the Go compiler permits `a + b` inside the generic function.

## Key excerpt

```go
type Adder interface {
	~int | ~float32
}

func Add[T Adder](a, b T) T {
	return a + b
}
```

## Expected behavior (from reading the code, not run)

- Can be called with primitive integers (`Add(2, 3)`), floats (`Add(1.5, 2.5)`), or derived custom types (`type MyInt int; Add(MyInt(1), MyInt(2))`).
- Calling with strings or other types fails at compile time.

## Things to watch

- **Tilde restriction**: The tilde `~T` operator requires `T` to be an underlying primitive type. Expressions like `~interface{}` or `~MyStruct` with non-underlying types are illegal.

## Terms

- **Type Constraint**: An interface that defines the set of permissible type arguments for a type parameter.
- **Tilde Operator (`~`)**: In generic interfaces, matches any type whose underlying type is the specified type.
