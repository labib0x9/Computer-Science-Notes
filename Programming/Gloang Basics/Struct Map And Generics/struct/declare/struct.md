## Things to watch

- **Field export visibility**: Fields starting with a capital letter (like `Name`) are exported and accessible to other packages; fields starting with a lowercase letter are unexported (private to the defining package).

## Terms

- **Struct**: A composite type in Go that groups together zero or more named fields of arbitrary types.
- **Composite Literal**: Syntax that constructs a new value for a composite type by listing its elements.
