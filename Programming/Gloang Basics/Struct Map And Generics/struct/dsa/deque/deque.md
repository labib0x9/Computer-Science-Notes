## Overview

This program demonstrates how to implement a double-ended queue (deque) data structure in Go using a struct wrapping an integer slice. It provides methods to push and pop elements from both the front and back of the queue.

## How it works

1. `Deque` struct wraps slice `dq []int`.
2. `NewDeque()` allocates an empty deque with `make([]int, 0)`.
3. Methods:
   - `PushBack(val)`: Appends `val` to the end of `dq`.
   - `PushFront(val)`: Prepends `val` to the beginning by creating a new slice `append([]int{val}, d.dq...)`.
   - `PopBack()`: Reads the last element and truncates length via `d.dq[:len(d.dq)-1]`.
   - `PopFront()`: Reads element at index 0 and reslices via `d.dq[1:]`.
   - Returns errors if `Pop` is attempted on an empty deque.

## Key excerpt

```go
type Deque struct {
	dq []int
}

func (d *Deque) PushFront(val int) {
	d.dq = append([]int{val}, d.dq...)
}

func (d *Deque) PopFront() (int, error) {
	if d.Len() == 0 {
		return 0, errors.New("empty deque")
	}
	val := d.dq[0]
	d.dq = d.dq[1:]
	return val, nil
}
```

## Things to watch

- **Prepend performance**: `append([]int{val}, d.dq...)` copies all existing elements on every `PushFront`, resulting in $O(N)$ time complexity. For production deques, use a ring buffer or doubly linked list to achieve $O(1)$ operations at both ends.
