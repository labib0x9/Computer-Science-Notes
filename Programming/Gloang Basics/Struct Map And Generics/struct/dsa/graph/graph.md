## Key excerpt

```go
type Graph struct {
	child map[int][]int
}

func NewGraph() *Graph {
	return &Graph{
		child: make(map[int][]int),
	}
}

func (g *Graph) AddEdge(u, v int) {
	g.child[u] = append(g.child[u], v)
}
```

## Things to watch

- **Undirected edges**: For undirected graphs, `AddEdge` must add edges in both directions: `g.child[u] = append(g.child[u], v)` and `g.child[v] = append(g.child[v], u)`.

## Terms

- **Adjacency List**: A graph representation where each vertex stores a list of adjacent destination vertices.
- **Directed Graph**: A graph where edges have a defined direction from one vertex to another.
