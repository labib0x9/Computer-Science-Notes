## Key excerpt

```go
type Qeque struct {
	que []int
}

func (q *Qeque) Push(val int) {
	q.que = append(q.que, val)
}

func (q *Qeque) Pop() (int, error) {
	if q.Len() == 0 {
		return 0, errors.New("empty queue")
	}
	val := q.que[0]
	q.que = q.que[1:]
	return val, nil
}
```

## Things to watch

- **Memory retention in slice re-slicing**: Using `q.que = q.que[1:]` does not free the memory occupied by popped elements; the underlying backing array remains referenced. In high-throughput long-lived queues, periodically copy active elements to a new slice or use a ring buffer.
- **Spelling**: The type is declared as `Qeque` and constructor as `NewDeque`.

## Terms
