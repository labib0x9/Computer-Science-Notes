## How it works

1. `Stack` struct wraps `st []int`.
2. `NewStack()` initializes an empty stack.
3. `Push(val)`: Appends `val` to `s.st`.
4. `Pop()`: Checks `IsEmpty()`. If not empty, retrieves the top element at `len(s.st) - 1`, truncates the slice via `s.st = s.st[:len(s.st)-1]`, and returns the element.
5. `Top()`: Returns the last element without modifying the slice.

## Key excerpt

```go
type Stack struct {
	st []int
}

func (s *Stack) Push(val int) {
	s.st = append(s.st, val)
}

func (s *Stack) Pop() (int, error) {
	if s.IsEmpty() {
		return 0, errors.New("empty stack")
	}
	top := s.st[len(s.st)-1]
	s.st = s.st[:len(s.st)-1]
	return top, nil
}
```

## Things to watch

- **Memory management for pointers**: When popping elements from a slice storing pointers (`[]*T`), explicitly zero out the popped slot (`s.st[len-1] = nil`) before truncating to allow the garbage collector to reclaim the referenced object immediately.

## Terms

- **LIFO (Last-In, First-Out)**: An ordering principle where the most recently added element is the first one removed.
- **Top / Peek**: Inspecting the head element of the stack without popping it.
