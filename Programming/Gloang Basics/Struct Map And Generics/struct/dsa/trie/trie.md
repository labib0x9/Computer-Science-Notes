## Overview

This program demonstrates how to implement a prefix tree (Trie) in Go. It supports full Unicode character sets by using a `map[rune]*Node` for child pointers, enabling word insertion, exact word search, and prefix matching.

## How it works

1. `Node` contains `children map[rune]*Node` and boolean `isEnd`.
2. `Trie` encapsulates pointer `root *Node`.
3. `Insert(word string)`: Iterates over the string's runes. For each rune, navigates to or creates the corresponding child node. Marks the final node with `isEnd = true`.
4. `Search(word string) bool`: Follows the rune path. Returns `true` only if all runes match and the final node has `isEnd == true`.
5. `StartsWith(prefix string) bool`: Follows the rune path. Returns `true` if the prefix path exists, regardless of `isEnd`.

## Key excerpt

```go
type Node struct {
	children map[rune]*Node
	isEnd    bool
}

type Trie struct {
	root *Node
}

func (t *Trie) Insert(word string) {
	curr := t.root
	for _, ch := range word {
		if _, exists := curr.children[ch]; !exists {
			curr.children[ch] = &Node{children: make(map[rune]*Node)}
		}
		curr = curr.children[ch]
	}
	curr.isEnd = true
}
```

## Things to watch

- **Rune vs Byte**: Using `rune` allows the Trie to handle non-ASCII Unicode characters (e.g. accented characters, emojis, Asian scripts) seamlessly.
- **Memory overhead**: Maps provide flexibility for sparse Unicode trees, but have higher memory overhead than fixed `[26]*Node` arrays used in English-only tries.

## Terms

- **Trie (Prefix Tree)**: A tree-like search data structure used to store a dynamic set of strings where keys are usually sequences of characters.
- **rune**: An alias for `int32` in Go representing a single Unicode code point.
