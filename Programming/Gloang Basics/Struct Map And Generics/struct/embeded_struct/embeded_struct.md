## Overview

This program demonstrates struct embedding (composition) in Go. By embedding an anonymous type within an outer struct, the inner type's fields and methods are automatically promoted to the outer struct, achieving code reuse without classical object-oriented inheritance.

## How it works

1. It defines inner struct `Person` with fields `Name` and `Age`.
2. It defines outer struct `Employee` containing an embedded `Person` field:
   ```go
   type Employee struct {
       Person // embedded type
       Position string
       EmployeeId string
   }
   ```
3. In `main`:
   - An `Employee` is instantiated with an embedded `Person`.
   - Fields of `Person` are accessed directly through field promotion: `emp.Name` and `emp.Age`.
   - They can also be accessed through the explicit qualification path: `emp.Person.Name`.

## Key excerpt

```go
type Person struct {
	Name string
	Age int
}

type Employee struct {
	Person	// embeded type
	Position string
	EmployeeId string
}

func main() {
	emp := Employee{
		Person: Person{Name: "Alice", Age: 30},
		Position: "Engineer",
		EmployeeId: "E123",
	}

	fmt.Println(emp.Name, emp.Position)
}
```

## Things to watch

- **Field collisions and shadowing**: If the outer struct defines a field with the exact same name as an embedded field, the outer field shadows the inner field; the inner field remains accessible via its explicit type path (e.g. `emp.Person.Name`).

## Terms

- **Struct Embedding**: Placing a type name without a field name inside a struct to embed its fields and methods.
- **Field Promotion**: The automatic ability to access embedded fields and methods directly from the outer struct instance.
