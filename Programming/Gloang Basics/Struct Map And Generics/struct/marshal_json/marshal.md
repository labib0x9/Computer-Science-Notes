## Overview

This program demonstrates how to serialize Go structs and slices into JSON byte arrays using the standard `encoding/json` package. It showcases custom struct field renaming via `json:"..."` tags and pretty-printing with `json.MarshalIndent`.

## Concepts used

- Struct field tagging (`json:"released"`)
- JSON serialization via `json.Marshal`
- Pretty-printing JSON with `json.MarshalIndent`
- Converting byte slices to strings for display

## How it works

1. It defines `Movie` struct:
   - `Title string`: Encoded as `"Title"`.
   - `Year int json:"released"`: Custom tag causes the JSON key to be `"released"`.
2. In `Marshal()`:
   - A slice of `Movie` structs `movieList` is populated.
   - `json.Marshal(movieList)` converts the slice to compact JSON.
   - `json.MarshalIndent(movieList, "", "  ")` formats the JSON with 2-space indentation.
   - Outputs both representations to the console.

## Key excerpt

```go
type Movie struct {
	Title string
	Year int `json:"released"`
}

func Marshal() {

	movieList := []Movie{
		{Title: "Casablanca", Year: 1942},
		{Title: "Cool Hand Luke", Year: 1967},
	}

	data, err := json.Marshal(movieList)
	if err != nil {
		fmt.Println("Error:", err)
		return
	}
	fmt.Println(string(data))
}
```

## Things to watch

- **Exported fields only**: Go's `encoding/json` package relies on reflection and can only serialize exported struct fields (fields beginning with an uppercase letter). Unexported fields are completely ignored during marshaling.

## Terms

- **JSON Marshaling**: The process of converting Go data structures into a JSON byte stream.
- **Struct Tag**: Metadata string attached to struct fields used by encoders, decoders, and ORMs.
