## Overview

This program demonstrates how to implement a fluent interface using method chaining in Go. By having pointer receiver methods return the receiver pointer (`return t`), multiple method calls can be chained together sequentially in a single expressive statement.

## Concepts used

- Method receiver return chaining (`return t`)
- Fluent API design pattern
- Pointer receivers for in-place mutation

## How it works

1. `Teacher` struct defines fields `Name`, `Age`, and `Id`.
2. Pointer receiver methods:
   - `(t *Teacher) setName(Name string) *Teacher`: Mutates `t.Name` and returns `t`.
   - `(t *Teacher) setAge(Age int) *Teacher`: Mutates `t.Age` and returns `t`.
   - `(t *Teacher) setId(Id string) *Teacher`: Mutates `t.Id` and returns `t`.
3. In `main`:
   - A `Teacher` pointer is created and chained:
     ```go
     t := (&Teacher{}).setName("John").setAge(35).setId("T101")
     ```
   - Prints the configured struct.

## Key excerpt

```go
type Teacher struct {
	Name string
	Age  int
	Id string
}

func (t *Teacher) setName(Name string) *Teacher {
	t.Name = Name
	return t
}

func (t *Teacher) setAge(Age int) *Teacher {
	t.Age = Age
	return t
}
```

## Expected behavior (from reading the code, not run)

- Evaluates the chained setter methods in sequence on the same struct instance.
- Prints the populated `Teacher` struct fields.

## Things to watch

- **Pointer receiver necessity**: Returning `*Teacher` ensures that mutations persist across all chained invocations on the original object. If a value receiver were used, each method would operate on and return a separate copy.

## Terms

- **Method Chaining**: Calling multiple methods successively on the same object in a single line of code.
- **Fluent Interface**: An API design that relies on method chaining to provide code that reads like natural language.
