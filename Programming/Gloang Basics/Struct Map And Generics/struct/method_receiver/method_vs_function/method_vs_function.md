## Overview

This program demonstrates that methods in Go are not restricted to struct types; they can be defined on any user-defined named type in the same package, including types whose underlying type is an integer primitive.

## Concepts used

- Custom named types on primitives (`type xyz int`)
- Attaching methods to non-struct types
- Method invocation via dot syntax (`a.SayHelloAgain()`)

## How it works

1. It defines custom type `type xyz int`.
2. It attaches a method to `xyz`:
   ```go
   func (x xyz) SayHelloAgain() {
       fmt.Println("Hello Again from xyz:", x)
   }
   ```
3. In `Blabla()`:
   - Variable `var a xyz = 10` is initialized.
   - It invokes `a.SayHelloAgain()`.

## Key excerpt

```go
// xyz custom data type
type xyz int

func (x xyz) SayHelloAgain() {
	fmt.Println("Hello Again from xyz:", x)
}

func Blabla(){

	var a xyz
	a = 10

	a.SayHelloAgain()

```

## Expected behavior (from reading the code, not run)

- Calls `SayHelloAgain()` on integer wrapper `a`.
- Prints `Hello Again from xyz: 10`.

## Things to watch

- **Same package constraint**: In Go, methods can only be defined on types declared within the same package. You cannot define methods on built-in types directly (e.g. `func (i int) Foo()`), which is why a custom named type like `type xyz int` is required.

## Terms

- **Method Receiver**: The parameter appearing before the function name that associates the function with a specific type.
