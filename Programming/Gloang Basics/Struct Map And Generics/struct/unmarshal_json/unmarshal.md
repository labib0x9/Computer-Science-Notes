## Overview

This program demonstrates JSON deserialization in Go using `json.Unmarshal`. It shows how to decode a JSON payload containing nested objects and snake_case keys into typed Go structs with pointer fields.

## Concepts used

- JSON deserialization with `json.Unmarshal`
- Mapping nested JSON objects to struct pointers
- Matching JSON keys with struct tags (`json:"total_count"`)
- Passing pointers to destinations in `Unmarshal`

## How it works

1. It defines nested structs:
   - `Issue`: Contains `TotalCount int`, `HTMLURL string`, and pointer `User *IssueUser`.
   - `IssueUser`: Contains `Name string`.
2. A raw JSON byte slice representing issue metadata is defined.
3. It declares `var issue Issue` and calls `json.Unmarshal(data, &issue)`.
4. `json.Unmarshal` parses the byte stream, matches JSON keys against struct tags, allocates the nested `IssueUser` struct on the heap, and populates the fields.
5. In `main`, it accesses `issue.User.Name` and prints the issue details.

## Key excerpt

```go
type Issue struct {
	TotalCount int        `json:"total_count"`
	HTMLURL    string     `json:"html_url"`
	User       *IssueUser `json:"user"`
}

type IssueUser struct {
	Name string `json:"name"`
}

func main() {
	var issue Issue
	err := json.Unmarshal([]byte(jsonData), &issue)
	if err != nil {
		panic(err)
	}
	fmt.Println(issue.TotalCount, issue.User.Name)
}
```

## Things to watch

- **Pass a pointer to Unmarshal**: The second argument to `json.Unmarshal` must be a non-nil pointer (e.g. `&issue`). Passing a non-pointer value returns an `InvalidUnmarshalError`.
- **Nil pointer checks**: If the input JSON does not include the `"user"` key, `issue.User` remains `nil`; dereferencing `issue.User.Name` without checking `if issue.User != nil` causes a nil pointer panic.

## Terms
