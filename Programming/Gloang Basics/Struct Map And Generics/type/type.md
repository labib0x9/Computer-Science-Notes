## How it works

The code defines three distinct types:
1. `type score int`: Defines `score` as a new distinct type with `int` as its underlying type. Even though underlying types match, `score` and `int` cannot be mixed in arithmetic without explicit casting.
2. `type converter func(string) score`: Defines a function type that accepts a string and returns a `score`.
3. `type teamScore map[string]score`: Defines a map type mapping strings to custom `score` values.

## Things to watch

- **Type definition vs Type alias**: `type score int` creates a new distinct type requiring explicit conversions. In contrast, `type score = int` creates a type alias, where `score` and `int` are completely interchangeable.

## Terms

- **Underlying Type**: The foundational primitive or composite type that a custom defined type is based upon.
- **Type Definition**: A declaration that introduces a new, distinct named type.
