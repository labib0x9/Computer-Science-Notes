## Overview

This program demonstrates how to design testable command-line interactive applications in Go. Instead of hardcoding standard input (`os.Stdin`), its input-handling functions accept an `io.Reader` interface parameter, allowing automated test suites to mock user keyboard input using in-memory string readers.

## How it works

1. `isPrime(n int) (bool, string)`: Evaluates whether `n` is prime and returns a descriptive message.
2. `checkInput(scanner *bufio.Reader) (string, bool)`:
   - Reads a line from `scanner`.
   - Strips whitespace.
   - If the user types `"q"`, exits.
   - Parses the integer with `strconv.Atoi` and evaluates `isPrime`.
3. In `main()`:
   - Wraps `os.Stdin` in `bufio.NewReader(os.Stdin)` and runs an interactive prompt loop.

## Key excerpt

```go
func isPrime(n int) (bool, string) {
	if n == 0 || n == 1 {
		return false, fmt.Sprintf("%d is not a prime", n)
	}
	if n == 2 {
		return true, fmt.Sprintf("%d is a prime", n)
	}
	if n%2 == 0 {
		return false, fmt.Sprintf("%d is not a prime, divisible by 2", n)
	}
```
