## Overview

This test file demonstrates how to unit test console input functions in Go. By supplying `strings.NewReader("5\n")` to `bufio.NewReader`, the test simulates user keyboard input without requiring user interaction.

## How it works

1. `TestcheckInput(t *testing.T)`:
   - Instantiates an in-memory string reader: `reader := bufio.NewReader(strings.NewReader("5\n"))`.
   - Calls `message, _ := checkInput(reader)`.
   - `checkInput` reads the simulated string `"5"`, evaluates `isPrime(5)`, and returns the prime confirmation message.
2. `TestreadUserInput(t *testing.T)`:
   - Uses `bytes.Buffer` to verify input and output streams.

## Things to watch

- **Trailing newlines in simulated input**: Console readers expecting `
` line delimiters will block or hang waiting for EOF unless the mock string explicitly includes `
`.

## Terms

- **strings.Reader**: An in-memory reader that implements `io.Reader`, `io.ByteScanner`, and `io.RuneScanner` over a string.
