## How it works

1. `UserService` holds a private field `repo UserRepository`.
2. `NewUserService(repo UserRepository) *UserService` accepts any implementation of `UserRepository` and returns an initialized service.
3. `GetUserName(id int) (string, error)`:
   - Calls `u.repo.FindById(id)`.
   - If an error occurs, returns an empty string and the error.
   - Otherwise, returns the user's name.

## Key excerpt

```go
type UserService struct {
	repo UserRepository
}

func NewUserService(repo UserRepository) *UserService {
	return &UserService{
		repo: repo,
	}
}

func (u *UserService) GetUserName(id int) (string, error) {
	user, err := u.repo.FindById(id)
	if err != nil {
		return "", err
	}
	return user.Name, nil
}
```
