## How it works

1. `Add(a, b int) int`: Returns `a + b`.
2. `IsPalindrome(msg string) bool`:
   - Iterates `i` from 0 up to `n / 2`.
   - Compares character at `msg[i]` with character from opposite end `msg[n - i - 1]`.
   - Returns `false` on any mismatch; returns `true` if all mirror characters match.

## Key excerpt

```go
func Add(a, b int) int {
	return a + b
}

func IsPalindrome(msg string) bool {
	n := len(msg)
	for i := 0; i < n / 2; i++ {
		if msg[i] != msg[n - i - 1] {
			return false
		}
	}
	return true
}
```

## Things to watch

- **Byte vs Rune comparison in IsPalindrome**: `msg[i]` indexes raw bytes. Non-ASCII multi-byte UTF-8 characters (like accented letters or runes) will be indexed byte by byte, which can produce incorrect results for non-ASCII palindromes. For full Unicode support, convert `[]rune(msg)` before checking.
