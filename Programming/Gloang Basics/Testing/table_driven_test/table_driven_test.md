2. `TestIsPalindrome(t *testing.T)`:
   - Defines test cases:
     ```go
     cases := []struct {
         name string
         input string

     }{
         {"palindrome", "racecar", true},

     }
     ```
   - Uses `t.Run(tc.name, ...)` to execute each test case as a discrete subtest.

## Key excerpt

```go
func TestAdd(t *testing.T) {

	testCasesInt := []struct {
		a, b, sum int64
	}{
		{10, 20, 30},
		{40, 43, 83},
		{1000001212, 1212, 1000002424},
	}

	for _, tc := range testCasesInt {
		got := int64(Add(int(tc.a), int(tc.b)))
		if got != tc.sum {
			t.Errorf("got %d, want %d", got, tc.sum)
		}
	}
}
```

## Things to watch

- **t.Run benefits**: Subtests allow running specific test cases individually from the CLI (e.g. `go test -run TestIsPalindrome/palindrome`), and test failures pinpoint the exact failing case name rather than just a line number.

## Terms

- **Subtest**: A child test managed by `t.Run()` that runs under the context of a parent test function.
