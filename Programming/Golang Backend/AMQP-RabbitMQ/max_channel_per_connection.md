## Overview

This program demonstrates how to restrict and test the maximum number of simultaneous AMQP channels permitted on a single RabbitMQ TCP connection using `amqp.DialConfig`.

## Concepts used

- Connection negotiation using `amq.DialConfig`
- Channel limits configured via `amq.Config{ChannelMax: 10}`
- Concurrent goroutines opening channels using `sync.WaitGroup`
- Error handling when channel limits are exceeded

## How it works

The program connects to RabbitMQ with custom configuration:
1. `amq.DialConfig` specifies `ChannelMax: 10`, instructing the client and server to negotiate a maximum limit of 10 open channels on this connection.
2. A `sync.WaitGroup` orchestrates 20 concurrent goroutines.
3. Each goroutine attempts to open an independent channel via `conn.Channel()`.
4. If channel creation succeeds, the goroutine prints the connection status and sleeps for 5 seconds before closing the channel.
5. If the channel creation exceeds the negotiated limit (10), `conn.Channel()` returns an error, which the goroutine logs to stdout.

## Key excerpt

```go
	conn, err := amq.DialConfig(
		"amqp://guest:guest@localhost:5672",
		amq.Config{
			ChannelMax: 10,
			Recovery:   &amq.Recovery{},
		})
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	var wg sync.WaitGroup
	for i := range 20 {
		wg.Add(1)
		go func(id int, wg *sync.WaitGroup) {
			defer wg.Done()
			ch, err := conn.Channel()
			if err != nil {
				fmt.Println("ID:", id, "Error", err, "Coonection", conn.IsClosed())
				return
			}
			fmt.Println("ID:", id, "Coonection", conn.IsClosed())
			defer ch.Close()
			time.Sleep(5 * time.Second)
		}(i, &wg)
	}
	wg.Wait()
```

## Things to watch

- **Channel multiplexing**: AMQP channels are lightweight virtual connections multiplexed over a single TCP connection. However, exceeding broker or client limits causes errors.
- **Typo in log output**: The code outputs `"Coonection"` (misspelled) in stdout.

## Terms

- **AMQP Channel**: A lightweight, multiplexed session sharing a single TCP connection.
- **ChannelMax**: Negotiation parameter defining the maximum number of open channels allowed simultaneously.
