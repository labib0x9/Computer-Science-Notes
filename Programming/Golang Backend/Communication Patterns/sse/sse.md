## Overview

This program demonstrates how to implement real-time server-push streaming over standard HTTP using Server-Sent Events (SSE) in Go. It monitors host memory utilization using `github.com/shirou/gopsutil/mem` and pushes alternating text and JSON events every second.

- Server-Sent Events wire format (`text/event-stream`)

- Client disconnection detection via `r.Context().Done()`
- System telemetry harvesting using `gopsutil`

## How it works

The program mounts static file serving on `/` and mounts `memEventHandler` on `/status/mem`:
1. `memEventHandler` configures headers required for SSE: `Content-Type: text/event-stream`, `Cache-Control: no-cache`, and `Connection: keep-alive`.
2. It constructs a 10-second timeout context for the session and a 1-second `time.Ticker`.
3. It obtains an `http.ResponseController` to manually flush output buffers.
4. An infinite `for select` loop listens on three channels:
   - `r.Context().Done()`: Triggered when the client closes the connection or navigates away; exits the handler immediately.
   - `ticker.C`: Ticks every second. Queries `mem.VirtualMemory()`. If `counter` is odd, it sends an event named `mem` with plain text data. If even, it serializes a `Status` struct and sends an event named `json`. It immediately calls `flusher.Flush()`.
   - `ctx.Done()`: Fires after 10 seconds, sends a closing `done` event, flushes, and terminates the stream.

## Expected behavior (from reading the code, not run)

- Connecting with an SSE-capable client (like `EventSource` in JavaScript or `curl -N http://localhost:8080/status/mem`) establishes a persistent connection.
- Every second, the server pushes an SSE event (`event: mem` or `event: json`) with current memory statistics.
- After 10 seconds, the server sends `event: done` and closes the stream.
- If the client disconnects before 10 seconds, `r.Context().Done()` fires and prints `CLient disconnected`.

## Things to watch

- **ResponseController**: Go 1.20 introduced `http.ResponseController` to standardize `http.Flusher` and `http.Hijacker` interfaces.
- **Context lifecycle**: The 10-second timeout uses `context.Background()` rather than deriving from `r.Context()`. As a result, the timeout is fixed regardless of incoming request cancellations.

## Terms

- **Server-Sent Events (SSE)**: A lightweight protocol over HTTP where a server can continuously push events to clients over an open connection.
- **Flusher**: An interface used by HTTP handlers to push buffered data to the client network connection immediately.
