## Overview

This program demonstrates how to connect to a MySQL database from Go using the standard `database/sql` package and the `github.com/go-sql-driver/mysql` driver. It shows DSN construction, connection verification, parameter-binding inserts, and row scanning.

## How it works

The code builds a DSN string from credentials:
1. `sql.Open("mysql", dsn)` initializes a `*sql.DB` connection pool handle.
2. `db.Ping()` verifies that the database server is reachable.
3. It prepares an insert query `INSERT INTO items (content) VALUES (?)` and executes it with `db.Exec(insertStmt, content)`.
4. It reads the generated ID with `res.LastInsertId()`.
5. It queries the newly inserted record with `db.QueryRow(queryStmt, id)` and scans the content into a Go string.

## Key excerpt

```go
func main() {

	dbName := "testDb"
	dsn := user + ":" + password + "@tcp(" + ip + ":" + port + ")/" + dbName
	fmt.Println(dsn)

	db, err := sql.Open("mysql", dsn)
	if err != nil {
		fmt.Println("Open error : %w", err)
		return
	}
	defer db.Close()

	if err := db.Ping(); err != nil {
		fmt.Println("Ping error")
		return
	}

	// Connected to mysql
	fmt.Println("Connected")
```

## Expected behavior (from reading the code, not run)

- If MySQL is running on `127.0.0.1:3306` with matching credentials, the program prints `Connected`, inserts a row into `items`, and reads it back.
- If MySQL is down or credentials are incorrect, `db.Ping()` fails and logs `Ping error`.

## Things to watch

- **sql.Open does not establish connection**: `sql.Open` only validates connection string arguments; it does not open a network socket. `db.Ping()` or the first query is required to verify real network connectivity.
- **SQL parameter placeholder**: MySQL uses `?` placeholders, unlike PostgreSQL which uses `$1, $2`.

## Terms

- **DSN (Data Source Name)**: A structured string specifying database driver parameters, credentials, network address, and database name.
- **sql.DB**: A database connection pool handle managed by Go's standard library.
