## Overview

This program demonstrates foundational PostgreSQL operations using the native `github.com/jackc/pgx/v5` driver in Go. It illustrates single-connection creation, configuration inspection, parameterized inserts, and iterating over query results using `pgx.CollectRows`.

## Concepts used

- Native PostgreSQL connection via `pgx.Connect`
- Connection configuration introspection with `conn.Config()`
- Parameterized queries using `$1` positional syntax
- Result mapping with `pgx.RowToStructByName` and `pgx.CollectRows`

## How it works

The program establishes a direct connection to PostgreSQL:
1. `pgx.Connect(context.Background(), pgURL)` opens a single TCP connection.
2. `conn.Config()` inspects configured database name and credentials.
3. `conn.Exec` runs an `INSERT` statement with `$1` positional arguments.
4. `conn.Query` fetches all rows from table `urls`.
5. `pgx.CollectRows(rows, pgx.RowToStructByName[Url])` maps SQL columns into a slice of `Url` structs automatically based on struct field names.

## Things to watch

- **Hardcoded credentials**: The source code contains hardcoded credentials (`short:secret`). In production applications, sensitive credentials should be supplied via environment variables or secret managers.
- **Single connection concurrency**: A single `*pgx.Conn` represents an individual TCP socket and cannot be accessed concurrently by multiple goroutines. For concurrent applications, use `pgxpool.Pool`.

## Terms

- **pgx**: A high-performance native PostgreSQL driver and toolkit for Go.
- **RowToStructByName**: A generic pgx helper that scans columns into matching struct fields.
