## Overview

This program demonstrates how to authenticate with the GitHub REST API as a GitHub App using `github.com/bradleyfalzon/ghinstallation/v2` and `github.com/google/go-github/v62/github`. It obtains an installation transport from a private key file and invites a user as a repository collaborator.

## How it works

The code implements `NewClient`:
1. `gh.NewKeyFromFile` takes the HTTP transport, App ID, Installation ID, and the path to an RSA private key file (`hikma-test-service.2026-08-12.private-key.pem`).
2. It constructs an authenticated `*http.Client` that automatically negotiates and refreshes short-lived GitHub App installation tokens.
3. `github.NewClient(authenticatedClient)` returns the high-level API client.
4. In `main`:
   - It initializes the client for organization `ZERO9xz`.
   - It calls `client.Repositories.AddCollaborator` to grant permission (`push`) on repository `test-delete` to user `labib0x9`.
   - It prints the HTTP response status.

## Key excerpt

```go
func NewClient(org string, appId, instalationId int64) *github.Client {
	transport, err := gh.NewKeyFromFile(
		http.DefaultTransport,
		appId,
		instalationId,
		"hikma-test-service.2026-08-12.private-key.pem",
	)
	if err != nil {
		panic(err)
	}

	return github.NewClient(
		&http.Client{
			Transport: transport,
			Timeout:   20 * time.Second,
		},
	)
}
```

## Things to watch

- **External credentials**: The code depends on a physical PEM private key file on disk and valid App/Installation IDs; missing keys or invalid permissions cause panics or 401/403 responses.
- **Octal literal bug**: `appId := 0773456` has a leading zero, causing Go compilers to parse it as an octal integer (`0773456` octal is `259886` decimal). In production code, avoid leading zeroes for base-10 IDs.

## Terms

- **GitHub App**: An integration that acts on its own behalf or on behalf of installations with fine-grained permissions.
- **Installation ID**: An identifier assigned when a GitHub App is installed on an organization or user account.
