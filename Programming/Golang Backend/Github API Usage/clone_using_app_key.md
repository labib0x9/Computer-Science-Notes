## Overview

This program demonstrates how to generate a temporary installation token from a GitHub App private key and use it to execute an authenticated `git clone` command against a private GitHub organization repository.

[clone_using_app_key.go](https://github.com/labib0x9/Programming-Notes/blob/main/Programming/Golang%20Backend/Github%20API%20Usage/clone_using_app_key.go)

## Concepts used

- Generating installation tokens via `ghinstallation.NewAppsTransportKeyFromFile`
- Authenticated Git cloning using the `x-access-token` convention
- Executing external commands with `os/exec.CommandContext`
- Working directory and path resolution using `filepath` and `os.MkdirAll`

## How it works

1. `NewToken` loads the private key file and requests an installation token for the specified GitHub App installation.
2. In `main`:
   - It formats an authenticated Git clone URL: `https://x-access-token:<token>@github.com/<org>/<repo>.git`.
   - It creates a local target destination directory in `/tmp/github-clone-test`.
   - It runs `git clone` via `exec.CommandContext`.
   - Standard output and error streams are captured and printed to the console.

## Key excerpt

```go
func main() {
	appId := int64(0773456)
	instalationId := int64(478367040)
	org := "ZERO9xz"
	repo := "test-delete"

	token := NewToken(org, appId, instalationId)

	cloneURL := fmt.Sprintf("https://x-access-token:%s@github.com/%s/%s.git", token, org, repo)

	targetDir := filepath.Join(os.TempDir(), "github-clone-test", repo)
	_ = os.RemoveAll(targetDir)
	_ = os.MkdirAll(filepath.Dir(targetDir), 0755)

	cmd := exec.CommandContext(context.Background(), "git", "clone", cloneURL, targetDir)
```

## Expected behavior (from reading the code, not run)

- Acquires a short-lived GitHub App token.
- Runs `git clone` to clone `ZERO9xz/test-delete` into `/tmp/github-clone-test/test-delete`.
- Prints `Cloned successfully to /tmp/github-clone-test/test-delete`.

## Things to watch

- **URL token exposure**: Tokens passed directly in command-line arguments can appear in process listings (`ps aux`). Using Git credential helpers or stdin configuration is safer in production.
- **Octal literal**: `0773456` has a leading zero and is parsed as octal.

## Terms

- **x-access-token**: The username placeholder recognized by GitHub when authenticating Git operations over HTTPS using installation tokens.
- **Installation Token**: An ephemeral bearer token valid for 1 hour issued to a GitHub App installation.
