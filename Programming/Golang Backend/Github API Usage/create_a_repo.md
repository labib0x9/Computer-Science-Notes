## Overview

This program demonstrates programmatic repository creation in a GitHub organization using the `google/go-github` SDK authenticated as a GitHub App.

- Setting repository visibility, description, and auto-initialization flags
- SDK helper pointers (`github.String`, `github.Bool`)

## How it works

1. It initializes an authenticated `github.Client` using `ghinstallation.NewKeyFromFile` with the private key `hikma-test-service.2026-08-12.private-key.pem`.
2. It sets up a 20-second timeout context.
3. It constructs a `github.Repository` specification:
   - `Name`: `test-delete`
   - `Private`: `true`
   - `AutoInit`: `true` (creates initial commit with README)
4. It calls `client.Repositories.Create(ctx, org, repo)`, which sends an HTTP POST request to GitHub's `/orgs/{org}/repos` endpoint.
5. If successful, it prints the repository clone URL.

## Key excerpt

```go
	newRepo := &github.Repository{
		Name:        github.String("test-delete"),
		Description: github.String("repo created using github app for testing"),
		Private:     github.Bool(true),
		AutoInit:    github.Bool(true),
	}

	repo, _, err := client.Repositories.Create(ctx, org, newRepo)
	if err != nil {
		panic(err)
	}

	fmt.Println("Repo created:", repo.GetCloneURL())
```

## Things to watch

- **Permissions**: The GitHub App must have `Administration: write` permission on repositories within the target organization.
- **Repository conflicts**: If a repository named `test-delete` already exists, GitHub returns an HTTP 422 Unprocessable Entity error.

## Terms

- **AutoInit**: GitHub API parameter that automatically commits an initial default README file upon repository creation.
- **go-github**: The official Google Go library for accessing the GitHub v3 API.
