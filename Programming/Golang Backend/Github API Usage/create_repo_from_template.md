## Things to watch

- **Template flag required**: The source repository (`test-template`) must have the "Template repository" checkbox enabled in its GitHub repository settings.
- **Asynchronous generation**: Template instantiation can take a few seconds on GitHub's backend; immediate subsequent Git clone operations may require retry logic.

## Terms

- **Template Repository**: A repository that users can generate new repositories from with the same directory structure and files.
