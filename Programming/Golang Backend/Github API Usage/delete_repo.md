## Overview

This program demonstrates how to permanently delete a repository from a GitHub organization using `google/go-github` authenticated as a GitHub App.

[delete_repo.go](https://github.com/labib0x9/Programming-Notes/blob/main/Programming/Golang%20Backend/Github%20API%20Usage/delete_repo.go)

## Concepts used

- Permanent repository destruction via `client.Repositories.Delete`
- GitHub App authentication with RSA private keys
- Handling HTTP response status codes

## How it works

1. `NewClient` creates an authenticated `*github.Client` using the installation's RSA private key.
2. In `main`:
   - It targets repository `test-delete` under organization `ZERO9xz`.
   - A 20-second timeout context is created.
   - It calls `client.Repositories.Delete(ctx, org, repo)`.
   - GitHub deletes the repository and returns HTTP status 204 No Content.
   - It prints `Deleted: 204 No Content`.

## Key excerpt

```go
	ctx, cancel := context.WithTimeout(context.Background(), 20*time.Second)
	defer cancel()

	repo := "test-delete"
	resp, err := client.Repositories.Delete(ctx, org, repo)
	if err != nil {
		panic(err)
	}

	fmt.Println("Deleted:", resp.Status)
```

## Expected behavior (from reading the code, not run)

- Sends an HTTP DELETE request to `https://api.github.com/repos/ZERO9xz/test-delete`.
- If the repository exists and the App has delete permissions, prints `Deleted: 204 No Content`.
- If the repository does not exist, panics with an HTTP 404 Not Found error.

## Things to watch

- **Irreversible action**: Repository deletion is immediate and permanent.
- **Required permissions**: The GitHub App must have `Administration: write` permission on the repository.

## Terms

- **HTTP 204 No Content**: Standard successful HTTP response code for DELETE requests indicating the entity was removed.
