## Overview

This program demonstrates how to serve downloadable files over HTTP in Go. It reads a file from disk, sniffs its MIME type, sets appropriate `Content-Disposition` download headers, and streams the payload using `io.Copy`.

## Concepts used

- MIME type detection using `http.DetectContentType`
- Forcing browser download prompts with `Content-Disposition: attachment`
- Zero-allocation stream copying via `io.Copy(w, file)`
- Query parameter extraction with `r.URL.Query().Get`

## How it works

In `downloadHandler`:
1. It extracts `filename` from the URL query string (e.g. `?filename=go.mod`).
2. It opens the local file with `os.Open(filename)`.
3. It reads the first 512 bytes into a buffer and passes them to `http.DetectContentType` to sniff the MIME type.
4. It resets the file read pointer back to the beginning using `file.Seek(0, io.SeekStart)`.
5. It configures response headers:
   - `Content-Type`: Sniffed MIME type
   - `Content-Disposition`: `fmt.Sprintf("attachment; filename=%s", filename)`
6. `io.Copy(w, file)` streams the file contents directly to the network connection buffer.

## Key excerpt

```go
func downloadHandler(w http.ResponseWriter, r *http.Request) {
	filename := r.URL.Query().Get("filename")
	file, err := os.Open(filename)
	if err != nil {
		http.Error(w, err.Error(), http.StatusInternalServerError)
		return
	}
	defer file.Close()

	buffer := make([]byte, 512)
	_, _ = file.Read(buffer)
	contentType := http.DetectContentType(buffer)
	_, _ = file.Seek(0, io.SeekStart)

	w.Header().Set("Content-Type", contentType)
	w.Header().Set("Content-Disposition", fmt.Sprintf("attachment; filename=%s", filename))

	_, err = io.Copy(w, file)
	if err != nil {
		return
	}
}
```

## Expected behavior (from reading the code, not run)

## Things to watch

- **Path Traversal Vulnerability**: `os.Open(filename)` opens user-supplied file paths directly without sanitization. An attacker could pass `?filename=../../../../etc/passwd` to download arbitrary server files. In production, sanitize with `filepath.Clean` and restrict paths to an allowed base directory.
- **http.ServeContent alternative**: The standard library provides `http.ServeContent` and `http.ServeFile`, which automatically handle range requests, caching (`Last-Modified`, `ETag`), and seek resets.

## Terms

- **Content-Disposition**: An HTTP header indicating whether content should be displayed inline or downloaded as an attachment.
- **http.DetectContentType**: A helper analyzing the first 512 bytes of data to determine its MIME type.
