## Overview

This program demonstrates how to parse and render external HTML templates using Go's standard `html/template` package. It also demonstrates how using `template.HTML` bypasses standard HTML contextual auto-escaping.

[template_basic.go](https://github.com/labib0x9/Programming-Notes/blob/main/Programming/Golang%20Backend/html%20css%20handling/template_basic.go)

## Concepts used

- HTML template parsing with `template.ParseFiles` and `template.Must`
- URL query parameter extraction with `r.URL.Query().Get`
- Template execution and rendering to `http.ResponseWriter`
- Unescaped HTML insertion using `template.HTML`

## How it works

At package initialization, the global variable `templ` is initialized:
- `template.ParseFiles("./hello.html")` reads and parses the template file.
- `template.Must` panics if parsing fails, ensuring invalid template syntax fails fast at startup.

In `echoHandler`:
1. It extracts the query parameter `name` from the incoming request URL (e.g. `?name=Alice`).
2. It casts the query string into `template.HTML(q)`.
3. It calls `templ.Execute(w, map[string]any{"Name": data})`, merging the parsed template with the data map and writing the resulting HTML document directly to `w`.

In `main`, `echoHandler` is registered on `/` and the server listens on `:8080`.

## Key excerpt

```go
// parse the template file once..
var templ = template.Must(template.ParseFiles("./hello.html"))

func echoHandler(w http.ResponseWriter, r *http.Request) {
	// get query
	q := r.URL.Query().Get("name")

	// html format, no encoding
	data := template.HTML(q)

	// 
	templ.Execute(w, map[string]any{
		"Name": data,
	})
}
```

## Expected behavior (from reading the code, not run)

- If `hello.html` exists in the working directory containing a placeholder like `{{.Name}}`, visiting `http://localhost:8080/?name=World` renders the template with `World`.
- If `hello.html` is missing, running `main` panics immediately during package variable initialization.

## Things to watch

- **XSS Security Risk**: Casting user input directly to `template.HTML(q)` tells Go's template engine that the input is trusted HTML, bypassing contextual sanitization. If a user passes `?name=<script>alert(1)</script>`, the raw script is executed by the browser. To prevent XSS, pass plain strings without converting to `template.HTML`.
- **File path dependency**: `./hello.html` assumes the process working directory is the folder containing `template_basic.go`.

## Terms

- **html/template**: Go standard library package providing data-driven templates with automatic contextual escaping against code injection.
- **template.HTML**: A type encapsulating known-safe HTML; it bypasses escaping filters.
