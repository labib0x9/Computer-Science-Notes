## Overview

This program demonstrates how to build an extensible middleware management pipeline in Go using function closures, chaining `http.Handler` wrappers to log request execution times and metadata.

## How it works

The code introduces a `Middleware` function type and a `Manager` struct:
1. `NewManager` initializes an empty slice of global middlewares.
2. `Manager.Use` appends middlewares to `globalMiddlewares`.
3. `Manager.With(next http.Handler, middlewares ...Middleware)` wraps `next` with route-specific middlewares followed by global middlewares. Because each wrapper decorates the previous handler, earlier wrappers in the loop execute closer to the innermost handler.

Two sample middleware functions are defined:
- `Logger`: Captures the start timestamp, calls `next.ServeHTTP(w, r)`, and logs the HTTP method, path, and duration via `slog.Info`.
- `Info`: Calls `next.ServeHTTP(w, r)` and logs basic request details.

In `main`, `manager.Use(Logger, Info)` configures global middlewares, registers `/notes` on an `http.ServeMux`, and starts an HTTP server on `:8080`.

## Key excerpt

```go
type Middleware func(http.Handler) http.Handler

type Manager struct {
	globalMiddlewares []Middleware
}

func (m *Manager) With(next http.Handler, middlewares ...Middleware) http.Handler {
	for _, middleware := range middlewares {
		next = middleware(next)
	}

	for _, middleware := range m.globalMiddlewares {
		next = middleware(next)
	}

	return next
}
```

## Things to watch

- **Execution order**: In `With`, wrapping iterates forward over `globalMiddlewares`. Because each wrapper calls the outer handler first, `m.globalMiddlewares[len-1]` runs its pre-handler logic first, followed by earlier items, while post-handler logic runs in reverse order.
- **Error handling during ServeHTTP**: If downstream handlers write headers or panic, middleware executing afterwards must handle those states gracefully.

## Terms

- **Middleware**: Code that intercepts HTTP requests before they reach the main business handler or inspects responses before they are returned.
- **Closure**: A function value that references variables from outside its body.
