## Concepts used

- Composable middleware functions (`func(http.Handler) http.Handler`)
- Structured logging with `log/slog`
- JSON payload encoding via `json.NewEncoder`
- Multiplexer configuration with `http.NewServeMux`

## How it works

1. `handleMiddleware(next http.Handler) http.Handler`:
   - Wraps the incoming handler in an `http.HandlerFunc`.
   - Logs request metadata and executes pre-processing logic.
   - Calls `next.ServeHTTP(w, r)`.
2. Handlers:
   - `apiHandler`: Sets `Content-Type: application/json` and encodes data maps.
3. In `main`:
   - Creates a new `http.NewServeMux()`.
   - Mounts routes wrapped with the middleware.
   - Listens on `:8080`.

## Key excerpt

```go
func handleMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		slog.Info("Incoming request", "method", r.Method, "path", r.URL.Path)
		next.ServeHTTP(w, r)
	})
}
```
