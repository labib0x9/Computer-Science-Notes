## Overview

This program demonstrates how to serve static assets (HTML, CSS, images) from a filesystem directory using `http.FileServer` and `http.Dir` in Go, combined with request logging middleware and `http.StripPrefix`.

## Concepts used

- Static file delivery via `http.FileServer`
- Filesystem abstraction with `http.Dir`
- Stripping URL route prefixes via `http.StripPrefix`
- Decorating file servers with logging middleware

## How it works

1. `printRequest(next http.Handler)`:
   - Middleware that logs incoming method and path before calling `next.ServeHTTP(w, r)`.
2. `http.Dir("./public")`:
   - Treats the `./public` directory as an `http.FileSystem`.
3. `http.StripPrefix("/static/", http.FileServer(fileDir))`:
   - Strips the `/static/` prefix from the URL path before searching the directory (e.g. `/static/app.js` looks for `./public/app.js`).
4. In `main`:
   - Mounts the stripped file server wrapped with `printRequest` on `/static/` and starts the server on `:8080`.

## Key excerpt

```go
func main() {
	mux := http.NewServeMux()

	fileServer := http.FileServer(http.Dir("./public"))

	// StripPrefix removes /static/ before looking in ./public
	mux.Handle("/static/", printRequest(http.StripPrefix("/static/", fileServer)))

	http.ListenAndServe(":8080", mux)
}
```

## Expected behavior (from reading the code, not run)

- Requests to `http://localhost:8080/static/file.txt` serve `./public/file.txt`.
- Console prints `Before GET /static/file.txt`.

## Things to watch

- **Trailing slash in route**: When mounting file servers, always include the trailing slash (`"/static/"`); omitting it prevents the mux from matching subpaths.

## Terms

- **http.Dir**: A string type representing a local directory path implementing `http.FileSystem`.
- **http.StripPrefix**: A helper handler that removes the specified prefix from the request URL before forwarding to the underlying handler.
