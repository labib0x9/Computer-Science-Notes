## Overview

This program demonstrates how to implement a custom `http.FileSystem` wrapper in Go to prevent unwanted directory browsing. By default, `http.FileServer` generates HTML directory index listings if an `index.html` file is absent; wrapping `http.FileSystem` intercepts folder access and safely returns `os.ErrNotExist`.

## How it works

1. It defines `type wrapFS struct { fs http.FileSystem }`.
2. It implements `Open(name string) (http.File, error)`:
   - Calls `w.fs.Open(name)` to open the requested file.
   - Calls `stat, err := file.Stat()`.
   - If `stat.IsDir()`, it checks whether an `index.html` file exists in that directory. If no `index.html` exists, it closes the file and returns `os.ErrNotExist` (which causes `http.FileServer` to return HTTP 404 rather than displaying directory contents).
   - If it is a normal file, returns the file handle.
3. In `main`:
   - Wraps `http.Dir("./public")` in `wrapFS` and registers it with `http.FileServer`.

## Key excerpt

```go
// http.FileSystem is an interface, with only `Open(name string) (File, error)` method
type wrapFS struct {
	fs http.FileSystem
}

func (w wrapFS) Open(name string) (http.File, error) {
	file, err := w.fs.Open(name)
	if err != nil {
		return nil, err
	}

	stat, err := file.Stat()
	if err != nil {
		return nil, err
	}

	if stat.IsDir() {
		// Prevent directory browsing
		return nil, errors.New("access denied")
	}

	return file, nil
}
```

## Expected behavior (from reading the code, not run)

## Things to watch

- **Security importance**: Leaving directory indexing enabled in production allows attackers to discover hidden configuration files, backup files, and source scripts.
