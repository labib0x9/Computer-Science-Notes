## How it works

1. `net.Listen("tcp", ":8080")` creates a TCP socket listener.
2. In a loop, `ln.Accept()` blocks until a client connects, returning a `net.Conn`.
3. It allocates a buffer `buf := make([]byte, 1024)`.
4. It reads bytes from `conn.Read(buf)`.
5. It prints the received payload and client remote address to stdout.
6. Closes connection with `conn.Close()`.
