This program demonstrates connectionless User Datagram Protocol (UDP) networking in Go using the standard `net` package. It resolves local UDP endpoints and listens for incoming datagram packets.

## Concepts used

- Resolving UDP addresses via `net.ResolveUDPAddr`
- Creating UDP packet listeners with `net.ListenUDP`
- Reading datagrams via `conn.ReadFromUDP`
- Connectionless network semantics

## How it works

1. `net.ResolveUDPAddr("udp", ":8080")` resolves the network address structure.
2. `net.ListenUDP("udp", localAddr)` binds a UDP socket to receive datagram packets.
3. `conn.ReadFromUDP(buf)` reads arriving datagrams, returning byte count `n`, remote sender address `addr`, and any error.
4. It logs the packet payload and sender address to stdout.

## Key excerpt

```go
func main() {

	localAddr, err := net.ResolveUDPAddr("udp", ":8080")
	if err != nil {
		panic(err)
	}

	conn, err := net.ListenUDP("udp", localAddr)
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	buf := make([]byte, 1024)
	n, remoteAddr, err := conn.ReadFromUDP(buf)
	fmt.Printf("Received %s from %s\n", string(buf[:n]), remoteAddr)
}
```

## Things to watch

- **Packet boundaries**: Unlike TCP which is an unstructured byte stream, UDP preserves discrete packet message boundaries. Each `ReadFromUDP` consumes exactly one datagram.
- **Unreliable delivery**: UDP does not guarantee packet ordering, delivery confirmation, or automatic retransmission.

## Terms

- **UDP (User Datagram Protocol)**: A connectionless, lightweight transport protocol offering minimal latency with no delivery guarantees.
- **Datagram**: A self-contained, independent entity of data carrying sufficient information to be routed from source to destination computer.
