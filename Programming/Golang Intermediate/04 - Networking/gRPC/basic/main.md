## Overview

This program demonstrates building Remote Procedure Call (RPC) microservices in Go using gRPC and Google Protocol Buffers. It shows how to define and implement a service interface, register it on a `grpc.Server`, and establish an RPC client connection to invoke remote methods.

## How it works

1. The service interface is generated from `todo.proto` using `protoc` with Go plugins.
2. Server implementation:
   - A struct embeds the generated `UnimplementedTodoServiceServer`.
   - Implements RPC methods (e.g. `CreateTodo`, `GetTodo`).
   - A `grpc.NewServer()` is initialized and the service is registered with `pb.RegisterTodoServiceServer(grpcServer, &server{})`.
3. Client implementation:
   - Establishes a connection with `grpc.NewClient("localhost:50051", grpc.WithTransportCredentials(insecure.NewCredentials()))`.
   - Constructs a client stub: `client := pb.NewTodoServiceClient(conn)`.
   - Invokes remote methods with a timeout context.

## Things to watch

- **Protoc code generation**: The Go code relies on pre-generated `.pb.go` files compiled by `protoc-gen-go` and `protoc-gen-go-grpc`.
- **Insecure credentials**: `insecure.NewCredentials()` disables TLS encryption, appropriate for local development but unsafe for public networks.
