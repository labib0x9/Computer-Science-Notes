## Overview

This program demonstrates periodic background job scheduling in Go using the `github.com/go-co-op/gocron/v2` package. It registers scheduled jobs with duration intervals and cron syntax, and handles graceful shutdown using OS signal listeners.

## Concepts used

- Background job scheduling with `gocron.NewScheduler()`
- Job intervals (`gocron.DurationJob(time.Second * 2)`)
- Task definitions via `gocron.NewTask(fn, args...)`
- Graceful shutdown with `signal.Notify` and `syscall.SIGINT`/`syscall.SIGTERM`

## How it works

1. `s, err := gocron.NewScheduler()` creates a new job scheduler.
2. `s.NewJob(...)` configures a recurring task:
   - Triggers every 2 seconds.
   - Executes the specified task function.
3. `s.Start()` starts the background scheduling worker loop.
4. The main goroutine blocks on an OS signal channel (`sigChan := make(chan os.Signal, 1)`).
5. When `SIGINT` (Ctrl+C) or `SIGTERM` is received, `s.Shutdown()` gracefully terminates scheduled jobs.

## Key excerpt

```go
func main() {
	s, err := gocron.NewScheduler()
	if err != nil {
		log.Fatal(err)
	}

	j, err := s.NewJob(
		gocron.DurationJob(time.Second*2),
		gocron.NewTask(func() {
			log.Println("Cron job executed")
		}),
	)
	if err != nil {
		log.Fatal(err)
	}
	_ = j

	s.Start()
```
