## Concepts used

## How it works

1. `NotFoundError` struct holds `Resource string`.
2. It implements the `error` interface:
   ```go
   func (e *NotFoundError) Error() string {
       return fmt.Sprintf("Resource not found: %s", e.Resource)
   }
   ```
3. A function returns `&NotFoundError{Resource: "User:123"}`.
4. Callers receive the error through the generic `error` interface.

## Things to watch

- **Pointer receiver nil interface trap**: If a function returns a typed nil pointer to a custom error struct (e.g. `var err *NotFoundError = nil; return err`), the returned `error` interface is NOT nil (`err != nil` evaluates to `true`) because interface values are only nil if both type and value are nil. Always return explicit `nil` for success.

## Terms
