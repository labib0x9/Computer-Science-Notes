## Things to watch

- **Prefer errors.As over type assertions**: Type assertions fail if the error has been wrapped with `%w`; `errors.As` traverses wrapped error chains to find matching types reliably.

## Terms

- **errors.As**: A function that examines an error chain for a specific target error type and assigns it to a destination pointer if found.
