This program demonstrates defining package-level sentinel error variables in Go using `errors.New`. It groups standard domain errors together so callers can test for specific error outcomes.

## Concepts used

- Sentinel error variable convention (`ErrXxx` or `XxxError`)
- Instantiating distinct error pointers with `errors.New`
- Exported package errors for caller comparison

## How it works

The code defines a grouped block of sentinel errors:
```go
var (
	NotFoundError  = errors.New("Not found")
	FileOpenFailed = errors.New("File open failed")
	ErrOutOfIndex  = errors.New("Slice is too short to access")
)
```
In `main`, functions return these sentinel errors, and callers compare them using `errors.Is`.
