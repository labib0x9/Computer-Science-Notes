## Overview

This program demonstrates `errors.Join`, a feature introduced in Go 1.20 that aggregates a slice of errors into a single joined error value.

## Source

## Concepts used

- Combining multiple errors with `errors.Join`
- Error tree traversal with `errors.Is` on joined errors
- Formatting multi-line error strings

## How it works

1. It initializes two separate errors:
   - `err1 := errors.New("file1 cannot be opened")`
   - `err2 := errors.New("file2 cannot be closed")`
2. It combines them: `err := errors.Join(err1, err2)`.
3. The resulting error formats both error strings separated by a newline.
4. Calling `errors.Is(err, err1)` and `errors.Is(err, err2)` both evaluate to `true`.

## Key excerpt

```go
func main() {

	err1 := errors.New("file1 cannot be opened")
	err2 := errors.New("file2 cannot be closed")
	errors.Join(err1, err2)
```

## Things to watch

- **Nil errors filtered**: `errors.Join` automatically discards any `nil` error arguments. If all arguments are `nil`, `errors.Join` returns `nil`.
