## How it works

1. `NotFoundError` struct holds `Resource string` and inner `Err error`.
2. Implements `Unwrap() error`:
   ```go
   func (e *NotFoundError) Unwrap() error {
       return e.Err
   }
   ```
3. When `errors.Unwrap` or `errors.Is` processes `NotFoundError`, Go calls `Unwrap()` to inspect the nested underlying error.

## Key excerpt

```go
type NotFoundError struct {
	Resource string
	Err error
}

func (e *NotFoundError) Error() string {
	return fmt.Sprintf("not found: %s: %v", e.Resource, e.Err)
}

func (e *NotFoundError) Unwrap() error {
	return e.Err
}
```
