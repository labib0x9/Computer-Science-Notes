## How it works

1. In `OpenFile(path)`:

     ```go
     return fmt.Errorf("open file failed (%v): %w", time.Now().Format(time.RFC3339), err)
     ```

   - Using `%w` ensures the returned error implements `Unwrap() error`, preserving the underlying `*os.PathError` for inspection by callers using `errors.Is` and `errors.As`.

## Key excerpt

```go
func OpenFile(path string) error {
	file, err := os.Open(path)
	if err != nil {
		return fmt.Errorf("open file failed (%v): %w", time.Now().Format(time.RFC3339), err)
	}
	defer file.Close()
	return nil
}
```

## Expected behavior (from reading the code, not run)

## Things to watch

- **%w vs %v**: Using `%v` or `%s` converts the inner error to a plain text string, permanently severing the error chain; callers will be unable to use `errors.Is` or `errors.As` on it. Only use `%w` when you want callers to be able to inspect underlying error types.

## Terms

- **%w Verb**: Special format specifier in `fmt.Errorf` that wraps an error while providing an `Unwrap` method.
