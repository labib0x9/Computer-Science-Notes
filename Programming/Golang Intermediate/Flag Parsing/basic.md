## Overview

This program demonstrates how to define and parse command-line flags in Go using the standard `flag` package. It showcases boolean flags, string flags, and inspecting parsed values.

## Concepts used

- Declaring flags returning pointers (`flag.Bool`, `flag.String`)
- Executing argument parsing via `flag.Parse()`
- Dereferencing flag pointers (`*syncFlag`, `*userFlag`)
- Flag default values and help text

## How it works

1. It defines command-line flags:
   - `syncFlag := flag.Bool("sync", false, "synchronize data")`
   - `userFlag := flag.String("user", "", "username identifier")`
2. It calls `flag.Parse()`, which parses flags from `os.Args[1:]`.
3. It prints the values using `*syncFlag` and `*userFlag`.

## Key excerpt

```go
func main() {

	syncFlag := flag.Bool("sync", false, "")
	userFlag := flag.String("user", "", "")

	flag.Parse()

	fmt.Println("Sync:", *syncFlag)
	fmt.Println("User:", *userFlag)
}
```

## Things to watch

- **flag.Parse must be called**: Forgetting to call `flag.Parse()` leaves flag pointers holding their default values regardless of CLI flags supplied by the user.

## Terms

- **CLI Flag**: An option passed to a command-line program (e.g. `--verbose` or `-user=admin`).
