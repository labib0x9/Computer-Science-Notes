## Overview

This program demonstrates how to implement a counting semaphore in Go using a buffered channel, restricting the maximum number of simultaneously executing goroutines to 3.

## Concepts used

- Counting semaphore pattern
- Buffered channel capacity as concurrency token limit
- Empty struct tokens (`struct{}{}`) for zero memory allocation

## How it works

1. Allocates `token := make(chan struct{}, 3)` with capacity 3.
2. For each task in a loop of 15 items, acquires a token via `token <- struct{}{}`.
3. If 3 goroutines are already running, the send blocks until an active goroutine finishes and releases its token via `<-token`.
4. Guarantees no more than 3 tasks run concurrently.

## Key excerpt

```go
// Maximum 3 goroutines running concurrently
token := make(chan struct{}, 3)

for i := 0; i < 15; i++ {
	token <- struct{}{} // acquire token (blocks if full)
	go func(n int) {
		defer func() { <-token }() // release token
		// do work
	}(i)
}
```

## Expected behavior (from reading the code, not run)

- Processes 15 tasks in batches of at most 3 concurrent workers.

## Things to watch

- Placing `token <- struct{}{}` before spawning the goroutine limits the number of running goroutines and avoids uncontrolled memory growth.

## Terms

- **Semaphore**: A synchronization object that controls access to a common resource by multiple concurrent processes.
- **Empty struct**: `struct{}` occupies zero bytes of memory, making it ideal for signaling tokens.
