## Concepts used

- Fan-out: distributing work items to multiple goroutines
- Fan-in: multiplexing multiple output channels into one stream
- `sync.WaitGroup` for multi-channel stream termination

## How it works

1. Producer generates input numbers into an input channel.
2. Multiple worker goroutines read from the input channel, process data, and push to individual intermediate channels (Fan-out).
3. A `merge` function reads from all intermediate channels and pipes results into a single output channel (Fan-in).
4. Main consumer reads consolidated results from the merged channel.
