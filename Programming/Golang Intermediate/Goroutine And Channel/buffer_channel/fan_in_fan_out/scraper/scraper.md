## Overview

This program implements a robust distributed web scraper combining fan-out worker dispatch with fan-in stream aggregation, parsing HTML links across multiple websites simultaneously.

## Concepts used

- Fan-out URL processing
- Fan-in link consolidation
- HTML anchor parsing using `golang.org/x/net/html`

## How it works

1. Target seed URLs are fanned out to independent fetcher goroutines.
2. Each fetcher downloads page contents and tokenizes HTML elements.
3. Extracted URLs from each fetcher are fanned into a central aggregation channel.
4. Main loop logs aggregated results as they arrive.
