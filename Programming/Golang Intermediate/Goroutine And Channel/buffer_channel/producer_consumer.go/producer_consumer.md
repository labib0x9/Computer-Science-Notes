## Overview

This program demonstrates the classic producer-consumer pattern in Go, emphasizing why the producer must close the channel to prevent consumer `for-range` loops from deadlocking.

## Concepts used

- Producer goroutine pattern
- Channel range iteration (`for item := range ch`)
- Deadlock prevention via `close(ch)`

## How it works

1. `Producer(ch chan int)` pushes integers from 0 to 10 into `ch`.
2. Demonstrates what happens if `close(ch)` is omitted: the consumer loop continues waiting indefinitely after receiving all items.
3. Shows that closing the channel allows the consumer loop to exit cleanly.

## Key excerpt

```go
func Producer(ch chan int) {
	for i := 0; i <= 10; i++ {
		ch <- i
	}
	// Run without closing the channel to observe deadlock,
	// or close(ch) to allow consumer to terminate cleanly:
	close(ch)
}
```

## Expected behavior (from reading the code, not run)

- With `close(ch)`, consumer prints integers 0 through 10 and terminates gracefully.
- Without `close(ch)`, triggers a runtime deadlock.

## Things to watch

- A `for item := range ch` loop will never finish unless the channel is explicitly closed.

## Terms

- **Channel drain**: Receiving all remaining buffered values from a closed channel until it is completely empty.
