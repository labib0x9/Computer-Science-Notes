## Concepts used

- Buffered channel initialization (`make(chan T, capacity)`)
- Non-blocking sends while capacity remains
- Blocking rules: full channel blocks senders; empty channel blocks receivers

## How it works

1. Allocates a 3-element buffered channel: `ch := make(chan int, 3)`.
2. Demonstrates sending 3 elements without blocking because capacity permits.
3. Explains that attempting a 4th send without an active receiver blocks the sending goroutine.
4. Demonstrates receiving elements in FIFO order.

## Key excerpt

```go
// send -> insert at the end of queue
// receive -> remove element from the front of queue
// Channel is full? sender blocks
// Channel is empty? receiver blocks

func BufferChannel() {
	ch := make(chan int, 3)
	ch <- 1
	ch <- 2
	ch <- 3
	// ch <- 4 // would block!
}
```

## Expected behavior (from reading the code, not run)

- Inserts 3 integers into the channel buffer without pausing or blocking.

## Things to watch

- Unlike unbuffered channels which require immediate receiver rendezvous, buffered channels decouple sender and receiver timing up to their buffer capacity.

## Terms

- **Buffered channel**: A channel with an internal ring buffer allowing sends to succeed asynchronously until the buffer fills up.
- **FIFO**: First-In, First-Out queue ordering.
