## How it works

1. Target URLs are queued in a buffered channel.
2. A pool of worker goroutines consumes URLs, executes HTTP GET requests, and reads response bodies.
3. Parses HTML DOM trees to extract `<a>` tag `href` attributes.
4. Collects and deduplicates discovered links.

## Key excerpt

```go
func scrapeWorker(id int, urls <-chan string, results chan<- []string, wg *sync.WaitGroup) {
	defer wg.Done()
	for u := range urls {
		resp, err := http.Get(u)
		if err != nil {
			continue
		}
		links := extractLinks(resp.Body)
		resp.Body.Close()
		results <- links
	}
}
```
