## Overview

This program demonstrates the classic worker pool pattern in Go, spawning a fixed set of persistent worker goroutines that consume and execute jobs from a shared task channel.

## How it works

1. Spawns $N$ worker goroutines listening on `jobs := make(chan int, bufferSize)`.
2. Each worker runs `for job := range jobs`, processing tasks as they arrive.
3. Producer pushes tasks into `jobs` and closes the channel when finished.
4. Workers terminate naturally when `jobs` is closed and drained.

## Key excerpt

```go
// Shared queue -> fixed sized worker pool
// NOTE: Distribution isn't guaranteed to be fair.
func worker(id int, jobs <-chan int, results chan<- int, wg *sync.WaitGroup) {
	defer wg.Done()
	for j := range jobs {
		fmt.Printf("Worker %d started job %d\n", id, j)
		results <- j * 2
	}
}
```

## Things to watch
