## How it works

1. `Channel()` creates an unbuffered channel: `ch := make(chan string)`.
2. Spawns background goroutine that sends string messages into `ch`.
3. The main routine receives messages using `<-ch`.
4. Execution synchronizes at the moment of channel communication.

## Key excerpt

```go
func Channel() {
	// unbuffered channel
	ch := make(chan string)

	go func() {
		ch <- "Hello from Goroutine"
	}()

	msg := <-ch
	fmt.Println(msg)
}
```
