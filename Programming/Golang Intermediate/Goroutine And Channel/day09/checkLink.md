## Overview

This program demonstrates concurrent network I/O in Go, dispatching HTTP GET probes to multiple website URLs concurrently and reporting health status across channels.

## Concepts used

- HTTP client requests via `net/http`
- Concurrent goroutine fan-out
- Communicating results through string channels

## How it works

1. Defines a slice of target URLs (Google, Facebook, StackOverflow, etc.).
2. Creates a channel for status messages.
3. Spawns a goroutine for each URL to execute `http.Get(link)`.
4. Checks for errors to report whether each site is up or down.

## Key excerpt

```go
func CheckLinks() {
	links := []string{
		"http://google.com",
		"http://facebook.com",
		"http://stackoverflow.com",
		"http://golang.org",
		"http://amazon.com",
	}

	c := make(chan string)
	for _, link := range links {
		go checkLink(link, c)
	}
}
```

## Things to watch

- Unbounded concurrency: spawning hundreds of network requests without a semaphore or rate limiter can exhaust OS socket descriptors.

## Terms

- **Health check**: A periodic probe verifying that a network service is operational and responding.
- **Fan-out**: Distributing tasks across multiple concurrent workers.
