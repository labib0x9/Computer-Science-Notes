## Overview

This program demonstrates parallel file processing in Go, spawning a goroutine for each input text file to parse numeric entries line-by-line with `bufio.Scanner` and aggregating the maximum value.

## Concepts used

- Buffered file reading with `bufio.NewScanner`
- String to integer parsing (`strconv.Atoi`)
- Fan-out file parsing with channel aggregation

## How it works

1. Reads text files concurrently.
2. In each goroutine, scans numbers line-by-line and computes the local maximum for that file.
3. Transmits local maximums across a channel back to the main aggregator.
4. Main goroutine computes and prints the highest global integer found across all files.

## Key excerpt

```go
// Open all files in goroutine and find max of these numbers
scanner := bufio.NewScanner(file)
localMax := 0
for scanner.Scan() {
	line := strings.TrimSpace(scanner.Text())
	val, err := strconv.Atoi(line)
	if err == nil && val > localMax {
		localMax = val
	}
}
ch <- localMax
```
