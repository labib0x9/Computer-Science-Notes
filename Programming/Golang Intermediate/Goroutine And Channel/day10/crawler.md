## Overview

This program demonstrates a concurrent web crawler architecture in Go, passing batches of newly discovered URLs across a `worklist` channel and tracking visited pages in a hash set.

## Concepts used

- Worklist channel pattern (`make(chan []string)`)

## How it works

1. `Crawler1()` initializes `worklist := make(chan []string)`.
2. Seeds initial links into `worklist`.
3. Reads lists of links, checks `seen[link]` map.
4. Spawns goroutines to crawl new links, feeding new URL slices back into `worklist`.

## Key excerpt

```go
func Crawler1() {
	wordlist := make(chan []string)

	// Seeds initial URLs and loops over incoming link slices:
	for list := range wordlist {
		for _, link := range list {
			if !seen[link] {
				seen[link] = true
				go func(link string) {
					wordlist <- crawl(link)
				}(link)
			}
		}
	}
}
```

## Things to watch

- Flaw in design: spawning unbounded goroutines for every link can open thousands of simultaneous network sockets, exhausting OS file descriptors.

## Terms

- **Worklist**: A queue of pending items awaiting processing in an algorithm.
- **File descriptor exhaustion**: An error occurring when a program exceeds the operating system's limit on simultaneously open socket handles.
