## How it works

1. Accepts target URL string.
2. Passes string bytes into `sha256.Sum256([]byte(url))`.
3. Encodes the 32-byte hash digest into a 64-character hexadecimal string with `hex.EncodeToString`.
4. Returns the hash string to be stored in the crawler deduplication index.

## Key excerpt

```go
var contestArchivePage = "https://atcoder.jp/contests/archive"

func hashURL(url string) string {
	h := sha256.Sum256([]byte(url))
	return hex.EncodeToString(h[:])
}
```
