## Overview

This program generates realistic, pseudo-randomized browser User-Agent header strings across modern Firefox and Chrome browser releases to simulate diverse organic web traffic during scraping.

## How it works

1. Maintains arrays of Firefox versions (65.0 through 76.0+) and browser platforms.
2. Selects a random version number and platform identifier.
3. Formats and returns a complete, RFC-compliant User-Agent header string.

## Key excerpt

```go
var firefoxVersions = []float32{
	65.0, 66.0, 67.0, 68.0, 69.0, 70.0, 71.0, 72.0, 73.0, 74.0, 75.0, 76.0,
}

func getRandomAgent() string {
	ver := firefoxVersions[rand.Intn(len(firefoxVersions))]
	return fmt.Sprintf("Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:%.1f) Gecko/20100101 Firefox/%.1f", ver, ver)
}
```
