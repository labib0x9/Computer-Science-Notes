## How it works

2. Before invoking `crawl(url)`, acquires a token: `tokens <- struct{}{}`.
3. In a defer block, releases token: `defer func() { <-tokens }()`.
4. Guarantees that at most 20 HTTP requests run in parallel across the system.

```go
// Enforce a limit of 20 concurrent requests at once
```
