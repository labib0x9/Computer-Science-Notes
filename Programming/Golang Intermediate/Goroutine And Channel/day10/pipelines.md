## Overview

This program demonstrates the pipeline concurrency pattern in Go, connecting three distinct processing stages through channels: a number generator, a squaring stage, and a printing consumer.

## Concepts used

- Pipeline concurrency pattern
- Streaming data between independent stages
- Graceful shutdown via channel closing

## How it works

1. Stage 1 (Generator): generates integers and writes to `naturals` channel, then closes it.
2. Stage 2 (Squarer): loops `for x := range naturals`, squares each value, and pushes to `squares` channel, then closes it.
3. Stage 3 (Printer): loops `for x := range squares`, printing values to standard output.

## Key excerpt

```go
// Pipelines -> one goroutine's output is another goroutine's input
func Pipeline() {
	naturals := make(chan int)
	squares := make(chan int)

	// Stage 1: Counter
	go func() {
		for x := 0; x < 10; x++ {
			naturals <- x
		}
		close(naturals)
	}()

	// Stage 2: Squarer
	go func() {
		for x := range naturals {
			squares <- x * x
		}
		close(squares)
	}()
```

## Expected behavior (from reading the code, not run)

- Prints the squares of integers 0 through 9 (0, 1, 4, 9, 16, 25, 36, 49, 64, 81) sequentially and terminates cleanly.

## Things to watch

- Closing each channel once its stage completes is essential for downstream stages to exit their `range` loops cleanly.

## Terms

- **Pipeline**: A series of processing stages where each stage consumes data from an upstream channel and emits results to a downstream channel.
