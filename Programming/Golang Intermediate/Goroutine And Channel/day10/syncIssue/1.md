## How it works

1. Initializes `var wg sync.WaitGroup`.
2. Launches multiple goroutines that sleep for random millisecond intervals.
3. Each worker prints its start and finish status.
4. `wg.Wait()` blocks `main` until all random workers have completed.

## Key excerpt

```go
func main() {
	var wg sync.WaitGroup
	for i := 1; i <= 5; i++ {
		wg.Add(1)
		go func(id int) {
			defer wg.Done()
			sleep := time.Duration(rand.Intn(500)) * time.Millisecond
			time.Sleep(sleep)
			fmt.Printf("Worker %d finished\n", id)
		}(i)
	}
	wg.Wait()
}
```
