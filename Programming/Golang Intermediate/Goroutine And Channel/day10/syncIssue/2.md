This program demonstrates concurrent file parsing in Go, spawning goroutines to read disk files concurrently with `bufio.Scanner` and aggregating line count metrics.

## How it works

1. Opens input files concurrently across multiple goroutines.
2. Reads line-by-line using `scanner.Scan()`.
3. Safely records line counts into a shared aggregator.
4. Logs progress and file metrics.

## Key excerpt

```go
scanner := bufio.NewScanner(file)
count := 0
for scanner.Scan() {
	count++
}
if err := scanner.Err(); err != nil {
	log.Fatal(err)
}
```
