## Overview

This program demonstrates how to use `sync.Once` in Go to perform thread-safe, one-time initialization, ensuring a setup routine runs exactly once regardless of how many goroutines call it concurrently.

## Concepts used

- `sync.Once` primitive
- Atomic one-time function execution (`once.Do(f)`)
- Thread-safe lazy initialization

## How it works

1. Declares `var once sync.Once`.
2. Multiple goroutines call `Init()`.
3. Inside `Init()`, calls `once.Do(setup)`.
4. The Go runtime executes `setup()` on the first call while blocking subsequent callers until `setup` returns; all further calls do nothing.

## Key excerpt

```go
var once sync.Once

func setup() {
	fmt.Println("Performing one-time initialization...")
}

func Init() {
	once.Do(setup)
}
```

## Expected behavior (from reading the code, not run)

- Prints `"Performing one-time initialization..."` exactly once, even when called concurrently from dozens of goroutines.

## Things to watch

- If the function passed to `once.Do` panics, `sync.Once` considers the initialization complete; future calls will NOT retry the function.

## Terms

- **sync.Once**: An object that will perform an action exactly once.
- **Lazy initialization**: Delaying object creation until the first time it is accessed.
