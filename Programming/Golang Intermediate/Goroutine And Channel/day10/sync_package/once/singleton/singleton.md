## Overview

This program implements the classic Singleton design pattern in Go using `sync.Once`, guaranteeing that a shared database connection instance is instantiated exactly once in a multi-threaded environment.

## How it works

1. `DbInstance` struct represents a shared database connection resource.
2. Package-level `var instance *DbInstance` and `var once sync.Once`.
3. `GetInstance() *DbInstance` uses `once.Do(func() { instance = &DbInstance{} })` to lazily construct the instance.
4. Returns the identical pointer instance to all callers.

## Key excerpt

```go
type DbInstance struct {
	// database connection pool
}

var (
	instance *DbInstance
	once     sync.Once
)

func GetInstance() *DbInstance {
	once.Do(func() {
		fmt.Println("Connecting to Database...")
		instance = &DbInstance{}
	})
	return instance
}
```

## Things to watch

- `sync.Once` avoids the double-checked locking antipattern by internally utilizing fast atomic load operations before falling back to mutex acquisition.

## Terms

- **Singleton Pattern**: A software creational pattern restricting object instantiation to a single global instance.
- **Double-checked locking**: A concurrency pattern used to reduce lock overhead by checking a condition before and after locking.
