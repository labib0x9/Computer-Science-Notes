This program demonstrates how to launch a function into a background concurrent thread of execution using Go's `go` keyword and highlights why the main routine must wait for child completion.

## How it works

1. Defines `Goroutine()` which launches `go Print("world")`.
2. Explains that since `main()` is itself a goroutine, if `main` terminates without synchronization, the child call is prematurely aborted.

## Things to watch

- Functions called with `go` cannot return values directly; communication and output must flow through channels or shared synchronized state.

## Terms

- **go statement**: Starts execution of a function call as an independent concurrent thread of control within the same address space.
