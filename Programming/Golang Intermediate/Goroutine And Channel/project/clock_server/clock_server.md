## Overview

This program implements a concurrent TCP clock server in Go, accepting inbound network connections and periodically transmitting current timestamps to each connected client every second.

## Concepts used

- TCP socket listener via `net.Listen("tcp", "...")`
- Handling connections concurrently in goroutines (`go handleConn(c)`)
- Periodic ticking via `time.Sleep` or `time.Tick`

## How it works

1. Binds TCP listener to `127.0.0.1:8080`.
2. Loops accepting client connections via `listener.Accept()`.
3. Spawns a goroutine for each client connection.
4. In the handler, loops indefinitely writing formatted timestamps (`time.Now().Format(...)`) followed by a 1-second pause.

## Key excerpt

```go
// Connect to server using netcat: nc 127.0.0.1 8080
listener, err := net.Listen("tcp", "127.0.0.1:8080")
if err != nil {
	panic(err)
}

for {
	conn, err := listener.Accept()
	if err != nil {
		continue
	}
	go handleConn(conn)
}
```

## Expected behavior (from reading the code, not run)

- Clients connecting via `nc 127.0.0.1 8080` receive live timestamp lines updated once per second.

## Things to watch

- When a client disconnects, write attempts fail with an error; the handler must catch this error and close the connection to avoid leaking goroutines.
