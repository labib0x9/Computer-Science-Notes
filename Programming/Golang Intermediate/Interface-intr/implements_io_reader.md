## Overview

This program demonstrates how to implement Go's foundational `io.Reader` interface by wrapping a raw operating system file descriptor and invoking `syscall.Read`.

## Concepts used

- The standard `io.Reader` contract (`Read(p []byte) (n int, err error)`)

## How it works

1. `syscallReader` struct stores a raw integer file descriptor `fd`.
2. It satisfies `io.Reader` by defining `Read(p []byte) (n int, err error)`, delegating directly to `syscall.Read(s.fd, p)`.
3. `ReadTenBytes(r io.Reader)` accepts any `io.Reader`, allocating a 10-byte buffer and reading from it.

## Key excerpt

```go
type syscallReader struct {
	fd int	// file descriptor
}

// Necessary method to implement io.Reader
func (s *syscallReader) Read(p []byte) (n int, err error) {
	n, err = syscall.Read(s.fd, p)
	return
}

func ReadTenBytes(r io.Reader) {
	b := make([]byte, 10)
	n, err := r.Read(b)
	fmt.Println(n, err, string(b[:n]))
}
```

## Expected behavior (from reading the code, not run)

- Reads up to 10 bytes from the associated file descriptor and prints the byte count and read slice content.

## Things to watch

- Pointer receiver `(s *syscallReader)` means only `*syscallReader` satisfies `io.Reader`, not the value type `syscallReader`.
- Directly using `syscall` is platform-dependent; higher-level `os.File` is standard in production.

## Terms

- **File descriptor**: A low-level integer handle used by Unix kernels to reference open file or socket streams.
- **io.Reader**: Go's core streaming input abstraction specifying `Read(p []byte) (n int, err error)`.
