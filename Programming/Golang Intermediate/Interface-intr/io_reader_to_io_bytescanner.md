## How it works

1. `byteReader` wraps an underlying `io.Reader` alongside internal state fields (`buf [1]byte`, `unread bool`, `prevBuf byte`, `firstCall bool`).
2. `ReadByte()` checks if an unread byte is pending; if so, returns it and resets the `unread` flag; otherwise, reads 1 byte from `b.r`.
3. `UnreadByte()` marks the most recently read byte as unread so subsequent calls to `ReadByte()` will yield it again.

## Key excerpt

```go
type byteReader struct {
	r         io.Reader
	buf       [1]byte
	unread    bool
	prevBuf   byte
	firstCall bool
}

func (b *byteReader) ReadByte() (byte, error) {
	if b.unread {
		b.unread = false
		return b.prevBuf, nil
	}
	n, err := b.r.Read(b.buf[:])
	if err != nil {
		return 0, err
	}
	b.prevBuf = b.buf[0]
	return b.buf[0], nil
}
```
