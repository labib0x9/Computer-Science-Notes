## How it works

1. `UserService` struct holds a private field `logger Logger`.
2. `NewUserService(l Logger) *UserService` acts as a factory constructor accepting any type satisfying `Logger`.
3. `CreateUser(user string)` logs the creation attempt and prints confirmation.

## Key excerpt

```go
type UserService struct {
	logger Logger
}

func NewUserService(l Logger) *UserService {
	return &UserService{
		logger: l,
	}
}

func (us *UserService) CreateUser(user string) {
	us.logger.Log("Creating user: " + user)
	fmt.Println("User created")
}
```
