## Things to watch

- Methods use value receivers (`p Paypal`), which copy the struct on every method call.
- Struct fields (`accountId`, `number`) are unexported (lowercase initial letters).

## Terms

- **Value receiver**: A method receiver that receives a copy of the caller value rather than a pointer to it.
- **Polymorphism**: The ability of different types to be used interchangeably when they satisfy a common interface.
