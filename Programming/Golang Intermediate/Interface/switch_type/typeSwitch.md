## Overview

This program demonstrates how to inspect and extract concrete dynamic types from an interface value using Go's `switch .(type)` syntax, contrasting variable-bound and unbound forms.

## Concepts used

- Empty interface `interface{}` (equivalent to `any`)
- Type switch expression `switch v := i.(type)`
- Dynamic type identification at runtime

## How it works

1. `detectDataType(i interface{})` receives an arbitrary type.
2. In the first switch, `switch v := i.(type)` evaluates the concrete type and binds `v` with that specific type inside each case branch (e.g. `string`, `int`, `float64`).
3. In the second switch, `switch i.(type)` checks the type without binding a typed variable.

## Key excerpt

```go
func detectDataType(i interface{}) {
	// With variable
	switch v := i.(type) {
	case string:
		fmt.Println(v, ": String")
	case int:
		fmt.Println(v, ": Int")
	case float64:
		fmt.Println(v, ": Float")
	}

	// Without variable
	switch i.(type) {
	case string:
		fmt.Println("Without variable string")
	}
}
```

## Expected behavior (from reading the code, not run)

- If passed a `string` (e.g., `"hello"`), prints `"hello : String"` followed by `"Without variable string"`.
- If passed an `int`, prints the integer with `": Int"`.

## Things to watch

- A type switch is only valid on interface values; calling `x.(type)` on a concrete type fails compilation.
- Inside each `case` branch of `switch v := i.(type)`, variable `v` has the exact concrete type specified by the case.

## Terms

- **Type switch**: A construct that compares the concrete dynamic type of an interface value against multiple type guards.
- **Dynamic type**: The actual underlying concrete type stored in an interface container at runtime.
