## Overview

This program demonstrates interface polymorphism alongside runtime type assertions to discover specialized sub-capabilities (such as recording) from a general media player interface.

## Concepts used

- Interface contract `Playable` (`Play`, `Stop`)
- Polymorphic function dispatching playlist iterations
- Type assertion to uncover extended recorder capabilities

## How it works

1. `TapePlayer` and `TapeRecorder` both implement `Playable`.
2. `PlayList(device Playable, songs []string)` iterates over songs and plays them.
3. If `device` can be asserted to a `TapeRecorder`, specialized recording actions are triggered.

## Key excerpt

```go
type Playable interface {
	Play(song string)
	Stop()
}

func main() {
	songs := []string { "song 1", "song 2" }
	
	tapePlayer := TapePlayer{}
	PlayList(tapePlayer, songs)

	rsongs := []string { "song 4", "song 3" }
	recorder := TapeRecorder{}
	PlayList(recorder, rsongs)
}
```

## Expected behavior (from reading the code, not run)

- Iterates through lists of songs and outputs playback messages for both `TapePlayer` and `TapeRecorder`.

## Things to watch

- Designing interfaces around common behaviors (`Playable`) allows client code to operate uniformly while using assertions only when specific capabilities are required.

## Terms

- **Capability interface**: An interface representing a specific optional behavior or feature set that can be queried at runtime via type assertions.
