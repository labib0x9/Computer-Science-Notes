## How it works

1. `log.Println("[Log] error")`:
   - Prints current date, time, and the log message to standard error.
2. `log.Printf("ip %s failed to start at port %s", ipAddr, port)`:
   - Formats variables using `printf`-style verbs and outputs with timestamps.

## Things to watch

- **log.Fatal exits process**: `log.Fatal` prints the log message and immediately calls `os.Exit(1)`, skipping deferred functions.
- **Stderr destination**: By default, the standard `log` package writes to standard error (`os.Stderr`), not standard output (`os.Stdout`).
