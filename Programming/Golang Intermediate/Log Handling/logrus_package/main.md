## Overview

This program demonstrates structured logging using `github.com/sirupsen/logrus`. It configures a custom logger instance with JSON formatting, sets minimum severity levels, and attaches key-value metadata fields via `WithFields`.

## Concepts used

- Creating independent logger instances via `logrus.New()`
- JSON serialization of log events (`logrus.JSONFormatter`)
- Log severity levels (`DebugLevel`, `InfoLevel`, `WarnLevel`, `ErrorLevel`)
- Attaching structured fields with `logger.WithFields`

## How it works

1. `logger := logrus.New()` instantiates a dedicated logger.
2. `logger.SetFormatter(&logrus.JSONFormatter{})` instructs Logrus to serialize each log line as a JSON object.
3. `logger.SetLevel(logrus.InfoLevel)` filters out debug messages.
4. `logger.WithFields(logrus.Fields{"user_id": 123, "ip": "127.0.0.1"}).Info("User logged in")` outputs structured metadata alongside the message.

## Key excerpt

```go
func main() {

	logger := logrus.New()

	logger.SetFormatter(&logrus.JSONFormatter{})
	logger.SetLevel(logrus.InfoLevel)

	logger.WithFields(logrus.Fields{
		"event": "user_signup",
		"topic": "security",
	}).Info("A new user registered")
}
```

## Things to watch

- **Logrus maintenance mode**: The authors of Logrus placed it in maintenance mode in favor of standard structured logging packages like `log/slog` or high-throughput alternatives like `uber-go/zap`.

## Terms

- **Structured Logging**: Logging records with structured key-value attributes rather than raw unformatted strings.
