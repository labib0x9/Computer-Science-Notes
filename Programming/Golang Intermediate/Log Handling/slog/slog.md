## Overview

This program demonstrates Go 1.21's standard structured logging package `log/slog`. It shows how to configure custom handlers (`TextHandler`, `JSONHandler`), set global default loggers, and attach structured attributes to log records.

## How it works

1. It creates a `TextHandler` writing to `os.Stdout`: `slog.New(slog.NewTextHandler(os.Stdout, nil))`.
2. It sets it as the default logger: `slog.SetDefault(logger)`.
3. It logs messages with structured key-value pairs:
   ```go
   slog.Info("Service started", "port", 8080, "env", "production")
   ```
4. It demonstrates contextual loggers: `subLogger := logger.With("service", "auth")` which automatically attaches `"service": "auth"` to all subsequent logs emitted by that handle.

## Key excerpt

```go
func main() {

	logger := slog.New(slog.NewTextHandler(os.Stdout, nil))
	slog.SetDefault(logger)

	slog.Info("Application startup",
		"port", 8080,
		"status", "healthy",
	)
}
```

## Things to watch

- **Performance with slog.Attr**: For high-performance logging, use strongly typed attributes like `slog.Int("port", 8080)` instead of loose key-value pairs to avoid allocation overhead during interface conversion.

## Terms

- **slog**: Go standard library structured logging package introduced in Go 1.21.
- **Handler**: The component in `slog` responsible for formatting and writing log records to a destination.
