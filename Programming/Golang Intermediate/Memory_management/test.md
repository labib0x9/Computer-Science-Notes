## How it works

1. Global variable `var a = 10` is stored in the data segment.
2. `add(x, y int) int` performs `z := x + y` and returns `z` directly by value.
3. `main()` calls `add(2, 4)` and `add(a, 5)`.
4. Escape analysis reveals zero heap allocations because no pointers or interface boxing are involved.

## Things to watch

- Functions this small are prime candidates for compiler inlining (`can inline add`), eliminating function call overhead completely.

## Terms

- **Function inlining**: An optimization where the compiler replaces a function call with the actual code of the function itself.
- **Pass-by-value**: Arguments and return values are copied into registers or stack frames.
