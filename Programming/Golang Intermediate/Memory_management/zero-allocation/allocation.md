## How it works

1. Creates byte slice `b := []byte("Hello World")`.
2. Takes header address `unsafe.Pointer(&b)`.
3. Converts byte slice to string: `s := string(b)`. In standard Go, this allocates a new string copy on the heap to preserve immutability.
4. Takes string header address `unsafe.Pointer(&s)`.

## Key excerpt

```go
b := []byte("Hello World")

ptr := unsafe.Pointer(&b)
fmt.Println(ptr)

s := string(b)
ptr = unsafe.Pointer(&s)
fmt.Println(ptr)

sl := []int{1, 2, 3}
ptr = unsafe.Pointer(&sl)
fmt.Println(ptr)
```

## Things to watch

- `string(b)` is a memory-allocating copy operation. In performance-critical zero-allocation code, `unsafe.String` or compiler-optimized map lookups are used instead.

## Terms

- **Unsafe pointer**: An untyped pointer in Go (`unsafe.Pointer`) allowing bypass of Go's static type safety rules.
- **Header copy**: Copying the descriptor struct (pointer, length, cap) rather than the underlying array data.
