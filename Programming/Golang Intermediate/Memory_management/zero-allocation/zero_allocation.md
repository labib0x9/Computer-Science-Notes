## Concepts used

## How it works

1. Preallocates a slice with high capacity `s := make([]int, 10, 10000)` and resets length with `s = s[:0]`.
2. References `sync.Pool` for thread-safe temporary object recycling.
3. Pre-sizes string building with `var x strings.Builder; x.Grow(10000)` before appending strings to avoid intermediate reallocations.

## Terms

- **Zero-allocation**: Writing code in such a way that the steady-state execution path triggers zero dynamic heap allocations.
- **strings.Builder.Grow**: Preallocates byte slice buffer capacity to fit $N$ additional bytes without reallocations.
