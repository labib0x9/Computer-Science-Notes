## Overview

This program demonstrates CGO interoperability in Go, embedding inline C functions inside preamble comments and invoking them directly from Go routines via the pseudo-package `C`.

[basic.go](https://github.com/labib0x9/Programming-Notes/blob/main/Programming/Golang%20Intermediate/Pointer/cgo/basic.go)

## Concepts used

- CGO comment preamble syntax
- Importing the `C` pseudo-package
- Calling C functions (`C.Print`, `C.Add`, `C.Mult`) from Go

## How it works

1. Places inline C function declarations and definitions inside block comments directly preceding `import "C"`.
2. Implements `Print(int)`, `Add(int, int)`, and `Mult(int, int)` in C.
3. In `main()`, calls `C.Print(10)`, `C.Add(2, 3)`, and `C.Mult(4, 5)`.

## Key excerpt

```go
/*
#include<stdio.h>
#include<stdlib.h>

void Print(int x) {
	printf("%d\n", x);
}

int Add(int a, int b) {
	return a + b;
}
*/
import "C" // Note: no blank line allowed between comment and import

func main() {
	C.Print(10)
	sum := C.Add(5, 7)
	fmt.Println("Sum:", sum)
}
```

## Expected behavior (from reading the code, not run)

- Prints `10` to standard output via C's `printf`.
- Computes addition and multiplication in C and returns integer results to Go.

## Things to watch

- CRITICAL: There must be NO blank lines between the closing comment `*/` and `import "C"`; any gap causes CGO compilation to fail.
- CGO calls incur a small performance overhead (context switching between Go goroutine stacks and C system stacks).

## Terms

- **CGO**: A Go tool enabling Go packages to call C code and vice versa.
- **Preamble**: The C code embedded in comments immediately above `import "C"`.
