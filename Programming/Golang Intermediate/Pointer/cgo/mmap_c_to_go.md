## How it works

1. C preamble defines `struct Header` representing a PCAP file header with `MagicByte`, version fields, and snap length.
2. In Go, maps the file into memory using C's `open` and `mmap`.
3. Casts the resulting void pointer into a Go struct pointer via `unsafe.Pointer`.
4. Inspects packet capture magic bytes (`0xa1b2c3d4`) to determine format version and endianness.

## Terms

- **Magic byte**: Distinct constant numeric values located at the beginning of files to identify their file format.
