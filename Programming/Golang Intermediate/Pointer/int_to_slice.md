## Overview

This program demonstrates how to project a primitive Go integer variable into a byte slice (`[]byte`) using `unsafe.Pointer` and `unsafe.Slice`, allowing byte-level inspection and mutation.

## Concepts used

- Variable size calculation with `unsafe.Sizeof`
- Pointer conversion from `*int` through `unsafe.Pointer` to `*byte`
- Constructing slices from pointers using `unsafe.Slice`

## How it works

1. Allocates `var x int = 256`.
2. Computes the machine word size: `intSize := unsafe.Sizeof(x)` (8 bytes on 64-bit).
3. Casts address to byte pointer: `ptr := (*byte)(unsafe.Pointer(&x))`.
4. Creates byte slice `xByte := unsafe.Slice(ptr, intSize)`.
5. Modifying `x` immediately alters the elements visible inside `xByte`.

## Key excerpt

```go
var x int = 256
intSize := unsafe.Sizeof(x)

ptr := (*byte)(unsafe.Pointer(&x))
xByte := unsafe.Slice(ptr, intSize) // int -> []byte

fmt.Println(xByte)
x = 123456 // changes xByte in place
fmt.Println(xByte)
```

## Expected behavior (from reading the code, not run)

- Prints the raw byte representations of 256 and 123456 according to little-endian representation.

## Things to watch

- Slices constructed with `unsafe.Slice` pointing to stack variables become invalid if the slice escapes beyond the enclosing function lifetime.

## Terms

- **unsafe.Slice**: Built-in function taking a pointer and length to return a slice backed by that memory.
- **Machine word**: The natural data size used by a computer processor (e.g. 64 bits = 8 bytes).
