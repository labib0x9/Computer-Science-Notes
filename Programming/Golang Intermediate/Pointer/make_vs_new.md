## Overview

This program clarifies the fundamental differences between declaring uninitialized pointer variables, allocating zero-valued memory with `new()`, and allocating built-in composite structures with `make()`.

## Concepts used

- Nil pointer initialization (`var x *int`)
- Memory allocation with `new(T)` returning `*T`
- Reflection type inspection with `reflect.TypeOf`

## How it works

1. `var x *int` initializes an unallocated pointer with value `nil`.
2. `var y = new(int)` allocates zeroed storage for an `int` and returns pointer `*int`.
3. Inspects and compares their reflection types and kinds via helper `whatType(t reflect.Type)`.

## Key excerpt

```go
func whatType(t reflect.Type) {
	fmt.Println(t)
	fmt.Println(t.Kind())
}

func main() {
	var x *int
	var y = new(int)

	t := reflect.TypeOf(x)
	whatType(t)
}
```

## Expected behavior (from reading the code, not run)

- Both `x` and `y` have reflection type `*int` and kind `ptr`.
- `x` evaluates to `nil`, whereas `y` points to a valid memory cell containing zero.

## Things to watch

- `new()` allocates zeroed storage for any type and returns a pointer. `make()` applies exclusively to slices, maps, and channels, initializing internal descriptors.

## Terms

- **new**: Built-in function allocating memory for a type and returning a pointer `*T`.
- **make**: Built-in function initializing slices, maps, and channels, returning initialized value `T`.
