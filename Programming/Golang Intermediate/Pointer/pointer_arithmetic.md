## How it works

## Things to watch

- CRITICAL: A `uintptr` is an integer, not a pointer. The garbage collector does not track `uintptr` values. Storing a pointer as `uintptr` across GC safepoints can lead to the referenced object being moved or garbage collected. Conversions between `unsafe.Pointer` and `uintptr` must occur in a single expression.

## Terms

- **uintptr**: An integer type large enough to hold the bit pattern of any pointer.
- **Stride**: The number of bytes between successive elements in contiguous memory.
