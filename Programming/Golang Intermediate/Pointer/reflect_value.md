## Overview

This program demonstrates how to inspect pointer values and dynamically dereference them using Go's `reflect.ValueOf` and `.Elem()` methods.

## Concepts used

- Dynamic value inspection with `reflect.ValueOf`
- Reflection kind checking (`rv.Kind() == reflect.Ptr`)
- Dereferencing pointer values via `rv.Elem()`

## How it works

1. Allocates an integer pointer `var pInt *int = new(int)`.
2. Inspects with `rv := reflect.ValueOf(pInt)`.
3. Demonstrates `rv.Type()` is `*int`, `rv.Kind()` is `reflect.Ptr`.
4. Dereferences the pointer value using `rv.Elem()`, yielding an `int` reflection value.

## Key excerpt

```go
var pInt *int = new(int)
rv := reflect.ValueOf(pInt)

// ptr
fmt.Println(rv)
fmt.Println(rv.Type())
fmt.Println(rv.Kind())

// elem -> int
fmt.Println(rv.Elem())
```

## Expected behavior (from reading the code, not run)

- Prints the pointer memory address.
- Prints `*int`.
- Prints `ptr`.
- Prints `0` (the default value of the dereferenced integer).

## Things to watch

- To modify the value pointed to by a pointer via reflection, use `rv.Elem().SetInt(...)`. Calling `.Set` directly on `rv` will panic.

## Terms

- **reflect.Value**: A reflection struct encapsulating a concrete value and its type information.
- **rv.Elem()**: Returns the value that the reflection interface or pointer `rv` points to.
