## Overview

This program demonstrates array sub-slicing in Go, using `unsafe.Pointer` to verify that sub-slices share identical memory locations with the original backing storage without allocating new memory.

## How it works

1. Allocates a 1024-byte array `bigBuf [1024]byte` and copies text into it.
2. Creates sub-slice `s1 := bigBuf[l:r]` between indices 6 and 21.
3. Prints the string representation of `s1`.
4. Compares `unsafe.Pointer(&bigBuf[l])` with `unsafe.Pointer(&s1[0])`, proving they point to the identical byte address.

## Key excerpt

```go
var bigBuf [1024]byte
copy(bigBuf[:], []byte("hello labib al faisal, how is your learning going ?"))

l, r := 6, 21
s1 := bigBuf[l:r]

fmt.Println(s1)
fmt.Println(string(s1))

fmt.Println(unsafe.Pointer(&bigBuf[l]))
fmt.Println(unsafe.Pointer(&s1[0]))
```

## Expected behavior (from reading the code, not run)

- Prints the slice bytes and text `"labib al faisal"`.
- Prints identical hexadecimal memory addresses for `bigBuf[l]` and `s1[0]`.

## Things to watch

- Since sub-slices share backing arrays, mutating `s1` mutates `bigBuf` at those indices.

## Terms

- **Sub-slice**: A slice derived by slicing an existing array or slice with `[low:high]`.
- **Shared backing store**: The contiguous memory block referenced by multiple slices simultaneously.
