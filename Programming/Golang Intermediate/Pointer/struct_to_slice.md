## Overview

This program demonstrates zero-copy struct serialization in Go, casting a concrete struct pointer into a raw byte slice (`[]byte`) to access its contiguous memory bytes directly.

## Concepts used

- Struct sizing via `unsafe.Sizeof`
- Memory reinterpretation with `unsafe.Slice`
- Zero-copy binary serialization

## How it works

1. Defines `User` struct with `name string` (16 bytes) and `age int` (8 bytes).
2. Obtains user instance: `u := GetUser()`.
3. Measures struct size: `sz := unsafe.Sizeof(u)` (24 bytes).
4. Creates byte slice spanning the struct memory: `buf := unsafe.Slice((*byte)(unsafe.Pointer(&u)), sz)`.
5. Prints raw byte contents of the struct.

## Key excerpt

```go
type User struct {
	name string
	age  int
}

u := GetUser()
sz := unsafe.Sizeof(u)

ptr := (*byte)(unsafe.Pointer(&u))
buf := unsafe.Slice(ptr, sz)

fmt.Println("Struct size:", sz)
fmt.Println("Raw bytes  :", buf)
```

## Expected behavior (from reading the code, not run)

- Prints 24 for the struct size.
- Prints the 24 individual bytes corresponding to the string header (data pointer + length) followed by the integer age.

## Things to watch

- Serializing structs containing pointers or strings directly to disk or network sends memory addresses rather than the referenced string text.

## Terms

- **Shallow serialization**: Copying only the immediate struct fields rather than deep-copying referenced data.
- **unsafe.Pointer cast**: Converting directly between unrelated pointer types.
