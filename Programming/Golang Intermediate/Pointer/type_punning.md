## Overview

This program demonstrates type punning in Go, reinterpreting the raw memory bits of a floating-point number (`float64`) as an unsigned integer (`uint64`) without triggering numeric value conversion.

## How it works

1. Initializes `var f float64 = 3.1416`.
2. Takes pointer `&f` and converts to `unsafe.Pointer(&f)`.
3. Casts to `(*uint64)` and dereferences: `*(*uint64)(unsafe.Pointer(&f))`.
4. Prints `x`, which contains the IEEE 754 binary bit representation of 3.1416 instead of the integer 3.

## Key excerpt

```go

// Type punning: reinterpret memory as uint64
var x uint64 = *(*uint64)(unsafe.Pointer(&f))

fmt.Println(x)
```
