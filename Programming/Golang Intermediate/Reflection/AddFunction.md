## How it works

1. `Add(a, b interface{}) interface{}` accepts two arbitrary values.
2. Compares their kinds: if operands belong to different kinds, returns a type mismatch error.
3. Switches on `vA.Kind()`:
   - For integer kinds, returns `vA.Int() + vB.Int()`.
   - For floating-point kinds, returns `vA.Float() + vB.Float()`.

## Key excerpt

```go
func Add(a, b interface{}) interface{} {
	vA := reflect.ValueOf(a)
	vB := reflect.ValueOf(b)
	if vA.Kind() != vB.Kind() {
		return fmt.Errorf("type mismatch: a=%s, b=%s", vA.Kind(), vB.Kind())
	}

	switch vA.Kind() {
	case reflect.Int, reflect.Int8, reflect.Int16, reflect.Int32, reflect.Int64:
		return vA.Int() + vB.Int()
	case reflect.Float32, reflect.Float64:
		return vA.Float() + vB.Float()
	}
	return fmt.Errorf("unsupported type: %s", vA.Kind())
}
```
