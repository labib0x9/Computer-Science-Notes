## How it works

2. Traces how assigning `x = 42` sets the dynamic pair to `(int, 42)`.
3. Traces assigning `x = "Hello, World!"` setting the dynamic pair to `(string, "Hello, World!")`.
4. Inspects both using `reflect.TypeOf(x)` and `reflect.ValueOf(x)`.

## Key excerpt

```go
// At compile time: static type is interface{}
var x interface{}

// At runtime: dynamic pair (type, value)
x = 42
fmt.Println(reflect.TypeOf(x), reflect.ValueOf(x)) // int 42

x = "Hello, World!"
fmt.Println(reflect.TypeOf(x), reflect.ValueOf(x)) // string Hello, World!
```

## Things to watch

- An interface value is only `nil` when both its dynamic type and dynamic value are `nil`. An interface containing a typed nil pointer (`(*int)(nil)`) is NOT equal to `nil`.

## Terms

- **Static type**: The type declared in the source code that the compiler checks at compile time.
- **Dynamic type**: The concrete type stored inside an interface container at runtime.
