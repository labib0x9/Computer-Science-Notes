## Concepts used

- `reflect.TypeOf(v)`
- `.Name()` vs `.String()` on unnamed composite types

## How it works

1. `Print(v interface{})` inspects arbitrary values.
2. Calls `reflect.TypeOf(v)`: outputs string representation (e.g. `[]int`).
3. Calls `.Name()`: outputs empty string `""` because slices are unnamed composite types.
4. Calls `.Kind()`: outputs `slice`.
5. Calls `.Elem().Kind()`: dereferences slice container to reveal element kind `int`.

## Key excerpt

```go
func Print(v interface{}) {
	fmt.Println(reflect.TypeOf(v))
	fmt.Println(reflect.TypeOf(v).Name())
	fmt.Println(reflect.TypeOf(v).Kind())
	fmt.Println(reflect.TypeOf(v).Elem().Kind())
	fmt.Println("-----")
}

func main() {
	sl := make([]int, 0, 10)
	Print(sl) // []int, "", slice, int
}
```

## Things to watch

- Unnamed types (slices, maps, channels, anonymous structs) return `""` for `.Name()`. Only defined types (`type MySlice []int`) have a non-empty `.Name()`.

## Terms

- **Defined type**: A type introduced with a `type` declaration (e.g. `type MyInt int`).
- **Unnamed type**: A type composed of type constructors without an explicit name (e.g. `[]int`, `map[string]int`).
