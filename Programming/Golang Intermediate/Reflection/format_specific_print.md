## How it works

1. `printTypeAndValue(x interface{}, verb rune)` accepts an arbitrary value and formatting verb.
2. Obtains `t := reflect.TypeOf(x)` and `v := reflect.ValueOf(x)`.
3. If `verb == 'T'`, prints type only: `fmt.Println("Type:", t)`.
4. If `verb == 'V'`, prints value only: `fmt.Println("Value:", v)`.
5. If `verb == 'B'`, prints both type and value.

## Key excerpt

```go
func printTypeAndValue(x interface{}, verb rune) {
	t := reflect.TypeOf(x)
	v := reflect.ValueOf(x)

	switch verb {
	case 'T':
		fmt.Println("Type:", t)
	case 'V':
		fmt.Println("Value:", v)
	case 'B':
		fmt.Println("Type:", t, "Value:", v)
	}
}
```

## Terms

- **Formatting verb**: A character directing how an argument should be formatted.
