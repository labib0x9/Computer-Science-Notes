## Concepts used

## How it works

1. Defines `type MyInt int` and initializes `var x MyInt = 42`.
2. Inspects with `v := reflect.ValueOf(x)`.
3. Demonstrates `v.Kind() == reflect.Int` evaluates to `true` (dynamic underlying kind).
4. Demonstrates `v.Type().Name() == "MyInt"` evaluates to `true` (defined type name).
5. Extracts integer value via `v.Int()`.
6. Confirms `v.CanInterface()` is `true`, allowing `v.Interface()` conversion.

## Key excerpt

```go
type MyInt int

var x MyInt = 42
v := reflect.ValueOf(x)

fmt.Println(v.Kind() == reflect.Int)    // true
fmt.Println(v.Type().Name() == "MyInt") // true
fmt.Println(v.Int())                    // 42
fmt.Println("Can interface:", v.CanInterface()) // true
```
