## Concepts used

- Custom defined types (`type MyInt int`, `type AnotherMyInt MyInt`)
- Static name retrieval with `t.Name()`
- Underlying kind retrieval with `t.Kind()`

## How it works

1. Defines `type MyInt int` and `type AnotherMyInt MyInt`.
2. Initializes `var x MyInt = 42`.
3. Obtains `t := reflect.TypeOf(x)`.
4. Shows `t.Name()` returns `"MyInt"`, the defined type name.
5. Shows `t.Kind()` returns `reflect.Int`, the underlying machine kind.

## Key excerpt

```go
type MyInt int
type AnotherMyInt MyInt

var x MyInt = 42
t := reflect.TypeOf(x)

fmt.Println("Type name:", t.Name()) // "MyInt"
fmt.Println("Type kind:", t.Kind()) // "int"
```

## Terms

- **reflect.Type**: The reflection interface representing a Go type.
- **Kind**: The categorization of a type into a fixed set of basic kinds (Int, Float, Slice, Struct, etc.).
