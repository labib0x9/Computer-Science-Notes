## Overview

This program demonstrates how `reflect.Value` exposes both the static type descriptor via `.Type()` and the dynamic machine kind via `.Kind()`.

## Concepts used

- `v := reflect.ValueOf(x)`
- `v.Type()` returning `reflect.Type`
- `v.Kind()` returning `reflect.Kind`

## How it works

1. Defines `type MyInt int`.
2. Initializes `var x MyInt = 42`.
3. Calls `v := reflect.ValueOf(x)`.
4. Queries `v.Type()`: returns `main.MyInt`.
5. Queries `v.Kind()`: returns `int`.

## Key excerpt

```go
type MyInt int
type AnotherMyInt MyInt

var x MyInt = 42
v := reflect.ValueOf(x)

fmt.Println("v.Type():", v.Type()) // main.MyInt
fmt.Println("v.Kind():", v.Kind()) // int
```

## Expected behavior (from reading the code, not run)

- Prints `v.Type(): main.MyInt`
- Prints `v.Kind(): int`

## Things to watch

- Calling `v.Type()` on a zero `reflect.Value` returns `nil`. Always check `v.IsValid()` before calling `.Type()`.

## Terms

- **Zero reflect.Value**: An invalid reflection value representing no concrete Go value, obtained when reflecting a bare untyped `nil`.
