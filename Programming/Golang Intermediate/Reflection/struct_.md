## Overview

This program demonstrates how to inspect struct layouts and read field tag annotations at runtime using Go's reflection package.

## Concepts used

- Struct reflection on pointer instances (`reflect.TypeOf(&u).Elem()`)
- Iterating fields with `NumField()` and `Field(i)`
- Extracting struct tag attributes (`field.Tag.Get("info")`)

## How it works

1. Defines `User` struct with `Name string` and `Age MyInt` decorated with tag `` `info:"age"` ``.
2. Initializes `u := User{Name: "Faisal", Age: 12}`.
3. Retrieves struct reflection type `ut := reflect.TypeOf(&u).Elem()`.
4. Loops from 0 to `ut.NumField() - 1`.
5. Reads field name, field type, and queries tag values via `field.Tag.Get("info")`.

## Key excerpt

```go
type MyInt int

type User struct {
	Name string
	Age  MyInt `info:"age"`
}

u := User{Name: "Faisal", Age: 12}
ut := reflect.TypeOf(&u).Elem()

for i := 0; i < ut.NumField(); i++ {
	f := ut.Field(i)
	fmt.Printf("Field: %s, Type: %s, Tag: %s\n", f.Name, f.Type, f.Tag.Get("info"))
}
```

## Expected behavior (from reading the code, not run)

- Prints field `Name` with type `string` and empty tag.
- Prints field `Age` with type `main.MyInt` and tag `age`.

## Things to watch

- Struct tags are simple string literals. Key-value convention requires format `key:"value"`; malformed spacing prevents `Tag.Get()` from matching keys.

## Terms

- **Struct tag**: A string literal attached to a struct field providing metadata for encoding libraries (JSON, ORM, validation).
- **NumField**: Method returning the total number of fields in a struct type.
