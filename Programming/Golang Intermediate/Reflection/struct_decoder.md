## How it works

1. `Store` struct defines fields with `map` tags (e.g. `Key string` with `` `map:"key"` `` and `Value MyInt` with `` `map:"value"` ``).
2. Decoder receives a map and a pointer to the destination struct.
3. Obtains `v := reflect.ValueOf(dest).Elem()`.
4. Inspects each field's tag: if matching key is present in the map, converts string to target field type (string or integer) and populates the field via `fieldVal.SetString()` or `fieldVal.SetInt()`.

## Things to watch

- To mutate a struct through reflection, you must pass a POINTER to the struct (`&store`) and call `.Elem()`. Passing a struct by value produces an unsettable reflection value where `CanSet()` is `false`.

## Terms

- **Settability**: The property of a `reflect.Value` that indicates whether its underlying memory can be modified via reflection (`CanSet()`).
- **Deserializer**: A routine that reconstructs in-memory data structures from serialized representations.
