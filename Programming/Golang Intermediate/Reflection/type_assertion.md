## Overview

This program demonstrates how an interface variable encapsulating an operating system file descriptor (`*os.File`) stores both the dynamic type descriptor and pointer value, inspecting both using reflection.

## Concepts used

- The `io.Reader` interface
- Wrapping concrete file pointers (`*os.File`) in interfaces
- Inspecting dynamic interface type and value via reflection

## How it works

1. Opens a file `test.txt` and obtains `file *os.File`.
2. Assigns file to interface: `var r io.Reader = file`.
3. At runtime, `r` internally holds `{type: *os.File, value: <file pointer address>}`.
4. Uses reflection to confirm that `reflect.TypeOf(r)` is `*os.File` and `reflect.ValueOf(r)` holds the pointer.

## Key excerpt

```go
var r io.Reader
file, err := os.OpenFile("test.txt", os.O_CREATE|os.O_RDWR, 0644)
if err != nil {
	fmt.Println("Error opening file:", err)
	return
}
defer file.Close()

r = file // r = {type: *os.File, value: 0x...}
fmt.Println(reflect.TypeOf(r))  // *os.File
fmt.Println(reflect.ValueOf(r)) // pointer address
```

## Things to watch

- Interface values are two machine words in size: the first word points to type metadata (itable), and the second word points to the actual data value.

## Terms

- **itable**: Interface table containing type metadata and function pointers for method dispatch.
- **Dynamic value**: The data word inside an interface referencing the concrete object.
