## Overview

This program demonstrates zero-copy conversion from a byte slice (`[]byte`) to a `string` using `unsafe.String`, illustrating that both reference identical backing memory.

## How it works

1. Creates byte slice `buf := []byte("Hello World")`.
2. Creates string `s := unsafe.String(unsafe.SliceData(buf), len(buf))` without heap allocation.
3. Prints `s` (`"Hello World"`).
4. Modifies the original slice: `buf[0] = 'h'`.
5. Prints `s` again, which now reflects `"hello World"`.

## Key excerpt

```go
buf := []byte("Hello World")

// s shares the underlying backing array of buf with zero allocation
s := unsafe.String(unsafe.SliceData(buf), len(buf))

fmt.Println(s) // Hello World
buf[0] = 'h'
fmt.Println(s) // hello World
```

## Things to watch

- Modifying the underlying byte buffer after creating a string with `unsafe.String` violates Go's immutability assumptions. Only use when the byte slice will never be modified again.

## Terms

- **Zero-copy**: An optimization technique where data is referenced in place rather than copied into a new memory buffer.
- **unsafe.String**: Standard library function introduced in Go 1.20 to construct strings directly from raw byte pointers.
