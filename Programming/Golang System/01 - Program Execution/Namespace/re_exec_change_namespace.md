## Overview

This program demonstrates the self-re-execution pattern in Go to create an isolated Linux mount namespace. Because the Go runtime starts multiple OS threads upon initialization, creating and configuring namespaces must be performed by re-executing the binary itself (`/proc/self/exe`) with special clone flags, comparing mount namespace IDs between parent and child processes.

## Concepts used

- Process self-re-execution (`/proc/self/exe`)
- Linux mount namespaces (`syscall.CLONE_NEWNS`)
- Querying namespace inodes from `/proc/<pid>/ns/mnt`
- Multi-stage CLI branching via `os.Args`

## How it works

The code contains `//go:build linux`.

The helper function `PrintPidAndMntNS(pid int, tag string)`:
- Reads the symlink target `/proc/<pid>/ns/mnt`.
- Strips the `"mnt:["` prefix and `"]"` suffix to extract the numeric inode of the mount namespace.
- Prints the tag, PID, and namespace ID.

The `parent()` function:
- Re-executes the current binary by invoking `/proc/self/exe child`.
- Sets `cmd.SysProcAttr = &syscall.SysProcAttr{Cloneflags: syscall.CLONE_NEWNS}`.
- Starts the command and calls `PrintPidAndMntNS(cmd.Process.Pid, "Parent")`.
- Waits for completion.

The `child()` function:
- Spawns an interactive shell `exec.Command("sh")`.
- Starts the shell and calls `PrintPidAndMntNS(cmd.Process.Pid, "Child")`.
- Waits for shell exit.

In `main`:
- Checks `os.Args`. If called with `args[1] == "child"`, it branches into `child()`.
- Otherwise, prints the main process PID and namespace, and invokes `parent()`.

## Key excerpt

```go
func PrintPidAndMntNS(pid int, tag string) {
	fmt.Println(tag, "PID=", pid)

	// mnt namespace id read
	mntNSPath := fmt.Sprintf("/proc/%d/ns/mnt", pid)

	mntNSOut, err := os.Readlink(mntNSPath)
	if err != nil {
		panic(err)
	}

	mntNSID := strings.TrimPrefix(mntNSOut, "mnt:[")
	mntNSID = strings.TrimSuffix(mntNSID, "]")
	fmt.Println(mntNSPath, "=", mntNSID)
}

// self-re-execution pattern
func parent() {
	cmd := exec.Command("/proc/self/exe", "child")
	cmd.Stdin = os.Stdin
	cmd.Stdout = os.Stdout
	cmd.Stderr = os.Stderr

	cmd.SysProcAttr = &syscall.SysProcAttr{
		Cloneflags: syscall.CLONE_NEWNS,
	}

	if err := cmd.Start(); err != nil {
		panic(err)
	}

	PrintPidAndMntNS(cmd.Process.Pid, "Parent")
	cmd.Wait()
}
```

## Things to watch

- **Privilege requirement:** Creating a new mount namespace without an accompanying user namespace (`CLONE_NEWUSER`) requires `CAP_SYS_ADMIN` privileges (running via `sudo`).
- **Linux /proc/self/exe link:** `/proc/self/exe` is a Linux virtual filesystem symlink pointing to the current executable binary. This mechanism does not exist on macOS or Windows.

## Terms

- **/proc/self/exe:** A special symlink in the Linux `/proc` filesystem that points to the absolute path of the currently executing binary.
- **Namespace Inode:** A unique 32-bit or 64-bit integer identifier assigned by the Linux kernel representing a specific namespace instance.
