## Overview

This program demonstrates what happens when a child process is placed in a separate process group (`Setpgid: true`) on Linux while sharing the parent's standard input. When a process in a background process group attempts to read from the controlling terminal, the Linux kernel sends a `SIGTTIN` signal, immediately halting the child process and causing execution to appear to hang.

## How it works

The code contains the `//go:build linux` build tag.

In `main`:
- Constructs `cmd1 := exec.Command("./sum")`.
- Maps standard streams: `cmd1.Stdin = os.Stdin`, `cmd1.Stdout = os.Stdout`, `cmd1.Stderr = os.Stderr`.
- Sets `cmd1.SysProcAttr = &syscall.SysProcAttr{Setpgid: true}`. This instructs the OS kernel to place the child into a brand new process group where `PGID == childPID`.
- Calls `cmd1.Start()`, printing the child PID.
- Calls `cmd1.Wait()`.
- If `./sum` attempts to read from standard input, the kernel detects that the process group of `./sum` is not the foreground process group of the terminal, so it delivers `SIGTTIN` to stop the child. The parent blocks indefinitely inside `cmd1.Wait()`.

## Key excerpt

```go
	cmd1 := exec.Command("./sum")
	cmd1.Stdin = os.Stdin
	cmd1.Stdout = os.Stdout
	cmd1.Stderr = os.Stderr

	cmd1.SysProcAttr = &syscall.SysProcAttr{
		Setpgid: true,
	}

	if err := cmd1.Start(); err != nil {
		panic(err)
	}

	fmt.Println("PID=", cmd1.Process.Pid)

	err := cmd1.Wait()
```

## Things to watch

- **The SIGTTIN stop:** Assigning `Setpgid: true` isolates the process group from the terminal. If the child attempts to read from `/dev/tty` or inherited standard input while in the background, the operating system stops it with `SIGTTIN`. To resolve this, the parent must explicitly transfer terminal foreground ownership using `TIOCSPGRP`.
- **Platform dependency:** Requires Linux due to `SysProcAttr` configuration.

## Terms

- **Process Group (PGID):** A collection of one or more processes that receive the same operating system signals.
- **SIGTTIN:** A POSIX signal sent to a background process when it attempts to read from its controlling terminal.
