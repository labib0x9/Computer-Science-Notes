## Overview

This program demonstrates how to properly transfer controlling terminal foreground ownership between a parent Go process and a newly spawned child process group on Linux. It illustrates the complete lifecycle: ignoring `SIGTTOU`, transferring the foreground group via `TIOCSPGRP`, waiting for the child, and restoring the parent's process group before exiting.

## Concepts used

- Signal suppression with `signal.Ignore(syscall.SIGTTOU)`
- New process group isolation (`Setpgid: true`)
- Terminal control transfer with `TIOCSPGRP` ioctl
- Foreground process group restoration via `syscall.Getpgrp()`

## How it works

The code includes `//go:build linux` for Linux platform compatibility.

In `main`:
- Calls `signal.Ignore(syscall.SIGTTOU)`. This prevents the parent process from being suspended when setting terminal attributes or changing foreground process groups.
- Configures `cmd1 := exec.Command("./sum")` with `cmd1.SysProcAttr = &syscall.SysProcAttr{Setpgid: true}` so the child starts in a new process group.
- Starts the process with `cmd1.Start()` and prints its PID.
- Opens `/dev/tty` with read-write permissions.
- Queries `childPGID, _ := unix.Getpgid(childPID)`.
- Invokes `unix.IoctlSetPointerInt(int(tty.Fd()), unix.TIOCSPGRP, childPGID)` to give the child exclusive control over the terminal keyboard and display.
- Calls `cmd1.Wait()`, allowing the child to run interactively.
- After the child terminates, reads `parentPGID := syscall.Getpgrp()`.
- Calls `unix.IoctlSetPointerInt(int(tty.Fd()), unix.TIOCSPGRP, parentPGID)` to safely restore the parent process as the foreground terminal owner.
- Checks and prints exit error and exit status code.

## Key excerpt

```go
	signal.Ignore(syscall.SIGTTOU)

	cmd1 := exec.Command("./sum")
	cmd1.Stdin = os.Stdin
	cmd1.Stdout = os.Stdout
	cmd1.Stderr = os.Stderr

	cmd1.SysProcAttr = &syscall.SysProcAttr{
		Setpgid: true,
	}

	if err := cmd1.Start(); err != nil {
		panic(err)
	}

	childPID := cmd1.Process.Pid
	fmt.Println("Child Process ID=", childPID)

	tty, err := os.OpenFile("/dev/tty", os.O_RDWR, 0)
	if err != nil {
		panic(err)
	}
	defer tty.Close()

	childPGID, _ := unix.Getpgid(childPID)

	if err := unix.IoctlSetPointerInt(int(tty.Fd()), unix.TIOCSPGRP, childPGID); err != nil {
		panic(err)
	}
```

## Things to watch

- **Device file access:** Opening `/dev/tty` requires an interactive terminal session. In non-interactive environments (such as headless Docker containers or CI pipelines without a TTY), `os.OpenFile("/dev/tty", ...)` will fail with `no such device or address`.
- **Typo in filename:** The filename `foregound_trnasfer.go` contains spelling errors ("foregound" and "trnasfer"), which are preserved in the note name to maintain exact alignment with the source file.

## Terms

- **TIOCSPGRP:** Terminal I/O Control Set Process Group, an ioctl command setting the foreground process group associated with a terminal.
- **SIGTTOU:** The signal generated by the kernel when a background process attempts to write to or modify settings of a terminal.
