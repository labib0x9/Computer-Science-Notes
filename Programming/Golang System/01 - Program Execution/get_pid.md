## Overview

This program demonstrates how to retrieve the Process ID (PID) and Process Group ID (PGID) of the currently running Go application using the `os` and `syscall` packages on Linux. It prints both identifiers and pauses for 10 minutes, providing an opportunity for developers to inspect the process tree and signal groups using external terminal tools like `ps`.

## Concepts used

- Process ID inspection (`os.Getpid()`)
- Process Group ID retrieval (`syscall.Getpgid()`)
- Process pausing with `time.Sleep`

## How it works

The file contains `//go:build linux`.

In `main`:
- Calls `os.Getpid()` to obtain the process identifier assigned by the Linux kernel.
- Calls `syscall.Getpgid(mainPID)` to obtain the process group identifier.
- Prints both IDs separated by a space.
- Invokes `time.Sleep(10 * time.Minute)` to keep the process alive in the foreground or background for inspection via `ps -p <PID> -o pid,ppid,pgid,comm`.

## Key excerpt

```go
func main() {

	mainPID := os.Getpid()
	mainPGID, _ := syscall.Getpgid(mainPID)

	fmt.Println(mainPID, mainPGID)

	time.Sleep(10 * time.Minute)
}
```

## Things to watch

- **Long sleep duration:** The 10-minute sleep is intended for interactive diagnostic inspection and will block the terminal unless terminated with `SIGINT` (`Ctrl+C`) or placed in the background.

## Terms

- **PGID (Process Group ID):** The numerical identifier of a process group, typically matching the PID of the group leader process.
