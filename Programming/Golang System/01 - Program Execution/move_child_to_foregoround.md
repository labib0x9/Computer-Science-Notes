## Overview

This program demonstrates the correct sequence for handing terminal foreground control to an external child process and safely reclaiming it in Go on Linux. It launches a child in a new process group, hands over `/dev/tty` using `TIOCSPGRP`, waits for completion, restores the parent's process group to the foreground, and successfully reads a line from standard input without triggering `SIGTTIN`.

## Concepts used

- Full terminal foreground handover and reclaim cycle

- Standard input line reading using `bufio.Reader`

## How it works

The code contains `//go:build linux`.

In `main`:
- Calls `signal.Ignore(syscall.SIGTTOU)`.
- Prepares `cmd1 := exec.Command("./sum")` with `Setpgid: true`.
- Opens `/dev/tty`.
- Starts the child process with `cmd1.Start()`.
- Obtains `childPGID` and calls `unix.IoctlSetPointerInt(int(tty.Fd()), unix.TIOCSPGRP, childPGID)`.
- Waits for the child via `cmd1.Wait()`.
- Reclaims terminal control for the parent: fetches `parentPGID := syscall.Getpgrp()` and executes `unix.IoctlSetPointerInt(int(tty.Fd()), unix.TIOCSPGRP, parentPGID)`.
- Evaluates child exit status.
- Reads a line of user input using `bufio.NewReader(os.Stdin).ReadString('\n')` and prints it. Because terminal foreground control was restored, this read succeeds without hanging.

	// move child process to foreground...
