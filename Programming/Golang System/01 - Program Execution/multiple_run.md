## Overview

This program demonstrates the correct design pattern for executing an external command multiple times in Go. Because the Go standard library disallows reusing an `exec.Cmd` struct after it has started, the program defines a factory function `newExecCmd` that constructs a fresh `exec.Cmd` instance for each invocation, resetting input and output buffers between runs.

## How it works

The function `newExecCmd(in io.Reader, out io.Writer, name string, args ...string) *exec.Cmd`:
- Takes input and output streams, an executable path, and variadic arguments.
- Instantiates and returns a new `&exec.Cmd` configured with standard streams.

In `main`:
- Allocates `out := strings.Builder{}` and `in := strings.NewReader("1 2\n")`.
- First run: creates `cmd = newExecCmd(in, &out, "./sum")`, calls `cmd.Start()`, calls `cmd.Wait()`, and prints `out.String()`.
- Second run: calls `out.Reset()` to clear previous output, calls `in.Reset("6 7\n")` to supply new input data, creates a fresh `cmd = newExecCmd(in, &out, "./sum")`, calls `cmd.Start()`, calls `cmd.Wait()`, and prints the new result.

## Key excerpt

```go
func newExecCmd(in io.Reader, out io.Writer, name string, args ...string) *exec.Cmd {
	cmd := exec.Command(name, args...)
	cmd.Stdin = in
	cmd.Stdout = out
	cmd.Stderr = os.Stderr
	return cmd
}

func main() {
	out := strings.Builder{}
	in := strings.NewReader("1 2
")

	cmd := newExecCmd(in, &out, "./sum")
	cmd.Start()
	cmd.Wait()
	fmt.Println(out.String())

	// Again Run
	out.Reset()
	in.Reset("6 7
")
	cmd = newExecCmd(in, &out, "./sum")
	cmd.Start()
	cmd.Wait()
	fmt.Println(out.String())
}
```

## Things to watch

- **Buffer reuse:** Reusing `strings.Builder` and `strings.Reader` via `.Reset()` prevents unnecessary heap allocations across iterations.

## Terms

- **Factory function:** A function that creates and returns newly configured instances of a struct or object.
- **strings.Builder.Reset:** Clears the underlying byte buffer of a `strings.Builder` for reuse.
