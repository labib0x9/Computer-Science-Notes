## Overview

This program demonstrates how to execute an external command and capture its standard output directly into a byte slice using `cmd.Output()` in Go. It shows how providing an `io.Reader` to `cmd.Stdin` enables feeding input to the child program while collecting its result in a single convenient function call.

## Concepts used

- Standard output capture with `cmd.Output()`
- Feeding standard input via `strings.NewReader`
- Error handling with external command output

## How it works

In `main`:
- Creates command `cmd := exec.Command("./sum")`.
- Prepares standard input using `in := strings.NewReader("1 2\n")` and binds it to `cmd.Stdin`.
- Invokes `out, err := cmd.Output()`. Internally, `Output()` runs the command, blocks until completion, collects bytes written to standard output, and returns them as a `[]byte`.
- Checks for errors. If successful, converts `out` to a string and prints it.

## Key excerpt

```go
func main() {
	cmd := exec.Command("./sum") // sum is a ext file in the current dir with no arg

	// io.Reader implements
	in := strings.NewReader("1 2
")

	// // I/O mechanism
	cmd.Stdin = in

	// runs the cmd and stores the output in out
	// out is []byte
	// io.Writer = bytes.Buffer
	out, err := cmd.Output()
	if err != nil {
		fmt.Println("Output Error" + err.Error())
		return
	}

	fmt.Println(string(out))
}
```

## Things to watch

- **cmd.Stdout conflict:** Calling `cmd.Output()` sets `cmd.Stdout` internally. If you manually assign `cmd.Stdout` prior to calling `Output()`, `cmd.Output()` will return an error stating `exec: Stdout already set`.
- **Standard error exclusion:** `cmd.Output()` captures standard output only. Any error output written by the child to standard error is returned as part of `*exec.ExitError.Stderr` if the command fails, or discarded if it succeeds. Use `cmd.CombinedOutput()` to capture both streams simultaneously.

## Terms

- **cmd.Output:** A high-level helper method in Go's `os/exec` that runs an executable and returns its stdout as `([]byte, error)`.
