## Overview

This program demonstrates how to execute shell commands and scripts in Go by invoking the POSIX shell `/bin/sh` with the `-c` flag. While `exec.Command` directly executes binaries without shell expansion by default, running `sh -c` allows developers to leverage shell features like pipes, variable expansion, and path evaluation.

## Concepts used

- Shell command invocation (`sh -c <cmd>`)
- Direct terminal stream mapping (`cmd.Stdout = os.Stdout`)
- Synchronous command execution (`cmd.Run()`)

## How it works

In `main`:
- Prepares command `cmd := exec.Command("sh", "-c", "pwd")`.
- Maps standard output and error directly to the terminal: `cmd.Stdout = os.Stdout`, `cmd.Stderr = os.Stderr`.
- Invokes `cmd.Run()`. The Go runtime spawns the `/bin/sh` process with arguments `["-c", "pwd"]`, prints the current working directory directly to terminal output, and checks for errors.

## Key excerpt

```go
func main() {

	cmd := exec.Command("sh", "-c", "pwd")

	// output via terminal / stdio
	// cmd.Stdin = os.Stdin
	cmd.Stdout = os.Stdout
	cmd.Stderr = os.Stderr

	if err := cmd.Run(); err != nil {
		fmt.Println("Run error:" + err.Error())
		return
	}
}
```

## Things to watch

- **Command injection security risk:** Passing un-sanitized user input into `sh -c` creates command injection vulnerabilities. Whenever possible, invoke executable binaries directly with discrete arguments rather than delegating through an intermediate shell.

## Terms

- **POSIX Shell (sh):** The standard Unix command language interpreter.
- **-c flag:** A shell option indicating that the subsequent string argument is to be parsed and executed as a shell command line.
