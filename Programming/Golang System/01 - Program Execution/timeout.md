## Overview

This program demonstrates how to enforce execution time limits on external processes using Go's `context` package. By creating a cancellation context with `context.WithTimeout` and passing it to `exec.CommandContext`, Go automatically sends a termination signal (SIGKILL) to kill the process if it does not finish within the deadline.

## Concepts used

- Context deadline management (`context.WithTimeout`)
- Process cancellation via `exec.CommandContext`
- Automatic SIGKILL termination on timeout expiration
- Detecting timeout cancellation in `ExitError`

## How it works

In `main`:
- Sets a 10-second timeout context: `ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)`.
- Defers `cancel()` to release context resources.
- Creates command: `cmd := exec.CommandContext(ctx, "./sum")`.
- Maps standard input and output.
- Invokes `cmd.Run()`. If `./sum` finishes within 10 seconds, `cmd.Run()` returns `nil`. If 10 seconds elapse before completion, the context is cancelled, prompting Go to terminate the process immediately.
- Inspects `err.(*exec.ExitError)` to report non-zero termination.

## Key excerpt

```go
func main() {

	// set timeout for 10sec
	ctx, cancel := context.WithTimeout(
		context.Background(),
		10*time.Second,
	)
	defer cancel()

	cmd := exec.CommandContext(ctx, "./sum")
	cmd.Stdin = os.Stdin
	cmd.Stdout = os.Stdout

	err := cmd.Run()
	if errExit, ok := err.(*exec.ExitError); ok {
		fmt.Println("Run Error=", err.Error())
		fmt.Println("Exit Error=", errExit.ExitCode())
		return
	}

	fmt.Println("Succesfully terminated")
}
```

## Things to watch

- **SIGKILL behavior:** On Unix systems, `CommandContext` kills the child process with `SIGKILL` when the context expires. The process is terminated abruptly without an opportunity to run cleanup handlers or flush open file buffers.
- **Process group caveat:** If the child process spawns child sub-processes of its own, killing the parent process via context does not kill its children unless a process group kill is configured via `SysProcAttr`.

## Terms

- **context.Context:** A standard Go interface used to propagate deadlines, cancellation signals, and request-scoped values across API boundaries.
- **SIGKILL:** A Unix signal (signal 9) that unconditionally and immediately terminates a process without catching.
