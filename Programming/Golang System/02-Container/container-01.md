- **pivot_root vs. chroot:** `pivot_root` is more secure than `chroot` because it swaps the actual root mount of the process and allows detaching and unmounting the old host filesystem entirely.

## Terms

- **pivot_root:** A Linux system call that moves the root filesystem of the current process to a directory in the new root and makes the new root the current root.
- **MNT_DETACH:** A mount flag performing a "lazy" unmount that removes the mount point immediately from the namespace while allowing active file references to complete.
