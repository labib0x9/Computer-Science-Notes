## Overview

This program demonstrates the complete lifecycle of a Docker container using the official Docker Go SDK (`github.com/docker/docker/client`). It connects to the local Docker daemon, inspects and pulls an Alpine Linux image if not present, creates a container, starts it, waits for it to exit, retrieves its standard output logs, and cleans up by removing the container.

## Concepts used

- Docker Go Client initialization (`client.NewClientWithOpts`)
- Image inspection and pulling (`ImageInspect`, `ImagePull`)
- Container lifecycle methods (`ContainerCreate`, `ContainerStart`, `ContainerWait`, `ContainerRemove`)
- Streaming container logs (`ContainerLogs`, `io.Copy`)

## How it works

The `main` function executes the following steps:
- Connects to the Docker daemon using `client.NewClientWithOpts(client.FromEnv, client.WithAPIVersionNegotiation())`.
- Defines `imageN := "alpine:3.20"` and checks if it exists locally via `client.ImageInspect`. If absent, pulls it from Docker Hub using `client.ImagePull` and streams download progress to `os.Stdout`.
- Creates a container named `"container-vv9"` via `client.ContainerCreate`, configuring it to execute `["echo", "Hello host"]`.
- Starts the container via `client.ContainerStart(context.Background(), containerId, ...)`.
- Waits for completion via `client.ContainerWait`, listening on channels `respCh` and `errCh` with `WaitConditionNotRunning` until the container stops.
- Retrieves logs using `client.ContainerLogs(..., container.LogsOptions{ShowStdout: true, ShowStderr: true})` and copies output to `os.Stdout`.
- Deletes the container using `client.ContainerRemove`.

## Key excerpt

```go
	containerN := "container-vv9"
	resp, err := client.ContainerCreate(context.Background(),
		&container.Config{
			Image: imageN, // image has to be present.. or pull
			Cmd:   []string{"echo", "Hello host"},
		},
		nil, nil, nil, containerN,
	)
	if err != nil {
		panic(err)
	}

	containerId = resp.ID
	fmt.Println("Continaer", containerN, "Created# Id:", containerId)

	// --- // STart the container.
	if err := client.ContainerStart(context.Background(), containerId, container.StartOptions{}); err != nil {
		panic(err)
	}

	// --- // Wait container to finish, Not Running -> Blocks until the container exits
	respCh, errCh := client.ContainerWait(context.Background(), containerId, container.WaitConditionNotRunning)
	select {
	case resp := <-respCh:
		fmt.Println(resp.StatusCode)
	case err := <-errCh:
		fmt.Println(err.Error())
	}
```

## Things to watch

- **Docker daemon requirement:** This program requires the Docker daemon (`dockerd` or Docker Desktop) to be actively running. If the daemon is unreachable, `client.NewClientWithOpts` or the first API call panics with `Cannot connect to the Docker daemon`.
- **Container name collisions:** The name `"container-vv9"` is hardcoded. If a previous run failed before `ContainerRemove` could execute, subsequent runs will panic with a naming conflict error (`Conflict. The container name ... is already in use`).

## Terms

- **Docker Daemon:** The persistent background service managing Docker containers, images, networks, and storage volumes.
- **API Version Negotiation:** Automatically selecting the highest mutually supported Docker API version between client and server.
