## Overview

This program demonstrates how to create and operate an interactive Docker container with pseudo-TTY support using the Docker Go SDK. It shows how to attach to a running container's input/output streams via raw hijacked network connections (`client.ContainerAttach`), send commands to the container's shell, stream responses back, and manage execution timeouts.

https://github.com/labib0x9/Programming-Notes/blob/main/Programming/Golang%20System/03-Docker%20Api/interractive.go

## Concepts used

- Interactive container creation (`Tty: true`, `OpenStdin: true`)
- Raw connection hijacking with `client.ContainerAttach`
- Bi-directional stream communication
- Execution timeouts using `time.NewTimer` and select channels

## How it works

In `main`:
- Connects to the Docker daemon.
- Ensures `alpine:3.20` is pulled locally.
- Creates container `"container-vv10"` with `Cmd: []string{"/bin/sh"}`, `AttachStdin: true`, `AttachStdout: true`, `Tty: true`, and `OpenStdin: true`.
- Calls `client.ContainerAttach` with `Stream: true`, returning a hijacked raw socket connection `hijack`.
- Starts the container via `client.ContainerStart`.
- Sends command bytes directly into the container's shell: `hijack.Conn.Write([]byte("whoami\n"))`.
- Copies container output to `os.Stdout` using `io.Copy(os.Stdout, hijack.Reader)`.
- Waits for container exit or a 30-second timeout timer. If the timer fires first, issues `client.ContainerStop`.
- Retrieves container logs and removes the container with `Force: true`.

## Things to watch

- **Spelling in filename:** Preserves the filename typo `interractive.go` ("rr").
- **Hijacked connection blocking:** `io.Copy(os.Stdout, hijack.Reader)` will block until EOF is reached on the stream (i.e. when standard output from the container closes). If the container shell stays open, `io.Copy` will block until the connection is closed.

## Terms

- **Hijacked Connection:** A persistent raw TCP/Unix socket connection hijacked from an HTTP upgrade, allowing streaming binary I/O.
- **Pseudo-TTY (pty):** An emulated terminal device providing terminal line discipline and interactive shell behaviors.
