## Overview

This program demonstrates how to download container images from Docker Hub or a remote container registry using the official Docker Go SDK. It issues an `ImagePull` request for `alpine:3.20` and streams the JSON progress status events directly to standard output.

## Concepts used

- Docker SDK client initialization
- Registry image downloading (`client.ImagePull`)
- Reading and streaming response streams via `io.Copy`

## How it works

In `main`:
- Initializes the Docker client with environment credentials and API negotiation.
- Invokes `reader, err := client.ImagePull(context.Background(), "alpine:3.20", image.PullOptions{})`.
- Checks for connection or authentication errors.
- Defers `reader.Close()` to ensure network stream closure.
- Streams the raw JSON progress updates from Docker Hub to the terminal using `io.Copy(os.Stdout, reader)`.

## Key excerpt

```go
func main() {

	// --- // Connect to dockerhub
	client, err := client.NewClientWithOpts(
		client.FromEnv,
		client.WithAPIVersionNegotiation(),
	)
	if err != nil {
		panic(err)
	}
	defer client.Close()

	reader, err := client.ImagePull(context.Background(), "alpine:3.20", image.PullOptions{})
	if err != nil {
		panic(err)
	}
	defer reader.Close()
	io.Copy(os.Stdout, reader)
}
```

## Things to watch

- **Raw JSON output stream:** `client.ImagePull` returns an `io.ReadCloser` that yields raw JSON objects detailing layer download progress rather than human-readable text. Production CLIs typically use `json.NewDecoder` or Docker's `pkg/jsonmessage` to format the progress output into a visual progress bar.

## Terms

- **Image Pull:** Downloading image layers and manifest data from a container registry to the local Docker engine store.
