## Overview

Now, again: why did I choose Go? Why not JavaScript or a Node.js framework, Python or Django, C# or .NET, Java or Spring Boot?

Actually, no particular reason. I tried Python and gave up after learning it has C underneath. JS has too much competition. I didn't like the OOP concepts in C# and Java, though they were important. I was also searching for how to do automation, and found that Go and Python are the most popular choices. While I was trying Python, I started exploring Go, and found it much easier to understand coming from a C/C++ background. Then I found it has literally everything that interests me. So I started learning it (what a dumb reason 😢) : the basic concepts, what it is popular for, and how it connects to other languages. Learning one language deeply explains most of the concepts in the others. Only the syntax and abstractions differ, so I wanted to go deep on this one.

- Basics (data types, variables, conditions, loops)
- Functions
- Closures and scope
- Arrays, strings, and slices
- Maps
- Structs
- Interfaces and Reflection
- Generics
- Error handling
- Testing
- Goroutines and channels (yooh, this is much more interesting...)
